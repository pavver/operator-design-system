# Рух

Рух існує лише для того, щоб пояснити, що сталося.
Інтерфейс у стані спокою є нерухомим.

## Тривалості

Усі значення наведено в мілісекундах і вони знаходяться в таблиці `[motion]` у [tokens.toml](../../tokens/tokens.toml).

## Криві

| Назва | Визначення | Застосування |
| :--- | :--- | :--- |
| Standard | `cubic-bezier(0.4, 0, 0.2, 1)` | Звичайні кольори стану, стрибки значень. |
| Smooth | `cubic-bezier(0.45, 0, 0.55, 1)` (smoothstep) | Згасання результату при виході. |
| Linear | `linear` | Ковзання індикаторів, спінери, кола очікування. |

## Правила

* Кольори результату з'являються миттєво та зникають із затуханням smoothstep тривалістю `500 ms`.
* Пряме перемикання між Success та Error змінює колір миттєво, без згасання.
* Переходи межі, фону, тексту та піктограми одного елемента керування починаються в одному кадрі.
* Рух, який скасовується (відкат), використовує ті самі тривалість і криву, що й рух, який його спричинив.
* Рух точно повторює вказівник під час перетягування і ніколи не анімується із запізненням.
