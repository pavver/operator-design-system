# Колір

## Концепція

Нейтральні кольори наслідують сірий робочий простір сучасних редакторів коду: пласкі, низькоконтрастні поверхні, що не привертають зайвої уваги.
Сигнальні кольори — це теплі графітові тони: бурштиновий для фокусу та виділення, бірюзовий для роботи, що триває, зелений і червоний для результатів.
Синій колір свідомо відсутній у наборі акцентів.
Колір завжди має значення; декоративних кольорів немає.

Точні значення знаходяться в [tokens.toml](../../tokens/tokens.toml) під `[themes.operator.dark]` та `[themes.operator.light]`.
Цей файл є єдиним джерелом правди; цей документ пояснює ролі.

## Правила

* Сигнальний колір з'являється лише тоді, коли діє його значення.
  Бурштиновий ніколи не прикрашає; бірюзовий з'являється лише під час очікування.
* Тоновані фони — це сигнальний колір із непрозорістю `15%`, накладений на поверхню.
  Натиснуті деструктивні кнопки використовують `30%`.
  Заповнення повзунка використовує `accent` на рівні `35%`, щоб межа очікування залишалася видимою над ним.
* Шари статусу згасають лише за непрозорістю.
  Їхні канали RGB ніколи не інтерполюються до базового кольору, що запобігає проміжним сірим кадрам.
* Темна та світла палітри мають однаковий набір ключів.
  Генератор токенів відхиляє палітру з відсутніми або зайвими ключами.
* Групи для конкретних компонентів: `status_*` для [StatusBadge](../components/status-badge.md), `switch_*` для [AsyncSwitch](../components/switch.md), `term_*` для [ConsoleTerminal](../components/console-terminal.md), `syntax_*` для [CodeBlock](../components/code-block.md) та `toggle_*` для [ThemeToggle](../components/theme-toggle.md).
