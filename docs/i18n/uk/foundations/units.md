# Одиниці вимірювання

Operator UI визначає дві незалежні від платформи одиниці.
Специфікації та переносні реалізації використовують лише ці одиниці.
Необроблені значення `dp`, `px`, `sp`, `pt` та `rem` заборонені.

## Design Units (DU)

`1 DU = 4 logical points`.
DU вимірює кожне просторове значення: розміри, внутрішні відступи, проміжки, межі, розміри піктограм та зміщення.
DU ніколи не масштабується разом із налаштуванням розміру тексту користувача.
Значення є кратними або простими частками одного DU, такими як `0.25 DU`, `0.5 DU`, `1.5 DU` або `10 DU`.

| Платформа | Відображення |
| :--- | :--- |
| Web (CSS) | `--op-du: 4px`; значення дорівнює `calc(var(--op-du) * N)`. |
| Jetpack Compose | `1 DU = 4.dp`. |
| egui | `1 DU = 4.0` points. |

## Type Units (TU)

`1 TU = 1 scalable logical point`.
TU вимірює лише розміри шрифту та висоту рядків.
TU слідує за налаштуванням масштабу тексту користувача.

| Платформа | Відображення | Джерело масштабування |
| :--- | :--- | :--- |
| Web (CSS) | `--op-tu: 0.0625rem`. | Кореневий розмір шрифту браузера. |
| Jetpack Compose | `1 TU = 1.sp`. | Системний масштаб шрифту. |
| egui | `1 TU = 1.0 * text_scale` points. | Налаштування застосунку. |

## Просторові токени

Надавайте перевагу іменованому токену над літералом.
Значення знаходяться в [tokens.toml](../../tokens/tokens.toml).

| Токен | Значення | Типове використання |
| :--- | :--- | :--- |
| `border` | `0.25 DU` | Стандартний контур. |
| `border_thick` | `0.5 DU` | Контур для акцентування, кільце фокусу. |
| `spinner_stroke` | `0.375 DU` | Штрих малих спінерів. |
| `gap_micro` | `0.5 DU` | Внутрішній відступ компактних контейнерів. |
| `pad_tight` | `1 DU` | Щільні проміжки, крапки поділок. |
| `pad_small` | `1.5 DU` | Проміжок між піктограмою та текстом у малих елементах керування. |
| `gutter` | `2 DU` | Проміжок між пов'язаними елементами. |
| `pad_content` | `2.5 DU` | Внутрішній відступ вмісту. |
| `pad_card` | `3 DU` | Внутрішній відступ карток і полів. |
| `margin_screen` | `4 DU` | Відступ екрана, бічний внутрішній відступ кнопок. |
| `section_gap` | `6 DU` | Проміжок між розділами. |
| `icon_small` | `4 DU` | Піктограми всередині елементів керування. |
| `icon_medium` | `4.5 DU` | Піктограми панелі інструментів. |
| `icon_large` | `6 DU` | Окремі піктограми, повзунок слайдера. |
| `row_dense` | `6 DU` | Рядки журналу та консолі. |
| `row_compact` | `8 DU` | Компактні рядки, висота слайдера. |
| `row_standard` | `10 DU` | Кнопки, поля, стандартні рядки. |
| `row_control` | `12 DU` | Рядки з елементом керування та міткою. |
| `row_two_line` | `13 DU` | Рядки із заголовком і підзаголовком. |
| `row_avatar` | `14 DU` | Рядки з аватаром. |

Висота рядків є мінімальною висотою.
Рядок збільшується, коли його вміст потребує більше місця.

## Модель Clamp

Контейнер із динамічним вмістом ніколи не має фіксованої ширини.
Його ширина становить `clamp(MinDU, PreferredRatio * ViewportWidth, MaxDU)`.
Кожен компонент, який використовує модель clamp, перелічує свої три параметри.
