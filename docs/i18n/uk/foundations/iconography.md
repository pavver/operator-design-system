# Іконографія

## Джерело

Піктограми походять із [Material Symbols](https://fonts.google.com/icons?icon.style=Sharp) у стилі **Sharp**.
Прямі кути відповідають геометрії `0 DU` решти системи.
Material Symbols ліцензовано за Apache License 2.0.

Піктограма малюється з нуля лише тоді, коли жоден символ Material не відповідає значенню.
Власні піктограми підпорядковуються правилам у розділі [Власні піктограми](#custom-icons).

## Варіанти

| Вісь | Значення | Примітки |
| :--- | :--- | :--- |
| Стиль | Sharp | Завжди. |
| Заповнення | Outlined | Заповнений лише там, де цього вимагає специфікація, наприклад для позначення активного стану. |
| Товщина | 400 | Єдина товщина, що використовується. |
| Оптичний розмір | 20 | Для піктограм до `5 DU`; використовуйте 24 для `icon_large` і вище. |

## Розміри

| Токен | Розмір | Застосування |
| :--- | :--- | :--- |
| `icon_small` | `4 DU` | Піктограми всередині елементів керування: кнопки, поля, сегменти. |
| `icon_medium` | `4.5 DU` | Дії на панелі інструментів та в заголовку. |
| `icon_large` | `6 DU` | Окремі піктограми. |

Піктограми статусу всередині малих круглих елементів, таких як повзунок слайдера, використовують `3.5 DU`.

## Колір

Піктограми одноколірні та приймають поточний колір вмісту.
Вони підпорядковуються тим самим кольорам стану та переходам, що й текст, див. [states.md](states.md).
Піктограми ніколи не мають власної палітри.

## Значення

* Піктограма на перемикачі показує дію, яку він виконує, а не поточний стан.
  Перемикач показу пароля відображає `visibility`, поки текст приховано.
* `check` та `close` зарезервовані для зворотного зв'язку про успіх і помилку, а також для дій підтвердження та скасування.
* Елемент керування лише з піктограмою завжди має доступну назву.

## Додавання піктограми

1. Знайдіть символ на <https://fonts.google.com/icons?icon.style=Sharp>.
2. Додайте запис до [tokens/icons.toml](../../tokens/icons.toml), наприклад `wifi = { material = "wifi" }`.
3. Запустіть `python3 tools/import_material_symbols.py`, потім `cargo run -p operator-tokens`.

Імпортер зберігає лише `viewBox` та дані контуру офіційного SVG.
CI зазнає невдачі, якщо файл піктограми відрізняється від свого джерела Material або відсутній у маніфесті.

## Власні піктограми

* Оголосіть піктограму в маніфесті за допомогою `custom = true`.
* Використовуйте viewBox `0 0 24 24` лише із заповненими контурами; без штрихів, без трансформацій.
* Зберігайте поле в `2` одиниці всередині viewBox і товщину лінії, схожу на штрих, у `2` одиниці.
* Використовуйте гострі кути та кути 45° або 90°, де це можливо.
* Узгоджуйте візуальну вагу із сусідніми піктограмами Material Sharp при `4 DU`.
