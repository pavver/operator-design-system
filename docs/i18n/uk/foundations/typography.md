# Типографіка

## Шрифт

Cascadia Code — єдина гарнітура на кожній платформі.
Запасні варіанти — `Cascadia Mono`, потім моноширинний шрифт платформи.
Cascadia Code ліцензовано за SIL Open Font License 1.1.
Постачайте немодифікований файл шрифту.
Підмножина шрифту вважається модифікованою версією відповідно до ліцензії та не повинна використовувати зарезервовану назву шрифту.

Моноширинний шрифт забезпечує вирівнювання стовпців і запобігає зсувам компонування під час зміни чисел.
Він також надає інтерфейсу його технічного характеру.

## Насиченість

* **Regular (400):** описи, підказки, вторинні показники.
* **Medium (500):** кнопки, текст полів, заголовки рядків, невибрані сегменти.
* **Bold (700):** заголовки екранів, вибрані сегменти, підказки, критичні значення.

Ієрархія формується завдяки насиченості та кольору, а не великій різниці в розмірах.

Усі розміри наведено в Type Units, див. [units.md](units.md).

| Стиль | Розмір | Висота рядка | Насиченість | Використання |
| :--- | :--- | :--- | :--- | :--- |
| `app_title` | `20 TU` | `26 TU` | 700 | Заголовки застосунку та верхньої панелі. |
| `screen_title` | `18 TU` | `24 TU` | 500 | Заголовки екранів та розділів. |

| `body` | `14 TU` | `18 TU` | 400 | Базовий текст, значення полів, мітки кнопок. |

| `console` | `12 TU` | `16 TU` | 400 | Журнали та термінали. |

## Правила

* Текстові контейнери ніколи не мають фіксованої ширини, коли текст може змінюватися або бути перекладеним.
* Однорядковий текст усікається трикрапкою.
* Багаторядковий текст дозволяє своєму контейнеру рости по вертикалі.
* Числа, які оновлюються в реальному часі, використовують табличні цифри.
