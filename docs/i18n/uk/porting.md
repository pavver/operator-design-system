# Портування на нову платформу

Цей посібник перелічує, що потрібно реалізації платформи, аби вона виглядала та поводилася як еталон.
Веббібліотека в [web/operator-ui](../web/operator-ui) є поточною еталонною реалізацією.

## 1. Токени

* Додайте вивід для платформи до генератора токенів або використайте наявний.
  Набори інструментів Rust використовують [crates/operator-ui-tokens](../crates/operator-ui-tokens) безпосередньо.
* Надайте DU та TU як єдині одиниці довжини, див. [foundations/units.md](foundations/units.md).
* Завантажуйте Cascadia Code з немодифікованого файла шрифту.

## 2. Спільні примітиви

Створіть їх один раз перед будь-яким компонентом.
Після цього кожен компонент стає переважно компонуванням.

| Примітив | Призначення | Вебеталон |
| :--- | :--- | :--- |
| `ControlState`, `ActionResult` | Типи стану та результату. | `src/core/` |
| Async action | Обробник `(value) -> future of ActionResult`. | `AsyncAction` |
| Job token | Ігнорує результати застарілих запитів. | `JobToken` |
| State visual | Відстежує поточний стан, останній результат і згасання при виході. | `use_state_visual` |
| State border | Базовий контур, пульсація результату, фон результату, сегмент очікування. | `.op-sb` in CSS |
| Content tone | Кольори тексту й піктограм, що підпорядковуються тим самим правилам результату. | `.op-tone` in CSS |
| Ripple | Обмежена пульсація натискання від позиції вказівника. | `spawn_ripple` |
| Spinner | Обертова дуга 270°. | `ProgressIndicator` |

Правила межі стану визначені в [foundations/states.md](foundations/states.md).
Малюйте контур усередині меж.
У наборах інструментів на базі canvas робіть відступ для прямокутника обведення на половину товщини лінії, щоб краї потрапляли на цілі пікселі.

## 3. Компоненти

Реалізуйте кожен компонент за його специфікацією в [components](components).
Специфікація визначає поведінку; вебкод показує один зі способів її досягнення.

## 4. Контрольний список перевірки

Для кожного компонента перевірте кожен пункт у темному та світлому режимах:

* [ ] Кожен стан у специфікації відображається так, як описано.
* [ ] Розміри відповідають значенням DU при 100% і великому масштабі тексту; текст ніколи не обтинається.
* [ ] Кольори результату з'являються миттєво та згасають упродовж `500 ms` без нейтрального кадру.
* [ ] Очікування блокує введення; Success та Error — ні.
* [ ] Помилка повертає значення назад із тією самою анімацією, що й зміна вперед.
* [ ] Новіший запит відкидає результат старішого.
* [ ] Фокус із клавіатури та доступні назви працюють.
* [ ] Швидке повторне введення не залишає компонент застряглим у будь-якому стані.

## 5. Відстеження статусу

Оновіть таблицю компонентів у [README](../README.md), коли реалізацію платформи буде перевірено.
