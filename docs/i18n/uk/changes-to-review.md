# Зміни для перевірки

Ці зміни компонентів є чернетками, що очікують перевірки супроводжувачем, від найновіших до найстаріших.
Відкрийте сторінку компонента, щоб переглянути специфікацію та живі приклади, а потім виконайте вказівки щодо перевірки й переходу на нову версію, якщо їх наведено.
Затверджені зміни залишаються в історії кожного компонента.

## Черга перевірки

Черга заповнюється з файлів змін під час кожного збирання сайту документації.
Затвердіть, замініть або видаліть кожен файл згідно з [процесом ведення історії компонентів](releasing.md#історія-змін-компонентів).
