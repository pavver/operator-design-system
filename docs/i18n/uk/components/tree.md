# Tree

Ієрархія рядків із розгортанням: області та їхні пристрої, домени сутностей і сутності, теки.
Рендеряться лише видимі рядки, тому дерева з тисячами нод залишаються швидкими.

Статус: **чернетка** у вебреалізації.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Рядок | `row_compact` (`8 DU`), один рядок. |
| Відступ | `4 DU` на рівень плюс `1 DU`. |
| Стрілка | `chevron_right` у слоті `4 DU`, повернута на `90°` в розгорнутому стані; листки зберігають порожній слот, щоб підписи вирівнювалися. |
| Піктограма | Необов'язкова, `icon_small` (`4 DU`), `text_secondary`. |
| Подробиці | Необов'язковий текст `caption` у кінці, `text_secondary`. |
| Вибрана | Фон `pressed` і смуга `0.5 DU` у кольорі `accent` на початковому краї. |

## Поведінка

* Клік вибирає рядок; клік на стрілці або подвійний клік розгортає чи згортає його.
* Arrow Up і Down переміщують вибір; Right розгортає ноду або переходить до першої дочірньої; Left згортає ноду або переходить до батьківської; Home і End переходять до першого й останнього рядків.
* Вибраний елемент прокручується у видиму область.
* Рядки є [VirtualList](virtual-list.md).

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `nodes` | список або сигнал `TreeNode` | обов’язковий | `TreeNode::new(id, label)` із `icon`, `detail`, `children`; ідентифікатори унікальні в межах дерева. |
| `expanded` | сигнал множини ідентифікаторів | обов’язковий | Розгорнуті ноди. |
| `selected` | необов'язковий сигнал ідентифікатора | обов’язковий | Вибрана нода. |
| `on_select` | зворотний виклик `(id)` | немає | Викликається при кожному виборі. |
| `height`, `max_height` | DU | немає | Розмір прокручуваної області. |
| `label` | string | `Tree` | Доступна назва. |

## Доступність

* Дерево має роль `tree`; рядки мають роль `treeitem` із `aria-level`, `aria-expanded` та `aria-selected`.
* Прокручувана область отримує фокус, і клавіші зі стрілками працюють, поки він у ній.

## Кастомізація

`class` і `style` застосовуються до кореня.
Явні кореневі стилі мають перевагу над метричними пропсами; невстановлені метрики зберігають початковий рендеринг.
Внутрішній маркер вимірювання та ResizeObserver узгоджують висоти рядків VirtualList і зміщення показу з клавіатури зі змінною CSS.
Наявні пропси `height` і `max_height` зберігають значення в DU для прокручуваної області.

| `indent` | DU | `--op-tree-indent` | `4 DU` |

| `padding_end` | DU | `--op-tree-padding-end` | `pad_tight` |
