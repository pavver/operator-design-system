# Kbd

Клавіша або сполучення клавіш, показане в рядку з текстом або в меню.

Статус: **reviewed** у вебреалізації.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Ключ | Висота `6.5 DU`, ширина щонайменше `6.5 DU`; кути `0 DU`. |
| Широка клавіша | Щонайменше `11 DU` для Shift, Enter, Tab, Backspace, Caps Lock, Ctrl, Alt, Cmd і Win; підпис на початку. |
| Клавіша пробілу | Щонайменше `26 DU`. |
| Тіло | Темніший корпус клавіші виступає на `0.25 DU` зверху, `0.5 DU` з боків і утворює передній край `1 DU` знизу; під ним м'яка тінь. |
| Колір корпусу | `background`, змішаний із `border_strong`, світліший угорі. |
| Верхня грань | `text_primary` із непрозорістю близько 10% поверх `surface`, із легким вертикальним градієнтом і відблиском `0.25 DU` уздовж верхнього краю. |
| Тип | Розмір `caption`, напівжирний, по центру верхньої грані. |
| Розділювач | `+` у кольорі `text_secondary`, на відстані `0.5 DU` від клавіш. |

## Поведінка

* Рядок сполучення розділяється за `+`: `Ctrl+Shift+K` показує три клавіші.
* `Ctrl++` показує саму клавішу плюса.
* `Up`, `Down`, `Left` і `Right` (або `ArrowUp` тощо) відображаються як стрілки.

## API

| Властивість | Тип | Опис |
| :--- | :--- | :--- |
| `keys` | string | Клавіша або сполучення, наприклад `Esc` чи `Ctrl+K`. |
| `height` | DU | Висота клавіші; типово `6.5 DU`. |
| `wide_min_width` | DU | Мінімальна ширина широких клавіш; типово `11 DU`. |
| `space_min_width` | DU | Мінімальна ширина клавіші пробілу; типово `26 DU`. |
| `padding_x` | DU | Горизонтальний внутрішній відступ клавіші; типово `1 DU`. |
| `gap` | DU | Проміжок між клавішами; типово `0.5 DU`. |
| `font_size` | TU | Розмір шрифту клавіші; типово розмір `caption`. |
| `separator` | слот | Власний розділювач між клавішами. |
| `aria_label` | string | Доступний підпис; типово `keys`. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-kbd-height` | `6.5 DU` |
| `wide_min_width` | DU | `--op-kbd-wide-min-width` | `11 DU` |
| `space_min_width` | DU | `--op-kbd-space-min-width` | `26 DU` |
| `padding_x` | DU | `--op-kbd-padding-x` | `pad_tight` (`1 DU`) |
| `gap` | DU | `--op-kbd-gap` | `gap_micro` (`0.5 DU`) |
| `font_size` | TU | `--op-kbd-font-size` | `type_caption_size` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-kbd-face` | `color-mix(in srgb, var(--op-text-primary) 10%, var(--op-surface))` |
| `--op-kbd-body` | `color-mix(in srgb, var(--op-background) 55%, var(--op-border-strong))` |
| `--op-kbd-text` | `text_primary` |
| `--op-kbd-separator` | `text_secondary` |

| Слот | Розташування |
| :--- | :--- |
| `separator` | Вміст між клавішами сполучення, що замінює типовий розділювач-плюс. |

`class` і `style` застосовуються до кореня.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `kbd.plus` | `+` |

## Доступність

Назвою групи є повний рядок сполучення клавіш.
