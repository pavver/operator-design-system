# ChatMessage

Бульбашка повідомлення для чату, гілок обговорень і комунікаційних потоків.
Вона підтримує зображення аватара, зазначення відправника, часові мітки та окрему геометрію для надісланих і отриманих повідомлень.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `ChatMessage` в інтерфейсах розмов, панелях підтримки клієнтів або стрічках активності.
Не використовуйте `ChatMessage` для системних сповіщень чи вбудованої довідки; натомість використовуйте [Banner](banner.md) або [Toast](toast.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кута | `0 DU` (квадратна геометрія Operator). |
| Розмір аватара | `8 DU` квадрат. |
| Межа | Стандартний контур `0.25 DU` навколо бульбашки. |
| Внутрішній відступ | `2 DU` всередині бульбашки повідомлення (`--op-chat-message-padding`). |

## Поведінка

* Отримані повідомлення вирівнюються за початком контейнера з приглушеним тлом поверхні.
* Надіслані повідомлення вирівнюються за кінцем із піднятим тлом поверхні.
* Аватар та ім'я відправника розташовуються поруч із бульбашкою залежно від напрямку.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `sent` | bool | `false` | Відрізняє надіслані повідомлення від отриманих. |
| `name` | string | немає | Відображуване ім'я відправника. |
| `stamp` | string | немає | Часова мітка або мітка статусу доставки. |
| `avatar` | string | немає | URL-адреса зображення аватара. |
| `text` | string | немає | Тіло повідомлення звичайним текстом. |
| `name_slot` | Slot | немає | Власний слот для імені відправника. |
| `stamp_slot` | Slot | немає | Власний слот для часової мітки. |
| `avatar_slot` | Slot | немає | Власний слот для аватара. |
| `padding` | DU | `--op-chat-message-padding` | Внутрішній відступ бульбашки. |
| `gap` | DU | `--op-chat-message-gap` | Проміжок між елементами. |
| `font_size` | TU | `--op-chat-message-font-size` | Розмір тексту. |
| `class` | string | немає | CSS-класи на кореневому елементі. |
| `style` | string | немає | Інлайн-CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `padding` | DU | `--op-chat-message-padding` | `2 DU` |
| `gap` | DU | `--op-chat-message-gap` | `1 DU` |
| `font_size` | TU | `--op-chat-message-font-size` | `inherit` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-chat-message-border` | `var(--op-border)` |
| `--op-chat-message-sent-bg` | `var(--op-surface-raised)` |
| `--op-chat-message-sent-text` | `var(--op-text-primary)` |
| `--op-chat-message-received-bg` | `var(--op-surface-subtle)` |
| `--op-chat-message-received-text` | `var(--op-text-primary)` |
| `--op-chat-message-name-color` | `var(--op-text-secondary)` |
| `--op-chat-message-stamp-color` | `var(--op-text-secondary)` |

`class` та `style` застосовуються до кореневого `div`.

### Рядки

`ChatMessage` не містить жорстко закодованих видимих рядків; тексти передаються через пропси викликача.

### Піктограми

`ChatMessage` не рендерить піктограм безпосередньо.

## Доступність

Аватари позначаються як декоративні за допомогою `aria-hidden="true"`.
Контейнер повідомлення забезпечує природний порядок читання для скринрідерів.
