# ChatMessage

Повідомлення чату для бесід, гілок обговорень та тактичних потоків зв'язку.
Він підтримує зображення аватара, зазначення автора та ролей, часові мітки, підтвердження доставки, таймери самознищення TTL, цитовані відповіді, переслані повідомлення, реакції та поліморфні вкладення (сітки медіа, осцилограми голосу, аудіо, круглі відеоповідомлення, наліпки, контакти, опитування, попередній перегляд вебсторінок, рахунки та історії).

Статус: **draft** у вебреалізації.

## Використання

Використовуйте `ChatMessage` у діалогових інтерфейсах, каналах телеметрії, стрічках підтримки користувачів і журналах активності.
Не використовуйте `ChatMessage` для загальносистемних сповіщень тривоги; натомість використовуйте [Banner](banner.md) або [Toast](toast.md).
При відображенні від 1 до 3 окремих емодзі `ChatMessage` автоматично перемикається на відображення великих ізольованих емодзі без контейнера повідомлення.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус заокруглення кутів | `0 DU` (прямокутна геометрія Operator; круговий виняток для відеоповідомлень та аватарів). |
| Стандартна рамка | Стандартний контур `0.25 DU` навколо повідомлення та карток вкладень. |
| Акцентна рамка | `0.5 DU` на активних межах, круглих контурах відеоповідомлень та знаках зупинки. |
| Внутрішній відступ | `2 DU` всередині повідомлення (`--op-chat-message-padding`). |
| Розмір аватара | Квадрат `8 DU` (`--op-avatar-default`). |
| Розмір відеоповідомлення | Круглий видошукач діаметром `40 DU`. |
| Розмір наліпки | Окремий обмежувальний блок `35 DU`. |
| Розмір знака зупинки | Симетричний правильний восьмикутник `3.75 DU` із центрованим знаком оклику. |

## Поведінка

* Отримані повідомлення вирівнюються за початком контейнера з тонким фоном поверхні.
* Надіслані повідомлення вирівнюються за кінцем контейнера з піднятим фоном поверхні.
* Послідовні повідомлення одного автора групуються щільніше зі зменшеним інтервалом.
* Згруповані повідомлення не дублюють ім'я відправника та аватар до граничного повідомлення.
* Елементи медіа підтримують накладання спойлерів, які розкриваються після натискання.
* Повідомлення, що зникають за таймером самознищення, відображають зворотний відлік, що пульсує, коли залишається 10 або менше секунд.
* Повідомлення лише з 1-3 емодзі відображаються без рамок і збільшеними без навколишнього повідомлення.
* Інтерактивні опитування оновлюють кількість голосів і відсотки смужок після вибору варіанта.
* Блоки коду з тегом синтаксису містять інтерактивну кнопку копіювання до буфера обміну в один клік.
* Цитовані відповіді мають акцентну ліву смужку та уривок цитованого автора.

## Підкомпоненти

* `DeliveryStatus`: Відображає мікроспінер (`Sending`), одну галочку (`Sent`), подвійну галочку (`Delivered`), акцентну подвійну галочку (`Read`) або восьмикутний знак зупинки (`Failed`).
* `ChatStatusBadge`: Відображає бейджі стану гілки розмови, включаючи бейджі особистої згадки `@`, лічильники непрочитаних, обертовий індикатор синхронізації та позначки закріплення/вимкнення сповіщень.
* `TtlIndicator`: Відображає таймери самознищення із замком шифрування, текстом тривалості та терміновою пульсацією.
* `ReactionsRow`: Відображає фішки реакцій з підрахунком і станом вибору, а також необов'язкову кнопку додавання реакції.
* `EmojiText`: Відображає текст, замінюючи короткі коди власних емодзі високоякісною графікою від застосунку.
* `IsolatedEmojiView`: Відображає від 1 до 3 ізольованих емодзі у великому розмірі з плаваючою міткою часу.

### Рядки

`ChatMessage` не містить жорстко закодованого видимого тексту для користувача.
Усі текстові мітки, заголовки та уривки передаються через властивості.
Вбудовані службові мітки (`edited`, `COPIED`, `SPOILER`, `PAID`) можна налаштувати через властивості застосунку або власні слоти.

### Піктограми

`ChatMessage` використовує піктограми Material Symbols Sharp з `operator_ui_tokens::icons`:
* `CHECK` для статусу відправлення, прочитаної подвійної галочки та підтвердження копіювання коду.
* `LOCK` для зашифрованих бейджів TTL самознищення.
* `REFRESH` для індикаторів синхронізації розмови.
* `ADD` для додавання реакцій емодзі.
* `CONTENT_COPY` для копіювання вмісту блоку коду.
* `OPEN_IN_NEW` для зовнішніх вебпосилань.

Символи, відсутні в наборі токенів:
Кнопки відтворення/паузи медіа, осцилограми звуку, багатокутник знака зупинки та значки файлів/контактів відображаються за допомогою тактичних геометричних SVG та символів Unicode.

## Доступність

Аватари та декоративні піктограми мають `aria-hidden="true"`.
Інтерактивні фішки реакцій, варіанти опитувань та кнопки дій доступні за допомогою клавіатури з відповідними ролями кнопок та мітками ARIA.
Індикатори стану доставки та таймери TTL мають явну роль `role="status"` та локалізовані описи `aria-label`.
Ділянки тексту під спойлером надають доступну семантику кнопок і можуть бути перемкнуті кліком вказівника або активацією з клавіатури.
