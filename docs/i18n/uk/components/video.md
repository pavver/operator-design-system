# Video

Адаптивна рамка для вбудовування зовнішніх відеопотоків і програвачів.
Зберігає співвідношення сторін за різних розмірів області перегляду екрана.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `Video` для вбудовування відеопотоків, навчальних матеріалів, посібників або моніторів камер спостереження.
Не використовуйте `Video` для локальних статичних зображень; натомість використовуйте [Image](image.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Типове співвідношення | `16 / 9` (`1.7778`). |
| Межі рамки | Заповнює `100%` ширини й висоти контейнера з розрахованим співвідношенням сторін. |

## Поведінка

* Відеоконтейнер використовує CSS `aspect-ratio` для резервування місця й запобігання зсувам компонування під час ініціалізації iframe.
* Коли `src` порожній або `about:blank`, показується видимий плейсхолдер із фоном поверхні, контуром і центрованою піктограмою камери.
* Внутрішній `iframe` безшовно розтягується до меж батьківського елемента, коли завантажено активне джерело.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `src` | сигнал рядка | обов’язковий | URL вбудованого відео. |
| `title` | string | `video.title` | Доступний заголовок iframe. |
| `ratio` | f32 | `16.0 / 9.0` | Пропорційне співвідношення сторін. |
| `max_width` | DU | немає | Максимальна ширина контейнера. |
| `max_height` | DU | немає | Максимальна висота контейнера. |
| `allow` | string | типові дозволи відео | Політика дозволів для медіафункцій. |
| `allow_fullscreen` | bool | `true` | Дозволяє програвачу переходити в повноекранний режим. |
| `class` | string | немає | CSS-класи на кореневому елементі. |
| `style` | string | немає | Інлайн-CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `max_width` | DU | `--op-video-max-width` | `none` |
| `max_height` | DU | `--op-video-max-height` | `none` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-video-background` | `var(--op-surface-subtle)` |
| `--op-video-border` | `var(--op-border)` |
| `--op-video-icon-color` | `var(--op-text-secondary)` |

`class` та `style` застосовуються до кореневого `div`.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `video.title` | `"Embedded video"` |

### Піктограми

`Video` показує піктограму `VIDEOCAM` у плейсхолдері відсутнього з'єднання або порожнього стану.

## Доступність

Вбудований `<iframe>` отримує доступний `title` через проп `title` або переклад `video.title`.
Плейсхолдер порожнього стану позначений декоративним через `aria-hidden="true"`.
