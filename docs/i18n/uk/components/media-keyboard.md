# MediaKeyboard

Уніфікована медіа-клавіатура, що відтворює структуру EmojiView в Android Telegram.
Вона надсилає Емодзі, Стікери та GIF із підтримкою пошуку, мобільної закріпленої панелі та десктопного поповера.

Статус: **draft** на web.

## Застосування

Використовуйте `MediaKeyboard` у полях введення чату, діалогах обміну повідомленнями та формах коментарів.
На комп'ютері компонент плаває над або під полем введення як Popover.
На телефонах він займає нижню область екрана замість екранної клавіатури.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` контурна рамка контейнера. |
| Ширина на комп'ютері | `85 DU` (`--op-media-keyboard-width`). |
| Висота | `70 DU` (`--op-media-keyboard-height`). |

## Поведінка

* Нижня навігаційна смуга плавно перемикає вкладки Емодзі, Стікери та GIF.
* На комп'ютері компонент відкривається прив'язаним до цільового елемента.
* На мобільних пристроях він розтягується на всю ширину внизу екрана.
* Надсилає відповідні дані через події `on_select_emoji`, `on_select_sticker` та `on_select_gif`.
* Додаткова кнопка backspace дозволяє видаляти попередній символ у полі введення.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `on_select_emoji` | `Callback<String>` | немає | Подія вибору емодзі. |
| `on_select_sticker` | `Callback<StickerAttachment>` | немає | Подія вибору стікера. |
| `on_select_gif` | `Callback<GifItem>` | немає | Подія вибору GIF. |
| `on_backspace` | `Option<Callback<()>>` | немає | Дія кнопки видалення символу. |
| `open` | `bool` | `true` | Керування видимістю клавіатури. |
| `on_close` | `Option<Callback<()>>` | немає | Подія закриття клавіатури. |
| `desktop` | `bool` | `true` | Десктопний поповер або закріплена мобільна панель. |
| `anchor` | `Option<Signal<Option<PopoverAnchor>>>` | немає | Координати прив'язки для поповера. |
| `initial_tab` | `Option<MediaKeyboardTab>` | `Emoji` | Початкова активна вкладка. |
| `custom_emojis` | `Option<CustomEmojiMap>` | немає | Реєстр власних емодзі. |
| `sticker_packs` | `Option<Vec<StickerPack>>` | немає | Набори стікерів. |
| `gifs` | `Option<Vec<GifItem>>` | немає | Список анімацій GIF. |
| `width` | `f32` | `85.0` | Ширина на комп'ютері в Design Units. |
| `height` | `f32` | `70.0` | Висота в Design Units. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Налаштування

### Метричні параметри

| Параметр | Змінна CSS | За замовчуванням | Одиниця |
| :--- | :--- | :--- | :--- |
| `width` | `--op-media-keyboard-width` | `85.0` | DU |
| `height` | `--op-media-keyboard-height` | `70.0` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-media-keyboard-bg` | `var(--op-color-surface)` | Фон клавіатури. |
| `--op-media-keyboard-border` | `var(--op-color-border)` | Рамка клавіатури. |
| `--op-media-keyboard-accent` | `var(--op-color-accent)` | Лінія активної вкладки та фокус. |

## Рядки

| Ключ | Англійський текст | Опис |
| :--- | :--- | :--- |
| `media-keyboard.emoji` | `"Emoji"` | Підпис вкладки емодзі. |
| `media-keyboard.stickers` | `"Stickers"` | Підпис вкладки стікерів. |
| `media-keyboard.gifs` | `"GIF"` | Підпис вкладки GIF. |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `media-keyboard.backspace` | `icons::CLOSE` | Піктограма видалення символу. |

## Доступність

* Кнопки перемикання вкладок мають атрибути `role="tab"` та `aria-selected`.
* Контейнер позначено орієнтиром `role="region"` із текстовою міткою.
