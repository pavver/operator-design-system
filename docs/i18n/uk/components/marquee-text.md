# MarqueeText

Однорядковий текст для контейнерів з обмеженими розмірами.
Текст, що не вміщується, повільно прокручується замість обрізання, а повний текст доступний у спливній підказці.

Статус: **чернетка** у вебреалізації.

## Використання

* Назви, заголовки й підписи пристроїв у рядках, заголовках і панелях інструментів з обмеженою шириною.
* Місця, де трикрапка приховала б частину тексту, яка відрізняє елементи.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Ширина | Займає ширину батьківського елемента; ніколи не ширший за нього. |
| Висота | Один рядок застосованого типографічного стилю. |
| Внутрішній відступ | `0 DU`; відступи задає батьківський елемент. |
| Проміжок циклу | `6 DU` між кінцем тексту та його повторним початком. |
| Спливна підказка | Стиль `caption`, фон `surface_alt`, спільна рамка [Popover](popover.md) `0.25 DU` у кольорі `accent`, внутрішні відступи `1 DU` × `2 DU`. |
| Ширина підказки | До `75 DU`; щонайбільше 6 рядків, потім трикрапка. |
| Зміщення підказки | `1.5 DU` від тексту. |

## Поведінка

* Прокручування сторінки чи іншого контейнера поза підказкою закриває її; прокручування всередині підказки — ні.
### Прокручування

1. Текст, що вміщується, ніколи не рухається.
2. Текст, що виходить за межі, залишається нерухомим протягом `2000 ms`, щоб можна було прочитати початок.
3. Потім він лінійно прокручується справа наліво зі швидкістю `7.5 DU` за секунду, доки повторна копія не досягне початкової позиції.
4. Зупиняється на `1200 ms` і повторюється.
5. Обмеження кількості циклів зупиняє текст на початковій позиції після останнього циклу.

Зміна тексту або ширини контейнера перезапускає цикл із нерухомої фази.
За налаштування зменшеного руху текст не прокручується й завершується трикрапкою.

### Спливна підказка

* Із мишею підказка відкривається при наведенні та закривається, коли вказівник виходить за межі.
* На сенсорному екрані довге натискання `500 ms` відкриває її; закривається через `3500 ms` після підняття пальця.
* Дотик до тексту при відкритій підказці або натискання будь-де ще закриває її.
* З'являється над текстом по центру й перевертається вниз, коли зверху бракує місця.
* По горизонталі обмежується областю перегляду.
* Відкривається також для тексту, що вміщується, щоб поведінка була передбачуваною.

### Клік

Клік викликає `on_click`, якщо він не завершує довге натискання або не закриває підказку.
* Підказка з повним текстом є пасивним шаром [Popover](popover.md) у хості оверлеїв.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `text` | string | обов’язковий | Текст. |
| `class` | string | немає | Клас типографіки, наприклад `op-t-row-title`. |
| `initial_delay_ms` | integer | `2000` | Час нерухомості до прокручування. |
| `delay_ms` | integer | `1200` | Пауза між циклами. |
| `velocity` | DU за секунду | `7.5` | Швидкість прокручування. |
| `spacing` | DU | `6` | Проміжок циклу. |
| `iterations` | integer | необмежено | Кількість циклів. |
| `tooltip` | bool | `true` | Вмикає підказку. |
| `tooltip_text` | string | `text` | Вміст підказки. |
| `on_click` | зворотний виклик | немає | Обробник кліку. |

## Доступність

* Допоміжні технології читають текст один раз; повторна копія прихована.
* Підказка має роль `tooltip`.

## Кастомізація

`class` і `style` застосовуються до кореня.
Явні кореневі стилі мають перевагу над метричними пропсами; невстановлені метрики зберігають початковий рендеринг.
Наявний `spacing` зберігає значення в DU та використовує запасне значення CSS, коли не встановлений.
Компонент вимірює проміжок циклу, тому перевизначення CSS також впливають на відстань анімації.
Внутрішнє передавання оверлею копіює публічні змінні підказки в Popover, змонтований через портал; виміряний проміжок підказки керує розташуванням.
`text` і `tooltip_text` — вміст викликача; для їх перекладу використовуйте пошук рядків застосунком.
