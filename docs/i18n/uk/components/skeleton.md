# Skeleton

Форми-плейсхолдери, що зберігають компонування під час завантаження вмісту.

Статус: **reviewed** у вебреалізації.

## Використання

* Списки, картки й подробиці, форма яких відома до надходження даних.
* Використовуйте форму справжнього вмісту, щоб нічого не стрибало після його появи.
* Для очікування коротшого за приблизно `300 ms` натомість нічого не показуйте.

## Геометрія

| Форма | Значення |
| :--- | :--- |
| Рядок тексту | Висота розміру основного шрифту, по центру одного основного рядка; на всю ширину. |
| Кілька рядків | Проміжок `1 DU`; останній рядок має ширину 60%. |
| Блок | Задані ширина й висота в DU. |
| Коло | Заданий розмір; лише для плейсхолдерів аватарів, круглий виняток [Avatar](avatar.md). |

Кути `0 DU`, крім кола.

## Рух

* М'яке підсвічування з `pressed` проходить поверх `surface_alt` раз на `skeleton_lap` (`1500 ms`), лінійно.
* За налаштування зменшеного руху форми є статичними `surface_alt`.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `width` | DU | на всю ширину | Ширина. |
| `height` | DU | один рядок тексту | Висота. |
| `lines` | integer | `1` | Кількість рядків тексту. |
| `circle` | bool | `false` | Кругла форма. |
| `gap` | DU | `1` | Проміжок між рядками. |
| `text_height` | TU | `type_body_size` | Висота смуги текстового плейсхолдера. |
| `text_line_height` | TU | `type_body_line` | Міжрядковий інтервал текстового плейсхолдера. |
| `label` | string | `skeleton.loading` | Доступна назва. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `width` | DU | `--op-skeleton-width` | `100%` |
| `height` | DU | `--op-skeleton-height` | `auto` |
| `gap` | DU | `--op-skeleton-gap` | `pad_tight` (`1 DU`) |
| `text_height` | TU | `--op-skeleton-text-height` | `type_body_size` |
| `text_line_height` | TU | `--op-skeleton-text-line-height` | `type_body_line` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-skeleton-background` | `surface_alt` |
| `--op-skeleton-shimmer` | `pressed` |

`class` і `style` застосовуються до кореня.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `skeleton.loading` | `Loading` |

## Доступність

Групу позначено зайнятою з назвою «Loading».
