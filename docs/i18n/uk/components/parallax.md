# Parallax

Візуальний банер, фонове зображення якого зміщується з меншою швидкістю за прокручування сторінки.

Статус: **draft** у вебреалізації.

## Використання

Використовуйте Parallax для додання глибини шапкам сторінок, головним банерам чи презентаційним блокам.
Компонент автоматично відстежує прокручування сторінки та вимикає рух, якщо користувач обрав зменшення анімацій.

## Геометрія

| Властивість | Типове значення | Змінна |
| :--- | :--- | :--- |
| Висота | `75 DU` | `--op-parallax-height` |

## Поведінка

* Фонове зображення рухається вертикально повільніше за швидкість прокручування згідно зі встановленим коефіцієнтом швидкості.
* Якщо у медіазапитах увімкнено `prefers-reduced-motion`, ефект паралакса вимикається, а зображення залишається по центру.
* Вкладений дочірній вміст накладається поверх фону та прокручується природно.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `src` | сигнал рядка | обов’язковий | Посилання або data URI фонового зображення. |
| `alt` | рядок | немає | Альтернативний текст для зображення. |
| `height` | метрика DU | `75 DU` | Висота контейнера паралакса. |
| `speed` | сигнал f32 | `0.5` | Коефіцієнт швидкості від 0.0 до 1.0. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-parallax-height` | `75 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-parallax-background` | `surface_alt` |

## Доступність

* Зміщення паралакса автоматично вимикається за наявності параметра `(prefers-reduced-motion: reduce)`.
* Фонове зображення підтримує опційний опис `alt`.
