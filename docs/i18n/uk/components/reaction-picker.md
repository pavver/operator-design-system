# ReactionPicker

Тактичний вибір реакцій зі швидкою панеллю та розгортуваним діалогом категорій.
Він забезпечує швидкі реакції в один дотик та повноцінне модальне вікно з категоріями.

Статус: **draft** на web.

## Застосування

Використовуйте `ReactionPicker` у повідомленнях чату, публікаціях стрічки та формах спільної роботи.
Хост-застосунок передає швидку смужку реакцій та структуровані розділи категорій.
Натискання швидкої реакції відправляє її негайно, а кнопка розгортання відкриває повний список категорій.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` контурна рамка діалогу. |
| Ширина діалогу | `85 DU` (`--op-reaction-picker-width`). |
| Максимальна висота | `110 DU` (`--op-reaction-picker-max-height`). |
| Розмір комірки | `9 DU` (`--op-reaction-picker-cell-size`). |

## Поведінка

* Натискання швидкої реакції викликає `on_select` без відкриття діалогу.
* Кнопка розгортання перемикає відображення повного діалогу категорій.
* У діалозі вкладки перемикають набори реакцій, передані застосунком.
* Вибір реакції в діалозі викликає `on_select` та автоматично закриває його.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `on_select` | `Callback<String>` | немає | Подія вибору символу реакції. |
| `quick_reactions` | `Option<Vec<String>>` | немає | Швидкі реакції від застосунку. |
| `categories` | `Option<Vec<ReactionSection>>` | немає | Розділи категорій реакцій від застосунку. |
| `show_quick_bar` | `bool` | `true` | Чи відображати рядок швидких реакцій. |
| `open` | `bool` | `false` | Керує видимістю повного діалогу. |
| `on_close` | `Callback<()>` | немає | Подія закриття діалогу. |
| `width` | `f32` | `85.0` | Ширина діалогу в Design Units. |
| `max_height` | `f32` | `110.0` | Максимальна висота діалогу в Design Units. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Налаштування

### Метричні параметри

| Параметр | Змінна CSS | За замовчуванням | Одиниця |
| :--- | :--- | :--- | :--- |
| `width` | `--op-reaction-picker-width` | `85.0` | DU |
| `max_height` | `--op-reaction-picker-max-height` | `110.0` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-reaction-picker-bg` | `var(--op-surface)` | Фон діалогу. |
| `--op-reaction-picker-border` | `var(--op-border)` | Рамка діалогу. |
| `--op-reaction-picker-accent` | `var(--op-accent)` | Акцентна рамка та виділення. |

## Рядки

| Ключ | Англійський текст | Опис |
| :--- | :--- | :--- |
| `reaction-picker.title` | `"SELECT REACTION"` | Заголовок модального діалогу. |
| `reaction-picker.quick-reactions` | `"Quick reactions"` | Доступна назва панелі швидких реакцій. |
| `reaction-picker.more` | `"More reactions"` | Доступна назва кнопки розгортання. |
| `reaction-picker.close` | `"Close"` | Доступна назва кнопки закриття. |
| `reaction-picker.empty` | `"No reactions available"` | Повідомлення про відсутність реакцій. |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `reaction-picker.close-icon` | `icons::CLOSE` | Піктограма кнопки закриття. |
| `reaction-picker.expand-icon` | `icons::ADD` | Піктограма кнопки розгортання. |

## Доступність

* Кнопки швидких реакцій та комірки діалогу мають доступні підписи емодзі через `aria-label`.
* Повний діалог категорій має атрибути `role="dialog"` та `aria-modal="true"`.
