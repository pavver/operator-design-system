# ReactionPicker

Тактичний компонент вибору реакцій для чатів, сповіщень та каналів зворотного зв'язку.
Він поєднує компактну панель швидких реакцій з розгортуваним повнорозмірним діалогом за категоріями.

Статус: **draft** на web.

## Застосування

Використовуйте `ReactionPicker` у стрічках повідомлень, спливаючих меню дій над повідомленнями та панелях реакцій.
Користувачі можуть обрати популярну реакцію зі швидкої смуги або розгорнути повний діалог.
Категорії розділяють реакції на Топ, Емоції, Жести, Символи та Тактичні об'єкти.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` стандартна товщина контуру. |
| Ширина діалогу | `85 DU` (`--op-reaction-picker-width`). |
| Максимальна висота діалогу | `110 DU` (`--op-reaction-picker-max-height`). |
| Розмір комірки емодзі | `9 DU` (`--op-reaction-picker-cell-size`). |

## Поведінка

* Клік на емодзі у швидкій панелі або в діалозі вибирає реакцію через `on_select`.
* Кнопка '+' у швидкій панелі відкриває повний діалог реакцій за категоріями.
* Перемикання вкладок категорій оновлює сітку для відповідної групи.
* Клік поза діалогом або натискання кнопки закриття приховує його.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `on_select` | `Callback<String>` | немає | Подія вибору емодзі. |
| `quick_reactions` | `Option<Vec<String>>` | `[👍, 👎, ❤️, 🔥, 👏, 🎉, ⚡]` | Емодзі для швидкої панелі. |
| `show_quick_bar` | `bool` | `true` | Відображення панелі швидких реакцій. |
| `open` | `bool` | `false` | Керування видимістю діалогу. |
| `on_close` | `Callback<()>` | немає | Подія закриття діалогу. |
| `width` | `f32` | `85.0` | Ширина діалогу в Design Units. |
| `max_height` | `f32` | `110.0` | Максимальна висота діалогу в Design Units. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

| :--- | :--- | :--- | :--- |
| `width` | `--op-reaction-picker-width` | `85.0` | DU |
| `max_height` | `--op-reaction-picker-max-height` | `110.0` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-reaction-picker-bg` | `var(--op-color-surface)` | Фон діалогу. |
| `--op-reaction-picker-border` | `var(--op-color-border)` | Рамка діалогу. |
| `--op-reaction-picker-accent` | `var(--op-color-accent)` | Акцентна рамка та підсвічування. |

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `reaction-picker.close` | `icons::CLOSE` | Піктограма закриття. |
| `reaction-picker.expand` | `icons::ADD` | Піктограма розгортання повної панелі. |

## Доступність

* Кнопки швидкого вибору та сітки мають доступні назви через `aria-label`.
* Повний діалог категорій позначено атрибутами `role="dialog"` та `aria-modal="true"`.
