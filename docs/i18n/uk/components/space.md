# Space

Гнучкий спейсер, що розширюється, заповнюючи доступний простір у flex-розмітці.
Він розсуває сусідні елементи вздовж головної осі.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `Space` між елементами керування на панелі інструментів, у заголовку чи рядку дій картки, щоб відокремити початкові та кінцеві елементи.
Не використовуйте `Space`, коли для однакових відступів краще підходить `gap` на батьківському контейнері.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Типовий розмір | Мінімальний розмір `0 DU` з `flex-grow: 1`. |
| Межі | Розтягується, займаючи залишковий простір уздовж напрямку flex. |

## Поведінка

* `Space` не має вмісту та прихований від допоміжних технологій (`aria-hidden="true"`).
* Він адаптується як до flex-рядків, так і до flex-стовпців.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `min_width` | f32 (DU) | немає | Резервування мінімальної ширини в DU. |
| `min_height` | f32 (DU) | немає | Резервування мінімальної висоти в DU. |
| `class` | string | немає | Класи CSS на кореневому елементі. |
| `style` | string | немає | Інлайн-CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `min_width` | DU | `--op-space-min-width` | `0` |
| `min_height` | DU | `--op-space-min-height` | `0` |

`class` та `style` застосовуються до кореневого `div`.

### Рядки

`Space` не відображає призначених для користувача чи доступних текстових рядків.

### Піктограми

`Space` не використовує піктограм.

## Доступність

`Space` є суто візуальним і позначений як `aria-hidden="true"`.
