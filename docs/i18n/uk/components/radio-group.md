# RadioGroup

Одиничний вибір із короткого списку варіантів, усі з яких видимі одночасно.

Статус: **reviewed** у вебреалізації.

## Використання

* Від двох до шести взаємовиключних варіантів, кожен із власним підписом.
* Для двох або трьох коротких варіантів у рядку [SegmentedControl](segmented-control.md) компактніший.
* Для довгих списків використовуйте [DropdownMenu](dropdown-menu.md) або [Combobox](combobox.md).

## Геометрія

Круглі позначка та крапка — дозволений виняток із прямокутної геометрії, як капсула [Switch](switch.md).
Коло є універсальним знаком одиничного вибору й дозволяє відразу відрізнити радіокнопку від квадратного [Checkbox](checkbox.md).

| Властивість | Значення |
| :--- | :--- |
| Висота рядка | Щонайменше `10 DU`. |
| Позначка | Коло `5 DU` із контуром стану, що повторює коло. |
| Крапка | Коло `2.5 DU` у кольорі `accent` по центру у вибраному стані. |
| Проміжок | `2.5 DU` між позначкою та підписом. |
| Горизонтальне компонування | Рядки переносяться з проміжком `4 DU` між варіантами. |

## Стани

| Стан | Вигляд |
| :--- | :--- |
| Невибрана | Контур `border`, без крапки. |
| Вибрана | `accent` із непрозорістю 15%, контур `accent` із товщиною штриха 1.5x, крапка `accent`; підпис зберігає свій колір, як у [Checkbox](checkbox.md). |
| Натиснута | Контур `border_strong`. |
| Очікування | Сегмент очікування на контурі цільового варіанта; [спінер із затримкою](../foundations/states.md#delayed-spinner) у його позначці. |
| Успіх / помилка | Пульсація результату на цільовій позначці протягом `result_hold` (`800 ms`). |
| Вимкнена | Кольори вимкненого стану, без взаємодії. |

## Поведінка

* Без асинхронного обробника вибір змінюється негайно.
* З асинхронним обробником значення фіксується лише після успіху, як у [AsyncSwitch](switch.md):
  1. Цільова позначка показує сегмент очікування, а згодом [спінер із затримкою](../foundations/states.md#delayed-spinner); попередній варіант залишається вибраним.
  2. У разі успіху крапка переходить до цільового варіанта, який пульсує зеленим.
  3. У разі помилки крапка залишається на місці, цільовий варіант пульсує червоним.
* Поки запит очікує завершення, уся група ігнорує нові вибори.
* Зворотний зв'язок результату не блокує нові вибори; новіший запит замінює попередній таймер результату.
* Вибір уже вибраного варіанта нічого не робить.
* Крапка з'являється, масштабуючись від 0 до повного розміру за `150 ms`.

## Доступність

* `radiogroup` із варіантами `radio` та `aria-checked`.
* Одна зупинка Tab: вибраний варіант або перший, коли нічого не вибрано.
* Клавіші зі стрілками переходять до наступного або попереднього варіанта й вибирають його.

## Кастомізація

`class` та `style` застосовуються до кореневого елемента.
Метричні пропси приймають реактивні значення DU або TU; невстановлені пропси зберігають змінну CSS або її точний запасний варіант із дизайн-системи.
`style` викликача додається після оголошень метрик і має вищий пріоритет.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `column_gap` | DU | `--op-radio-group-column-gap` | `var(--op-dim-margin-screen)` |
| `gap` | DU | `--op-radio-group-gap` | `var(--op-dim-pad-content)` |
| `height` | DU | `--op-radio-group-height` | `var(--op-dim-row-standard)` |
| `padding_x` | DU | `--op-radio-group-padding-x` | `var(--op-dim-pad-tight)` |
| `size` | DU | `--op-radio-group-size` | `calc(var(--op-du) * 5)` |
| `dot_size` | DU | `--op-radio-group-dot-size` | `var(--op-dim-pad-content)` |
