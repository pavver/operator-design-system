# SearchField

Однорядкове поле для фільтрування та пошуку.
Воно передає запит після короткої паузи, тому результати оновлюються під час введення без окремого запиту на кожне натискання клавіші.

Статус: **reviewed** у вебреалізації.

## Геометрія

Поле має форму [TextField](text-field.md) зі слотом на початку:

| Властивість | Значення |
| :--- | :--- |
| Висота | `10 DU`. |
| Початковий слот | Квадрат `10 DU` з піктограмою пошуку `6 DU` (`icon_large`) у кольорі `text_secondary`; у фокусі — `accent`; розмір спінера завантаження — `4.5 DU`. |
| Кнопка очищення | Квадрат `10 DU` у кінці поля, видимий лише тоді, коли в полі є текст. |

## Поведінка

* Запит передається через `search_debounce` (`300 ms`) після останньої зміни.
* Enter передає запит негайно.
* Очищення спорожнює поле, передає порожній запит і залишає фокус у полі.
* Escape очищає непорожнє поле.
* Коли встановлено `pending`, спінер кольору `pending` замінює піктограму пошуку.
* Сам пошук виконує код, що використовує компонент; поле нічого не фільтрує.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал рядка | обов’язкова | Пошуковий запит. |
| `placeholder` | рядок | `"Search"` | Підказка. |
| `on_search` | зворотний виклик `(string)` | немає | Отримує запит. |
| `debounce_ms` | ціле число | `300` | Пауза перед передаванням запиту. |
| `pending` | bool | `false` | Показує спінер. |
| `enabled` | bool | `true` | Дозволяє введення. |
| `label` | рядок | `"Search"` | Доступна назва. |
| `clear_label` | сигнал рядка | `"Clear search"` | Доступна назва кнопки очищення (передайте перекладений текст). |

## Доступність

Поле є орієнтиром `search`, а елемент введення має тип `search`.
