# SearchField

Однорядкове поле введення для фільтрації та пошуку.
Поле передає пошуковий запит після короткої паузи, тому результати оновлюються слідом за введенням без окремого запиту на кожне натискання клавіші.

Статус: **reviewed** у вебреалізації.

## Геометрія

Поле має форму [TextField](text-field.md) із початковим слотом:

| Властивість | Значення |
| :--- | :--- |
| Висота | `10 DU`. |
| Початковий слот | Квадрат `10 DU` з піктограмою пошуку `6 DU` (`icon_large`) у кольорі `text_secondary`; `accent` під час фокусу. Спінер завантаження має розмір `4.5 DU`. |
| Кнопка очищення | Квадрат `10 DU` наприкінці, показується, лише коли поле містить текст. |

## Поведінка

* Запит передається через `search_debounce` (`300 ms`) після останньої зміни.
* Enter негайно передає запит.
* Очищення спорожнює поле, передає порожній запит і зберігає фокус у полі.
* Escape очищає непорожнє поле.
* Доки встановлено `pending`, піктограму пошуку замінює спінер у кольорі `pending`.
* Сам пошук є завданням викликача; поле ніколи нічого не фільтрує.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал рядка | обов’язковий | Запит. |
| `placeholder` | string | `search-field.placeholder` | Підказка всередині порожнього поля. |
| `on_search` | зворотний виклик `(string)` | немає | Отримує запит. |
| `debounce_ms` | integer | `300` | Пауза перед передаванням запиту. |
| `pending` | bool | `false` | Показує спінер. |
| `enabled` | bool | `true` | Вмикає введення. |
| `label` | string | немає | Видимий підпис над полем; також є доступною назвою. |
| `aria_label` | string | `search-field.label` | Доступна назва, коли немає видимого підпису. |
| `clear_label` | string | `search-field.clear` | Доступна назва кнопки очищення. |
| `hint` | string | немає | Допоміжний текст під полем. |
| `error` | string | немає | Текст помилки під полем; замінює підказку та малює контур помилки. |
| `variant` | `outlined` або `borderless` | `outlined` | Вигляд поля, див. [Field](field.md). |
| `icon`, `clear_icon` | icon | `search-field.search`, `field.clear` | Перевизначення піктограм. |

## Кастомізація

SearchField побудовано на [Field](field.md) і має ті самі хуки.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-field-height` | `row_standard` (`10 DU`) |
| `padding_x` | DU | `--op-field-padding-x` | `pad_card` |
| `slot_size` | DU | `--op-field-slot-size` | `row_standard`; ширина слота піктограми пошуку та кнопки очищення |
| `gap` | DU | `--op-field-gap` | `gap_micro`; між підписом, полем, підказкою та зовнішніми слотами |
| `font_size` | TU | `--op-field-font-size` | `type_body_size` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-field-background` | `surface` |
| `--op-field-text` | `text_primary` |

| Слот | Розташування |
| :--- | :--- |
| `prepend` | Замінює піктограму пошуку. |
| `append` | Всередині поля, перед кнопкою очищення. |
| `before`, `after` | Зовні поля. |

`class` та `style` застосовуються до кореня (підпис, поле та підказка).

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `search-field.placeholder` | `Search` |
| `search-field.label` | `Search` |
| `search-field.clear` | `Clear search` |

### Піктограми

| Ключ | Типове значення |
| :--- | :--- |
| `search-field.search` | `search` |
| `field.clear` | `close` |

## Доступність

Поле є орієнтиром `search`, а елемент введення має тип `search`.
