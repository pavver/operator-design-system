# PopupEdit

Редагування значення на місці в прикріпленому спливному шарі з асинхронним збереженням.
За потреби замінює статичний текст спливним редактором із діями збереження та скасування.

Статус: **чернетка** у вебреалізації.

## Використання

* Редагування комірки таблиці на місці або зміна полів профілю.
* Швидка зміна властивостей без переходу на іншу сторінку.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Ширина | `72 DU`. |
| Внутрішній відступ | `pad_card` (`3 DU`). |
| Проміжок | `gap_small` (`2 DU`). |
| Радіус заокруглення кутів | `0 DU`. |

## Поведінка

* Клік на елементі відкриття відкриває прикріплений спливний діалог із [TextField](text-field.md).
* Після відкриття поле введення автоматично отримує фокус.
* Надсилання форми або клік на збереженні запускає перевірку й асинхронну дію збереження.
* У разі успіху значення оновлюється, а спливний шар закривається.
* У разі помилки показується повідомлення про помилку, а чернеткове значення зберігається.
* Escape або клік зовні скасовує зміни й закриває спливний шар.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал рядка | обов’язковий | Цільове значення для редагування. |
| `on_save` | `AsyncAction<String>` | немає | Асинхронна дія, що виконується при збереженні. |
| `on_change` | зворотний виклик `(String)` | немає | Сповіщає про підтверджені оновлення значення. |
| `validate` | зворотний виклик `(String -> Option<String>)` | немає | Синхронний зворотний виклик перевірки, що повертає текст помилки. |
| `enabled` | bool | `true` | Вмикає взаємодію редагування. |
| `label` | string | `popup-edit.label` | Доступна назва діалогу редактора. |
| `save_label` | string | `popup-edit.save` | Підпис кнопки збереження. |
| `cancel_label` | string | `popup-edit.cancel` | Підпис кнопки скасування. |
| `content` | `Slot` | немає | Власний вигляд елемента відкриття замість звичайного тексту значення. |
| `header` | `Slot` | немає | Вміст над полем введення у спливному шарі. |
| `footer` | `Slot` | немає | Вміст під діями у спливному шарі. |
| `width` | метрика DU | `72 DU` | Ширина панелі спливного шару. |
| `padding` | метрика DU | `pad_card` | Внутрішній відступ панелі. |
| `gap` | метрика DU | `gap_small` | Проміжки всередині форми. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `width` | DU | `--op-popup-edit-width` | `72 DU` |
| `padding` | DU | `--op-popup-edit-padding` | `pad_card` (`3 DU`) |
| `gap` | DU | `--op-popup-edit-gap` | `gap_small` (`2 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-popup-edit-background` | `surface` |
| `--op-popup-edit-text` | `inherit` |
| `--op-popup-edit-accent` | `accent` |

| Слот | Розташування |
| :--- | :--- |
| `content` | Власний вміст усередині кнопки відкриття. |
| `header` | Верхня частина панелі редагування. |
| `footer` | Нижня частина панелі редагування. |

`class` і `style` застосовуються до кореневої обгортки.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `popup-edit.label` | `Edit value` |
| `popup-edit.save` | `Save` |
| `popup-edit.cancel` | `Cancel` |

### Піктограми

PopupEdit не визначає вбудованих піктограм.

## Доступність

Кнопка відкриття встановлює `aria-haspopup="dialog"` і `aria-expanded`.
Відкрита панель поводиться як модальний діалог і утримує фокус у межах текстового поля та кнопок.
Escape коректно закриває сеанс редагування.
