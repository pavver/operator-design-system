# LoadingBar

Тонка анімована смуга перебігу, прикріплена до краю контейнера або області перегляду сторінки.
Керується сигналом для відображення асинхронної фонової активності рівня сторінки.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `LoadingBar` угорі макета застосунку, навігаційної оболонки або контейнера картки, щоб сигналізувати про фонове отримання даних, не перериваючи дій користувача.
Не використовуйте `LoadingBar`, коли взаємодія з користувачем має бути заблокована; натомість використовуйте [LoadingOverlay](loading-overlay.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Товщина | `0.5 DU` (`--op-loading-bar-thickness`). |
| Позиція | Прикріплена до краю `top` або `bottom` найближчого позиціонованого предка. |

## Поведінка

* Плавно з’являється, коли `pending` стає `true`.
* Відображає безперервний лінійний градієнт розгортки вздовж смуги.
* Плавно зникає, коли `pending` стає `false`.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `pending` | signal bool | обов’язковий | Керує тим, чи є смуга активною та видимою. |
| `position` | LoadingBarPosition | `Top` | Край розміщення (`Top` або `Bottom`). |
| `thickness` | DU | `0.5 DU` | Товщина смуги в DU. |
| `label` | string | `loading-bar.loading` | Доступний опис. |
| `class` | string | немає | CSS-класи на кореневому елементі. |
| `style` | string | немає | Інлайн-CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `thickness` | DU | `--op-loading-bar-thickness` | `0.5 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-loading-bar-color` | `var(--op-accent)` |

`class` та `style` застосовуються до кореневого `div`.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `loading-bar.loading` | `"Loading page"` |

### Піктограми

`LoadingBar` не використовує піктограм.

## Доступність

`LoadingBar` має `role="progressbar"` з `aria-busy="true"` та доступну мітку.
Він не перехоплює кліки вказівника (`pointer-events: none`).
