# InfiniteScroll

Поступовий завантажувач вмісту, що спрацьовує при вході нижньої контрольної мітки у вікно перегляду.

Статус: **draft** у вебреалізації.

## Використання

Використовуйте InfiniteScroll для поступового завантаження неперервних потоків даних, таких як журнал подій чи результати пошуку.
Компонент завчасно надсилає запити до того, як користувач дійде до кінця сторінки, та містить готові стани очікування та повторної спроби.

## Геометрія

| Властивість | Типове значення | Змінна |
| :--- | :--- | :--- |
| Відступ випередження | `10 DU` | `--op-infinite-scroll-offset` |
| Висота рядка індикатора | `12 DU` | `--op-infinite-scroll-pending-height` |

## Поведінка

* Непомітна мітка спостерігається за допомогою `IntersectionObserver`.
* Коли мітка наближається до вікна перегляду на відстань випередження, викликається `on_load`.
* Поки `loading` активний, опитування призупиняється та показується рядок завантаження.
* Якщо встановлено `error`, показується рядок помилки з кнопкою повтору.
* Коли `has_more` стає false, мітка видаляється.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `on_load` | зворотний виклик `()` | обов’язковий | Викликається для завантаження наступної порції елементів. |
| `has_more` | сигнал bool | `true` | Показує, чи залишилися ще елементи для завантаження. |
| `loading` | сигнал bool | `false` | Активний під час виконання асинхронного завантаження. |
| `error` | сигнал `Option<String>` | `None` | Повідомлення про помилку для рядка помилки. |
| `on_retry` | зворотний виклик `()` | немає | Викликається при натисканні кнопки повтору. |
| `offset` | метрика DU | `10 DU` | Відстань у DU від низу до початку завантаження. |
| `pending_height` | метрика DU | `12 DU` | Висота рядка індикатора завантаження або помилки. |
| `loading_label` | рядок | `infinite-scroll.loading` | Текст під час завантаження. |
| `error_label` | рядок | `infinite-scroll.error` | Текст у разі помилки. |
| `retry_label` | рядок | `infinite-scroll.retry` | Текст кнопки повторної спроби. |
| `loading_slot` | слот | немає | Власний слот замість стандартного індикатора. |
| `error_slot` | слот | немає | Власний слот замість стандартного блоку помилки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `offset` | DU | `--op-infinite-scroll-offset` | `10 DU` |
| `pending_height` | DU | `--op-infinite-scroll-pending-height` | `12 DU` |

## Тексти

| Ключ | Типовий текст (uk) | Опис |
| :--- | :--- | :--- |
| `infinite-scroll.loading` | `Завантаження ще…` | Повідомлення під час очікування даних. |
| `infinite-scroll.error` | `Не вдалося завантажити` | Типовий текст повідомлення про помилку. |
| `infinite-scroll.retry` | `Повторити` | Текст кнопки повтору. |

## Піктограми

| Ключ | Типове значення | Опис |
| :--- | :--- | :--- |
| `icons::ERROR` | Material error | Піктограма поруч із помилкою. |
| `icons::REFRESH` | Material refresh | Піктограма всередині кнопки повтору. |

## Доступність

* Рядок завантаження використовує `role="status"` та `aria-busy="true"`.
* Рядок помилки використовує `role="alert"`.
