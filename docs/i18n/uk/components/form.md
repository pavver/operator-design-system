# Form

Контейнер перевірки форми через зареєстровані межі FormField.
Групує поля, координує перевірку під час надсилання або втрати фокусу, фокусує перше некоректне поле та керує циклами скидання.

Статус: **чернетка** у вебреалізації.

## Використання

* Надсилання введених даних з узгодженою перевіркою кількох полів.
* Скидання стану форми й автоматичне фокусування полів із помилками.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Проміжок | `gap_small` (`2 DU`). |
| Внутрішній відступ | `pad_card` (`3 DU`). |
| Радіус заокруглення кутів | `0 DU`. |

## Поведінка

* Надсилання форми послідовно перевіряє всі зареєстровані дочірні поля.
* Якщо перевірка не пройшла, надсилання зупиняється, а фокус переходить до першого некоректного поля.
* Якщо дані коректні, викликається асинхронна дія `on_submit`, а форма переходить у стан `Pending`.
* Скидання форми очищує помилки й відновлює початкові значення полів.
* Під час очікування весь набір полів позначається `inert` і вимикається.

## API

### Form

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `children` | `Children` | обов’язковий | Дочірні елементи, що містять поля форми. |
| `on_submit` | `AsyncAction` | немає | Асинхронний обробник надсилання. |
| `on_reset` | зворотний виклик `()` | немає | Зворотний виклик події скидання. |
| `on_validation` | зворотний виклик `(bool)` | немає | Передає загальний результат перевірки. |
| `enabled` | bool | `true` | Вмикає надсилання форми та введення. |
| `label` | string | `form.label` | Доступний підпис форми. |
| `submit_label` | string | `form.submit` | Типовий текст кнопки надсилання. |
| `reset_label` | string | `form.reset` | Типовий текст кнопки скидання. |
| `header` | `Slot` | немає | Слот вмісту заголовка. |
| `actions` | `Slot` | немає | Слот власних кнопок дій замість типових кнопок. |
| `footer` | `Slot` | немає | Слот вмісту нижньої частини. |
| `gap` | метрика DU | `gap_small` | Проміжок між полями форми та діями. |
| `padding` | метрика DU | `pad_card` | Внутрішній відступ форми. |
| `class`, `style` | string | немає | Кореневі хуки. |

### FormField

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал рядка | обов’язковий | Сигнал значення поля. |
| `rules` | `Vec<ValidationRule>` | обов’язковий | Список функцій перевірки, що повертають `Option<String>`. |
| `children` | `Children` | обов’язковий | Обгорнутий елемент введення. |
| `error` | `Option<RwSignal<Option<String>>>` | внутрішній | Сигнал тексту помилки поля. |
| `enabled` | bool | `true` | Вмикає межу поля. |
| `gap` | метрика DU | `gap_small` | Внутрішні проміжки. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `gap` | DU | `--op-form-gap` | `gap_small` (`2 DU`) |
| `padding` | DU | `--op-form-padding` | `pad_card` (`3 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-form-text` | `text_primary` |
| `--op-form-background` | `surface` |
| `--op-form-border` | `border` |
| `--op-form-error` | `error` |
| `--op-form-submit-background` | `accent` |
| `--op-form-submit-text` | `on_accent` |
| `--op-form-submit-border` | `accent` |
| `--op-form-reset-background` | `surface` |
| `--op-form-reset-text` | `text_secondary` |

| Слот | Розташування |
| :--- | :--- |
| `header` | Над областю полів. |
| `actions` | Область рядка кнопок. |
| `footer` | Під областю дій. |

`class` і `style` застосовуються до кореневого елемента форми.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `form.label` | `Form` |
| `form.submit` | `Submit` |
| `form.reset` | `Reset` |

### Піктограми

Form не визначає вбудованих піктограм.

## Доступність

Форма використовує нативну семантику `<form>` з `novalidate`, щоб уникнути конфліктів перевірки браузера.
Під час асинхронного надсилання елементи fieldset отримують `disabled` і `inert`.
Загальні повідомлення про помилки передаються через `role="status"`.
