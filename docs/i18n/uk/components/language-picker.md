# LanguagePicker

Варіант Combobox для вибору мови інтерфейсу.

Статус: **чернетка** у вебреалізації.

## Використання

* Вибір поточної мови інтерфейсу застосунку.
* Фільтрація підтримуваних мов за самоназвою, англійською назвою або стандартним кодом BCP 47.
* Представлення мов із впізнаваною графікою прапорів країн і стандартизованими подвійними підписами.

## Геометрія

* Оболонка введення — це [Field](field.md) із кінцевою піктограмою `arrow_drop_down`.
* Прапор вибраної мови показується на початку поля в початковому слоті prepend, коли `show_flags` має значення true.
* Кожен варіант у списку показує піктограму прапора, після якої йде підпис мови.
* Прапор типово відображається у квадратному контейнері завширшки `6 DU` і заввишки `4 DU`.
* Контейнер прапора має прямі кути з радіусом `0 DU`.
* Усередині контейнера прапора малюється внутрішня межа `0.25 DU` з наявним токеном `--op-border`, щоб білі смуги залишалися видимими на світлих поверхнях.
* Кольори прапорів є справжніми кольорами прапорів (це вміст, а не токени інтерфейсу): це навмисний виняток для вмісту з правил токенів дизайну.

## Поведінка

* Введення в полі фільтрує список за входженням підрядка без урахування регістру в самоназві, англійській назві або коді BCP 47.
* Варіанти типово мають формат «Самоназва (англійська назва)», наприклад «Українська (Ukrainian)» або «Deutsch (German)».
* Коли самоназва й англійська назва збігаються (як-от «English»), показується лише одна назва без зайвих дужок.
* Навігація варіантами клавішами зі стрілками циклічна й прокручує активний елемент у видиму область.
* Enter або клік фіксує код BCP 47 вибраної мови.
* Втрата фокусу фіксує точні збіги або повертає незафіксований текст до попередньо вибраної мови.

## Опції

Варіант мови представлено типом `LanguageOption`:

| Поле | Тип | Опис |
| :--- | :--- | :--- |
| `code` | `String` | Код мови BCP 47 (наприклад, `uk`, `en`, `de`). |
| `native` | `String` | Самоназва мови. |
| `english` | `String` | Англійська назва мови. |
| `flag` | `Option<Flag>` | Пов'язане представлення прапора. |

Вбудовані мови доступні через перелік `Language` (`Language::En`, `Language::Uk` тощо) і перетворюються безпосередньо через `LanguageOption::from(Language)`.
Викликачі також можуть створювати цілком власні варіанти мов через `LanguageOption::new(code, native, english)`.

## Прапори

Прапори можуть бути вбудованими, власною SVG-розміткою або відсутніми:

| Варіант | Опис |
| :--- | :--- |
| `Flag::Builtin(&'static str)` | Вбудований код країни: `UA`, `GB`, `US`, `DE`, `FR`, `ES`, `IT`, `PL`, `PT`, `NL`, `CZ`, `SE`, `JP`, `CN`, `KR`, `TR`. |
| `Flag::Svg(String)` | Вбудована SVG-розмітка, надана застосунком. |
| `Flag::None` | Прибирає піктограму прапора для варіанта. |

Кольори прапорів використовують автентичні кольори кожного національного прапора як графічний вміст замість токенів кольорів теми.

## Доступність

* Елемент введення має `role="combobox"` із `aria-autocomplete="list"`.
* Спливний шар має `role="listbox"`, а кожен елемент — `role="option"`.
* Активний варіант відстежується через стани вибору та фокусу.
* Зображення прапорів позначені `aria-hidden="true"`, щоб читачі екрана озвучували лише описові назви мов.
* Перекладні доступні підписи надаються через `language-picker.label`.

## Кастомізація

`class` і `style` застосовуються до кореня компонента.
Метричні пропси оголошують користувацькі властивості CSS із токенами як запасними значеннями.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `width` | DU | `--op-language-picker-width` | `100%` |
| `flag_width` | DU | `--op-language-picker-flag-width` | `6 DU` |
| `flag_height` | DU | `--op-language-picker-flag-height` | `4 DU` |

Список відкривається в хості оверлеїв, поза коренем компонента, тому його мінімальна ширина є змінною рівня теми: `--op-language-picker-list-min-width` (типово `64 DU`).
Список має щонайменше таку ширину, навіть коли поле компактне, тому назви мов не обрізаються.

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-language-picker-border` | `--op-border` |

| Слот | Розташування |
| :--- | :--- |
| `option` | Із областю видимості `LanguageOption`; замінює типовий рендеринг рядка. |
| `empty` | Замінює повідомлення порожнього стану за відсутності відповідних мов. |
| `before_options` | Усередині списку вибору перед елементами. |
| `after_options` | Усередині списку вибору після елементів. |
| `header` | Над списком вибору. |
| `footer` | Під списком вибору. |
| `prepend` | Усередині поля перед елементом введення. |
| `append` | Усередині поля перед стрілкою списку вибору. |
| `before` | Зовні поля з початкового боку. |
| `after` | Зовні поля з кінцевого боку. |
