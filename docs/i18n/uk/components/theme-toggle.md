# ThemeToggle

Перемикач дня й ночі для світлого та темного режимів.
Сонце ковзає небом із хмарами та під час руху перетворюється на місяць серед зірок.

Статус: **reviewed** у вебреалізації.

Заснований на [Day/Night Toggle](https://codepen.io/jh3y/pen/LYgjpYZ) від Jhey Tompkins, ліцензія MIT.
Контури хмар, кольори неба, сонця й місяця та крива анімації походять з оригіналу.
Анімацію ведмедя та мерехтіння у стані спокою з оригіналу опущено; поки перемикач у спокої, нічого не рухається.
Оригінальний місяць, що ковзає поверх сонця, замінено одним тілом, яке змінює колір.

## Геометрія

Капсульна доріжка та круглий бігунок є дозволеним винятком із прямокутної геометрії.

| Властивість | Значення |
| :--- | :--- |
| Розмір | Типово `17 DU` × `7.5 DU`. |
| Бігунок | Коло діаметром, що дорівнює висоті мінус `1.25 DU`, із відступом `0.625 DU`. |
| Контур | `0.25 DU`, `border` із непрозорістю 50%; `border_strong` при натисканні. |

## Кольори

Ілюстрація використовує окремі токени, однакові в обох режимах:

| Токен | Значення | Частина |
| :--- | :--- | :--- |
| `toggle_day_sky` | `#3893C8` | Денне небо. |
| `toggle_night_sky` | `#1E2333` | Нічне небо. |
| `toggle_sun` | `#F7CA31` | Сонце. |
| `toggle_moon` | `#CAD5DE` | Місяць. |
| `toggle_crater` | `#9EB0C2` | Кратери місяця. |
| `toggle_cloud` | `#FFFFFF` | Передні хмари, непрозорість 95%. |
| `toggle_cloud_back` | `#D9D9D9` | Задні хмари, непрозорість 45%. |
| `toggle_star` | `#FFFFFF` | Зірки та ореоли сонця. |

## Рух

* Усі частини рухаються протягом `450 ms` із `cubic-bezier(0.4, -0.2, 0.4, 1.2)`, із невеликим виходом за кінцеву позицію.
* Колір неба змінюється за `400 ms`.
* Сонце й місяць є одним тілом.
  Під час ковзання його колір змінюється з `toggle_sun` на `toggle_moon`, а кратери проявляються, обидві зміни — за `450 ms` із плавною кривою.
* День у ніч: тіло ковзає праворуч і стає місяцем, ореоли згасають, хмари опускаються та згасають, а сім зірок зростають від `30%` до повного розміру.
* Ніч у день відтворює кожен рух у зворотному напрямку.

## Поведінка

* Клік негайно викликає `on_toggle` із протилежним значенням.
* Перемикач не має асинхронного, вимкненого стану або станів результату.
  Тема є локальним налаштуванням: вона має застосовуватися негайно, а її збереження є фоновим завданням викликача.
  Коли тему не можна змінити, наприклад коли вона слідує системному налаштуванню, приховуйте перемикач замість вимкнення.
* Відгук на натискання: хвиля, обрізана капсулою, та контур `border_strong`.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `dark` | bool | обов’язковий | `true` для ночі. |
| `on_toggle` | зворотний виклик `(bool)` | немає | Викликається з новим значенням; без нього перемикач статичний. |
| `width` | DU | `17` | Ширина. |
| `height` | DU | `7.5` | Висота. |
| `label` | string | `theme-toggle.label` | Доступна назва. |
| `thumb_inset` | реактивний DU | не встановлено | Перевизначає `--op-theme-toggle-thumb-inset`; див. Кастомізація. |
| `star_scale` | реактивний DU | не встановлено | Перевизначає `--op-theme-toggle-star-scale`; див. Кастомізація. |
| `class` | реактивний string | немає | Застосовується до кореневого елемента. |
| `style` | реактивний string | немає | Застосовується до кореневого елемента. |
| `content` | слот | немає | Замінює декоративну сцену; перемикач зберігає доступну назву. |

## Доступність

Елемент керування має роль `switch` і позначений у нічному режимі.

## Кастомізація

`class` та `style` застосовуються до кореневого елемента.
Метричні пропси приймають реактивні значення DU або TU; невстановлені пропси зберігають змінну CSS або її точний запасний варіант із дизайн-системи.
`style` викликача додається після оголошень метрик і має вищий пріоритет.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `width` | DU | `--op-theme-toggle-width` | `calc(var(--op-du) * 17)` |
| `height` | DU | `--op-theme-toggle-height` | `calc(var(--op-du) * 7.5)` |
| `thumb_inset` | DU | `--op-theme-toggle-thumb-inset` | `calc(var(--op-du) * 0.625)` |
| `star_scale` | DU | `--op-theme-toggle-star-scale` | `calc(var(--op-du) * 1)` |

Наявні числові пропси розміру зберігають назви та значення в DU й тепер також приймають реактивні значення.

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-theme-toggle-accent` | `var(--op-accent)` |
| `--op-theme-toggle-border` | `var(--op-border)` |
| `--op-theme-toggle-emphasis-border` | `var(--op-border-strong)` |
| `--op-theme-toggle-cloud` | `var(--op-toggle-cloud)` |
| `--op-theme-toggle-cloud-back` | `var(--op-toggle-cloud-back)` |
| `--op-theme-toggle-crater` | `var(--op-toggle-crater)` |
| `--op-theme-toggle-day-sky` | `var(--op-toggle-day-sky)` |
| `--op-theme-toggle-disabled-border` | `var(--op-disabled-border)` |
| `--op-theme-toggle-moon` | `var(--op-toggle-moon)` |
| `--op-theme-toggle-night-sky` | `var(--op-toggle-night-sky)` |
| `--op-theme-toggle-ripple` | `var(--op-ripple)` |
| `--op-theme-toggle-star` | `var(--op-toggle-star)` |
| `--op-theme-toggle-sun` | `var(--op-toggle-sun)` |
| Слот | Розташування |
| :--- | :--- |
| `content` | Замінює декоративну сцену; перемикач зберігає доступну назву. |

Декоративна сцена слідує за визначеними розмірами кореня, відступом бігунка та масштабом зірок, зокрема за значеннями, успадкованими через CSS.
`star_scale` — масштаб зображення зірки в DU; типове значення — `1 DU`.
