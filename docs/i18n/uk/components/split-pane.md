# SplitPane

Дві панелі з перетягуваним розділювачем, як-от список поруч із подробицями.

Статус: **reviewed** у вебреалізації.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Лінія розділювача | `0.25 DU` у кольорі `border`; `0.5 DU` у кольорі `accent` при наведенні, фокусі та перетягуванні. |
| Зона влучання | `2 DU` поперек лінії. |
| Ручка | `1 DU` × `6 DU` зі смугами `border_strong` посередині лінії. |
| Мінімальний розмір панелі | `min_size` (типово `20 DU`) з кожного боку. |
| Орієнтація | Поруч або одна над одною з `vertical`. |

## Поведінка

* Перетягування розділювача задає частку першої панелі; панелі ніколи не зменшуються нижче `min_size`.
* Коли розділювач у фокусі, клавіші зі стрілками переміщують його на 2%, із Shift — на 10%; Home і End переміщують до меж.
* Подвійний клік або Enter відновлює початкову частку.
* Кожна панель прокручується окремо.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `start` | слот | обов’язковий | Перша панель. |
| `end` | слот | обов’язковий | Друга панель. |
| `ratio` | сигнал float | `0.5` | Частка першої панелі. |
| `vertical` | bool | `false` | Розташовує панелі одна над одною. |
| `min_size` | DU | `20` | Мінімальний розмір панелі. |
| `handle_size` | DU | `gutter` | Розмір зони влучання розділювача. |
| `divider_width` | DU | `border` | Ширина лінії розділювача. |
| `divider_active_width` | DU | `border_thick` | Ширина лінії активного розділювача або при наведенні. |
| `grip_width` | DU | `pad_tight` | Ширина ручки. |
| `grip_length` | DU | `icon_large` | Довжина ручки. |
| `grip` | слот | немає | Слот власної ручки. |
| `label` | string | `split-pane.handle` | Доступний підпис ручки розділювача. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `min_size` | DU | `--op-split-pane-min-size` | `20 DU` |
| `handle_size` | DU | `--op-split-pane-handle-size` | `gutter` |
| `divider_width` | DU | `--op-split-pane-divider-width` | `border` |
| `divider_active_width` | DU | `--op-split-pane-divider-active-width` | `border_thick` |
| `grip_width` | DU | `--op-split-pane-grip-width` | `pad_tight` |
| `grip_length` | DU | `--op-split-pane-grip-length` | `icon_large` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-split-pane-divider-color` | `border` |
| `--op-split-pane-divider-active-color` | `accent` |
| `--op-split-pane-grip-color` | `border_strong` |

| Слот | Розташування |
| :--- | :--- |
| `start` | Вміст першої панелі. |
| `end` | Вміст другої панелі. |
| `grip` | Замінює смуги ручки. |

`class` і `style` застосовуються до кореневого елемента split-pane.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `split-pane.handle` | `Splitter` |

### Піктограми

SplitPane не має вбудованих семантичних піктограм.

## Доступність

Розділювач є `separator`, що може отримувати фокус, із `aria-valuenow` у відсотках.
