# Timeline

Вертикальна послідовність датованих віх, змін стану або записів історії.
Кожен запис показує ноду-індикатор із необов'язковою піктограмою та семантичним тоном.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `Timeline` для відображення журналів аудиту, етапів розгортання, відстеження відправлень або історій змін у хронологічному порядку.
Не використовуйте `Timeline` для інтерактивних лінійних кроків майстра, що потребують введення користувача; натомість використовуйте [Stepper](stepper.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Розмір ноди | Квадрат `6 DU` (радіус кута `0 DU`). |
| З'єднувальна лінія | Ширина `0.25 DU` (`--op-timeline-line-width`). |
| Проміжок між записами | Типово `4 DU` (`2 DU` у режимі `dense`, `--op-timeline-gap`). |

## Поведінка

* Записи з'єднуються неперервною вертикальною лінією вздовж доріжки.
* Лінія закінчується на останньому записі.
* Крапка ноди підтримує семантичні тони (`pending`, `success`, `warning`, `error`, `accent`) для позначення стану віхи.

## API

### Timeline

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `dense` | bool | `false` | Зменшує проміжок між записами. |
| `gap` | DU | `--op-timeline-gap` | Проміжок між записами. |
| `line_width` | DU | `--op-timeline-line-width` | Ширина лінії доріжки. |
| `label` | string | `timeline.label` | Доступний підпис списку. |
| `class` | string | немає | CSS-класи на кореневому елементі. |
| `style` | string | немає | Інлайн-CSS на кореневому елементі. |

### TimelineEntry

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `title` | string | немає | Заголовок віхи. |
| `date` | string | немає | Рядок дати або часової позначки. |
| `tone` | string | `"default"` | Семантичний тон (`"pending"`, `"success"`, `"warning"`, `"error"`, `"accent"`). |
| `icon` | Icon | немає | Піктограма всередині крапки ноди. |
| `title_slot` | Слот | немає | Слот власного заголовка. |
| `date_slot` | Слот | немає | Слот власної дати. |
| `icon_slot` | Слот | немає | Слот власної крапки ноди. |
| `class` | string | немає | Класи CSS на елементі запису. |
| `style` | string | немає | Інлайн-CSS на елементі запису. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `gap` | DU | `--op-timeline-gap` | `4 DU` |
| `line_width` | DU | `--op-timeline-line-width` | `0.25 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-timeline-line-color` | `var(--op-border)` |
| `--op-timeline-dot-bg` | `var(--op-surface-raised)` |
| `--op-timeline-dot-border` | `var(--op-border)` |
| `--op-timeline-dot-color` | `var(--op-text-primary)` |
| `--op-timeline-date-color` | `var(--op-text-secondary)` |
| `--op-timeline-title-color` | `var(--op-text-primary)` |
| `--op-timeline-body-color` | `var(--op-text-secondary)` |

`class` і `style` застосовуються до контейнера `<ol>` у `Timeline` та `<li>` у `TimelineEntry`.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `timeline.label` | `"Timeline"` |

### Піктограми

Записи приймають будь-яку піктограму з `operator_ui_tokens::icons`.

## Доступність

`Timeline` структуровано як упорядкований список (`<ol>`) із доступним підписом орієнтира (`aria-label`).
Ноди та з'єднувальні лінії декоративні й позначені `aria-hidden="true"`.
