# IconButton

Квадратна кнопка лише з піктограмою, що підтримує синхронні та асинхронні кліки.

Статус: **reviewed** у вебреалізації.

## Використання

* Дії панелі інструментів, заголовка та всередині рядків.
* Компактні дії, для яких не вміститься підпис.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Розмір | Квадрат, типово `row_compact` (`8 DU`). Поширені розміри: `7`, `8`, `9` і `11 DU`. |
| Піктограма | Типово `icon_small` (`4 DU`), по центру. |
| Радіус заокруглення кутів | `0 DU`. |
| Контур | Контур стану, `0.25 DU`. |

## Стани

| Стан | Тло | Піктограма |
| :--- | :--- | :--- |
| `Idle` | `surface` | `icon` |
| `Pressed` | `pressed` | `icon` |
| `Selected` | `selection` | `icon` |
| `Pending` | `surface` | Рухомий контур; піктограма, потім [спінер із затримкою](../foundations/states.md#delayed-spinner) розміром із піктограму |
| `Success` | `success` на 15% | `check` у кольорі `success` |
| `Error` | `error` на 15% | `close` у кольорі `error` |
| `Disabled` | `disabled_surface` | `icon_disabled` |

## Поведінка

* Усередині [ButtonGroup](button-group.md) кнопка також враховує `enabled` групи і, з `exclusive`, вимкнена, поки виконується інша кнопка групи.
* Синхронний клік негайно виконує свій зворотний виклик і не має асинхронних станів.
* Асинхронний клік переводить у `Pending` та ігнорує подальші кліки до отримання результату.
* Піктограма результату показується протягом `500 ms`, потім початкова піктограма повертається в кольорі результату на `300 ms`.
* Потім результат згасає протягом `500 ms`.
* `loading = true` примусово встановлює `Pending` ззовні, наприклад, поки батьківський компонент завантажує дані.

## Режим посилання

Встановлення `href` перетворює кнопку на навігаційне посилання з таким самим виглядом.
Використовуйте його, коли натискання відкриває сторінку або зовнішній ресурс, а не запускає дію.

* Застосовуються лише `Idle`, `Pressed` та `Disabled`.
  `state`, `loading`, `on_click` та `on_async_click` ігноруються.
* `new_tab` відкриває ціль у новій вкладці чи вікні, якщо платформа підтримує цю концепцію.
* Вимкнене посилання зберігає свій вигляд, але не здійснює навігацію.

### Примітки щодо платформ

| Платформа | Реалізація |
| :--- | :--- |
| Веб | Справжній елемент `<a href>`, тому пошукові роботи переходять за ним, а клік коліщатком, кліки з модифікаторами та контекстне меню посилання працюють. `new_tab` додає `target="_blank"` і `rel="noopener noreferrer"`. Вимкнене посилання скидає `href` і встановлює `aria-disabled`. |
| Нативні інструментарії | Звичайна кнопка, натискання якої відкриває ціль через системний обробник URL платформи, наприклад `open_url` в egui. |

## Кастомізація

`class` та `style` застосовуються до кореневого елемента.
Метричні пропси приймають реактивні значення DU або TU; невстановлені пропси зберігають змінну CSS або її точний запасний варіант із дизайн-системи.
`style` викликача додається після оголошень метрик і має вищий пріоритет.
ActionButton та IconButton спільно використовують змінні `--op-button-*` для метрик і кольорів з однаковим значенням.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `size` | DU | `--op-button-size` | `var(--op-dim-row-compact)` |
| `icon_size` | DU | `--op-button-icon-size` | `var(--op-dim-icon-small)` |
| `gap` | DU | `--op-button-gap` | `var(--op-dim-gutter)` |
| `spinner_stroke` | DU | `--op-button-spinner-stroke` | `var(--op-dim-spinner-stroke)` |

Наявні числові пропси розміру зберігають назви та значення в DU й тепер також приймають реактивні значення.

| Змінна кольору | Типове значення |
| :--- | :--- |

| `--op-button-disabled-border` | `var(--op-disabled-border)` |

| `--op-button-icon` | `var(--op-icon)` |

| `--op-button-pending` | `var(--op-pending)` |
| `--op-button-pressed` | `var(--op-pressed)` |
| `--op-button-ripple` | `var(--op-ripple)` |
| `--op-button-selection` | `var(--op-selection)` |
| `--op-button-success` | `var(--op-success)` |

| Слот | Розташування |
| :--- | :--- |
| `leading` | Перед типовим вмістом. |

| Проп | Ключ | Типове значення |
