# FileField

Вибір файлів і область їх скидання на основі спільної оболонки Field.
Підтримує вибір кількох файлів, обмеження розміру, фільтрацію MIME-типів, перетягування та елементи-чипи, які можна вилучати.

Статус: **чернетка** у вебреалізації.

## Використання

* Вибір файлів із файлової системи.
* Скидання файлів безпосередньо в область введення.

## Геометрія

Елемент керування наслідує геометрію та компонування [Field](field.md).
Типова висота — `row_standard` (`10 DU`); зростає по вертикалі, коли чипи файлів переносяться на нові рядки.

## Поведінка

* Клік на кнопці вибору відкриває нативний файловий діалог.
* Перетягування файлів над елементом керування підсвічує область скидання.
* Скинуті файли фільтруються за правилами `accept` та `max_size`.
* Прийнятні файли додаються до списку, а назви відхилених передаються через `on_rejected`.
* Вибрані файли відображаються як елементи [Chip](chip.md) з можливістю вилучення.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал `Vec<PickedFile>` | обов’язковий | Список поточних вибраних файлів. |
| `multiple` | bool | `true` | Дозволяє вибирати більше одного файлу. |
| `append_files` | bool | `true` | Додає щойно вибрані файли до поточного списку. |
| `accept` | string | немає | Фільтр MIME-типів або розширень (наприклад, `image/*,.pdf`). |
| `max_files` | usize | немає | Максимально дозволена кількість файлів. |
| `max_size` | f64 | немає | Максимально дозволений розмір файлу в байтах. |
| `enabled` | bool | `true` | Вмикає введення та скидання файлів. |
| `state` | `ControlState` | немає | Явне перевизначення стану елемента керування. |
| `on_change` | зворотний виклик `(Vec<PickedFile>)` | немає | Сповіщає про оновлення файлів. |
| `on_rejected` | зворотний виклик `(Vec<String>)` | немає | Передає назви відхилених файлів. |
| `label` | string | `file-field.label` | Видимий підпис і доступна назва. |
| `hint` | string | немає | Допоміжний опис під полем. |
| `error` | string | немає | Повідомлення про помилку замість підказки. |
| `pick_label` | string | `file-field.pick` | Підпис кнопки вибору. |
| `pick_icon` | піктограма | `file-field.pick` | Піктограма кнопки вибору. |
| `variant` | `FieldVariant` | `Outlined` | Варіант стилю рамки. |
| `prepend` | `Slot` | немає | Слот перед чипами файлів. |
| `append` | `Slot` | немає | Слот після чипів файлів. |
| `before` | `Slot` | немає | Слот перед полем. |
| `after` | `Slot` | немає | Слот після поля. |
| `file` | `ScopedSlot<PickedFile>` | немає | Слот з областю видимості для відображення власних елементів файлів. |
| `chip_gap` | метрика DU | `gap_micro` | Проміжок між чипами файлів. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-field-height` | `row_standard` (`10 DU`) |
| `padding_x` | DU | `--op-field-padding-x` | `pad_card` |
| `slot_size` | DU | `--op-field-slot-size` | `row_standard` |
| `gap` | DU | `--op-field-gap` | `gap_micro` |
| `font_size` | TU | `--op-field-font-size` | `type_body_size` |
| `chip_gap` | DU | `--op-file-field-chip-gap` | `gap_micro` (`0.5 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-file-field-drop-background` | `hover` |
| `--op-file-field-text` | `text_primary` |
| `--op-file-field-disabled-text` | `text_disabled` |

| Слот | Розташування |
| :--- | :--- |
| `prepend` | Усередині поля, перед списком файлів. |
| `append` | Усередині поля, після списку файлів. |
| `before` | Зовні поля, перед ним. |
| `after` | Зовні поля, після нього. |
| `file` | Слот з областю видимості для відображення окремого файлу. |

`class` і `style` застосовуються до кореневого контейнера поля.

## Доступність

Кнопка вибору має доступний підпис і активує приховане нативне поле введення файлу.
Вибрані файли мають окремі доступні кнопки вилучення на чипах.
Скидання файлів повідомляє допоміжним технологіям про оновлення через сповіщення стану.
