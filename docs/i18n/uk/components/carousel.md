# Carousel

Контейнер послідовних слайдів зі стрілками навігації, індикаторами-крапками, жестами гортання, автопрокручуванням та керуванням із клавіатури.

Статус: **draft** у вебреалізації.

## Використання

Використовуйте Carousel для компактного показу наборів банерів, карток або вибраного вмісту.
Компонент підтримує автоматичну зміну слайдів із паузою при наведенні чи фокусуванні, а також повне керування жестами та клавіатурою.

## Геометрія

| Властивість | Типове значення | Змінна |
| :--- | :--- | :--- |
| Висота | `75 DU` | `--op-carousel-height` |
| Розмір кнопки-стрілки | `9 DU` | `--op-carousel-arrow-size` |
| Розмір крапки-індикатора | `2 DU` | `--op-carousel-dot-size` |

## Поведінка

* Кнопки зі стрілками вліво та вправо перемикають слайди.
* У безкінечному режимі карусель плавно зациклюється між першим і останнім слайдами.
* Нижні крапки-індикатори показують позицію поточного слайда та дозволяють швидкий перехід.
* Стрілки клавіатури «Вліво» та «Вправо» перемикають слайди у фокусі.
* Жести гортання дозволяють перемикати слайди на сенсорних пристроях.
* Автопрокручування регулярно перемикає слайди та призупиняється при наведенні чи фокусі.

## API

### Carousel

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `current` | сигнал rw-signal usize | обов’язковий | Поточний індекс слайда (починаючи з 0). |
| `count` | usize | обов’язковий | Загальна кількість слайдів. |
| `arrows` | сигнал bool | `true` | Показує кнопки зі стрілками навігації. |
| `dots` | сигнал bool | `true` | Показує нижні індикатори-крапки. |
| `infinite` | сигнал bool | `true` | Зациклює перемикання між початком і кінцем. |
| `autoplay` | сигнал bool | `false` | Автоматично перемикає слайди за розкладом. |
| `interval_ms` | сигнал u64 | `5000` | Інтервал автопрокручування в мілісекундах. |
| `swipeable` | сигнал bool | `true` | Вмикає сенсорні жести гортання. |
| `prev_label` | рядок | `carousel.prev` | Доступний підпис кнопки попереднього слайда. |
| `next_label` | рядок | `carousel.next` | Доступний підпис кнопки наступного слайда. |
| `aria_label` | рядок | `carousel.label` | Доступна назва області каруселі. |
| `height` | метрика DU | `75 DU` | Висота контейнера каруселі. |
| `arrow_size` | метрика DU | `9 DU` | Розмір кнопок-стрілок. |
| `dot_size` | метрика DU | `2 DU` | Розмір індикаторів-крапок. |

## Доступність

* Контейнер каруселі має `role="region"`, `aria-roledescription="carousel"` і доступний для фокусу клавіатури.
* Окремі слайди мають `role="group"` та `aria-roledescription="slide"`.
* Індикатори-крапки працюють як `tablist` зі станом `aria-selected`.
