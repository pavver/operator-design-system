# ChatInput

Панель введення чату з автоматичним розширенням багаторядкового тексту, заголовком цитування/редагування та перемикачем на кнопку запису медіа.
Вона плавно інтегрується з асинхронним автоматом станів Operator (`Idle`, `Pending`, `Success`, `Error`).

Статус: **draft** на web.

## Застосування

Використовуйте `ChatInput` як основну панель створення повідомлень у чатах, каналах спільної роботи та коментарях.
Текстове поле вертикально збільшується під час введення і вмикає прокручування при досягненні максимальної висоти.
Коли поле порожнє, у правій частині відображається кнопка запису `MediaRecordButton`; введення будь-якого символу перемикає її на кнопку надсилання.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` контурна рамка контейнера. |
| Мінімальна висота | `9 DU` (`--op-chat-input-min-height`). |
| Максимальна висота | `29 DU` (`--op-chat-input-max-height`). |
| Розмір шрифту | `13 TU` (`--op-chat-input-font-size`). |

## Поведінка

* Багаторядковий текст автоматично збільшує висоту поля вводу.
* Натискання `Enter` викликає `on_send`, а `Shift+Enter` створює новий рядок.
* За відсутності тексту елемент відображає `MediaRecordButton` для запису аудіо/відео.
* Цитування повідомлень та активне редагування відображають верхню панель із можливістю скасування.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `value` | `Signal<String>` | обов'язковий | Сигнал тексту введення. |
| `on_input` | `Callback<String>` | обов'язковий | Зворотний виклик при зміні тексту. |
| `on_send` | `Callback<()>` | обов'язковий | Зворотний виклик надсилання повідомлення. |
| `reply` | `Option<MessageReply>` | немає | Посилання на цитоване повідомлення. |
| `is_editing` | `bool` | `false` | Чи активне редагування наявного повідомлення. |
| `on_cancel_reply` | `Option<Callback<()>>` | немає | Дія скасування цитати або редагування. |
| `on_attach` | `Option<Callback<()>>` | немає | Зворотний виклик кнопки додатків. |
| `on_toggle_media` | `Option<Callback<()>>` | немає | Зворотний виклик перемикача медіа-клавіатури. |
| `state` | `ControlState` | `Idle` | Стан кнопки надсилання (`Idle`, `Pending`, `Success`, `Error`). |
| `placeholder` | `string` | `"Type a message..."` | Підказка в текстовому полі. |
| `min_height` | `f32` | `9.0` | Мінімальна висота в Design Units. |
| `max_height` | `f32` | `29.0` | Максимальна висота в Design Units. |
| `font_size` | `f32` | `13.0` | Розмір шрифту в Type Units. |
| `leading` | `Slot` | немає | Слот перед текстовим полем. |
| `trailing` | `Slot` | немає | Слот перед кнопкою надсилання/запису. |
| `attachments` | `Slot` | немає | Власний слот кнопки додатків. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Доступність

* Автозростаюче поле вводу зберігає повну підтримку клавіатури та стандартних сполучень клавіш.
* Заголовки цитат та редагування містять описовий текст із кнопками скасування.
* Кнопка надсилання відображає `aria-busy` та асинхронні стани Operator.
