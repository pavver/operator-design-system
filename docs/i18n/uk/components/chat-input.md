# ChatInput

Багаторядкове поле введення повідомлень чату з автоматичним вертикальним розширенням.
Воно підтримує цитування відповідей, режим редагування, кнопки додатків, асинхронні стани відправлення та перемикання на запис голосових і відеоповідомлень.

Статус: **draft** на web.

## Застосування

Використовуйте `ChatInput` як головний елемент взаємодії у стрічках чату, службах підтримки та тактичних консолях.
Коли поле порожнє, дія відправлення плавно перемикається на [MediaRecordButton](media-record-button.md) для швидкого запису медіа.
Коли введено текст, натомість з'являється кнопка відправлення у стилі [ActionButton](action-button.md) зі станами очікування, успіху та помилки.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` стандартна рамка контейнера. |
| Мінімальна висота | `9 DU` (`--op-chat-input-min-height`). |
| Максимальна висота | `29 DU` (`--op-chat-input-max-height`). |
| Розмір шрифту | `13 TU` (`--op-chat-input-font-size`). |

## Поведінка

* Текстове поле автоматично збільшується у висоту при перенесенні рядків між 9 DU та 29 DU.
* Натискання `Enter` без клавіші `Shift` надсилає повідомлення через `on_send`.
* Натискання `Shift+Enter` створює новий рядок.
* Цитування повідомлення або редагування відображає панель попереднього перегляду з кнопкою скасування.
* Коли текст відсутній, кнопка надсилання замінюється елементом запису медіа.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `value` | `Signal<String>` | обов'язковий | Реактивний стан чорнетки тексту. |
| `on_input` | `Callback<String>` | обов'язковий | Подія зміни вмісту тексту. |
| `on_send` | `Callback<()>` | обов'язковий | Подія надсилання повідомлення. |
| `reply` | `Option<MessageReply>` | немає | Цитована відповідь на повідомлення. |
| `is_editing` | `bool` | `false` | True у режимі редагування надісланого повідомлення. |
| `on_cancel_reply` | `Callback<()>` | немає | Подія скасування цитати або редагування. |
| `on_attach` | `Callback<()>` | немає | Подія кліку на кнопку вкладень. |
| `on_toggle_media` | `Callback<()>` | немає | Подія відкриття медіа-клавіатури. |
| `state` | `ControlState` | `Idle` | Стан Operator для кнопки надсилання. |
| `media_mode` | `MediaRecordMode` | `Voice` | Активний режим кнопки запису медіа. |
| `recording` | `bool` | `false` | True під час активного запису. |
| `recording_locked` | `bool` | `false` | True під час зафіксованого запису. |
| `placeholder` | `string` | немає | Текст підказки поля введення. |
| `min_height` | `f32` | `9.0` | Мінімальна висота в Design Units. |
| `max_height` | `f32` | `29.0` | Максимальна висота в Design Units. |
| `font_size` | `f32` | `13.0` | Розмір шрифту в Type Units. |
| `leading` | `Slot` | немає | Слот перед полем введення. |
| `trailing` | `Slot` | немає | Слот після поля введення. |
| `attachments` | `Slot` | немає | Власний слот для кнопки додатків. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Доступність

* Автозростаюче поле вводу зберігає повну підтримку клавіатури та стандартних сполучень клавіш.
* Заголовки цитат та редагування містять описовий текст із кнопками скасування.
* Кнопка надсилання відображає `aria-busy` та асинхронні стани Operator.
