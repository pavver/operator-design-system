# LoadingOverlay

Напівпрозорий фон зі спінером і повідомленням стану, що покриває батьківський контейнер.
Повністю блокує взаємодію користувача з покритою областю, поки виконуються асинхронні операції.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `LoadingOverlay` над картками, таблицями, формами або модальними представленнями, коли фонова мережева операція змінює їхній вміст.
Не використовуйте `LoadingOverlay` для коротких мікровзаємодій усередині кнопок; натомість використовуйте стан очікування [ActionButton](action-button.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Межі | Розтягується на весь батьківський контейнер (`inset: 0`). |
| Розмір спінера | `8 DU` (`--op-loading-overlay-spinner-size`). |
| Штрих спінера | `0.5 DU` (`--op-loading-overlay-spinner-stroke`). |

## Поведінка

* Коли `showing` має значення `true`, оверлей з'являється й перехоплює всі події вказівника.
* Він відображає центрований [ProgressIndicator](primitives.md) та необов'язковий описовий підпис.
* Оверлей плавно з'являється і згасає за токенами руху (`--op-motion-fade`).
* За використання з дочірніми елементами автоматично обгортає їх у контейнер із відносним позиціюванням.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `showing` | сигнал bool | обов’язковий | Активує оверлей і блокує введення. |
| `label` | string | `loading-overlay.loading` | Текст під спінером. |
| `spinner_size` | DU | `8 DU` | Діаметр спінера. |
| `spinner_stroke` | DU | `0.5 DU` | Товщина штриха спінера. |
| `gap` | DU | `2 DU` | Проміжок між спінером і текстом. |
| `font_size` | TU | `--op-loading-overlay-font-size` | Розмір тексту підпису. |
| `class` | string | немає | CSS-класи на кореневому елементі. |
| `style` | string | немає | Інлайн-CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `spinner_size` | DU | `--op-loading-overlay-spinner-size` | `8 DU` |
| `spinner_stroke` | DU | `--op-loading-overlay-spinner-stroke` | `0.5 DU` |
| `gap` | DU | `--op-loading-overlay-gap` | `2 DU` |
| `font_size` | TU | `--op-loading-overlay-font-size` | `inherit` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-loading-overlay-background` | `var(--op-overlay-scrim, rgb(0 0 0 / 55%))` |
| `--op-loading-overlay-spinner` | `var(--op-accent)` |
| `--op-loading-overlay-text` | `var(--op-text-primary)` |

`class` і `style` застосовуються до `div` оверлею.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `loading-overlay.loading` | `"Loading..."` |

### Піктограми

`LoadingOverlay` використовує векторне кільце прогресу з `ProgressIndicator`.

## Доступність

`LoadingOverlay` має `role="status"` із `aria-live="polite"` і встановлює `aria-busy="true"` на батьківській області, поки активний.
Введення користувача в покритій області повністю призупиняється.
