# Popover

Плавучий шар, прикріплений до якоря: спільна основа [Menu](menu.md), [DropdownMenu](dropdown-menu.md), [Combobox](combobox.md), [Tooltip](tooltip.md) та підказок [MarqueeText](marquee-text.md).
Не має власного вигляду; шар оформлює компонент, який його використовує.

Статус: **чернетка** у вебреалізації.

## Шар

* Кожен `ThemeRoot` містить один хост оверлеїв після свого вмісту.
  Спливні шари монтуються там, тому предки з трансформаціями, обрізанням, `overflow` або власним контекстом накладання ніколи не переміщують і не обрізають їх, а тема продовжує діяти.
* Поза коренем теми шар монтується в тіло документа.
* Шари накладаються в порядку відкриття; пізніший шар покриває попередній.

## Розташування

| Розташування | Позиція |
| :--- | :--- |
| `BelowStart` | Під якорем, початкові краї вирівняні; перевертається вгору, коли знизу бракує місця. |
| `BelowEnd` | Під якорем, кінцеві краї вирівняні; перевертається вгору, коли знизу бракує місця. |
| `BelowStretch` | Під якорем із шириною якоря, для списків поля. |
| `Above` | По центру над якорем, на відстані `gap` DU; перевертається вниз, коли вміщується лише там. |
| `Below` | По центру під якорем, на відстані `gap` DU; перевертається вгору, коли вміщується лише там. |
| `Side(side, align)` | На бажаній стороні `LayerSide` з бажаним вирівнюванням `LayerAlign`; перевертається на протилежну сторону, потім (зліва чи справа) вниз і вгору, і зсувається вздовж якоря, щоб лишатися на екрані. |
| `AtPoint` | У позиції вказівника, зі зміщенням для утримання в області перегляду (контекстні меню). |
| `SideStart` | Поруч із якорем, верхні краї вирівняні, праворуч або ліворуч (підменю). |

Шар завжди обмежується областю перегляду.
Центрований або бічний шар (`Above`, `Below`, `Side`) біля краю екрана зсувається вздовж якоря, щоб лишатися на екрані, і ніколи не буває ширшим за область перегляду.
Коли він не вміщується ні зверху, ні знизу, то займає бік, де більше місця, отримує його висоту як обмеження й обрізає вміст.
Вміст, що може рости, розміщує рядки у [ScrollView](scrollbar.md), який заповнює обмежений шар і прокручується бібліотечною смугою прокручування замість нативної.
У першому кадрі він вимірюється прихованим, а в наступному показується на визначеному місці, тому ніколи не блимає в неправильній позиції.

## Вигляд

| Властивість | Значення |
| :--- | :--- |
| Поверхня | `surface`. |
| Рамка | Бордер `0.25 DU` кольору `accent` усередині меж, однаковий для всіх спливних шарів. |

Компоненти на основі Popover зберігають цю рамку й лише прив'язують її колір до власної змінної, наприклад `--op-menu-border`.

## Поведінка

* Прокручування будь-якого предка та зміна розміру вікна змінюють розташування відкритого шару; `dismiss_on_resize` натомість закриває його (меню).
* `dismiss_on_scroll` закриває шар, коли прокручується сторінка або будь-який контейнер поза ним, замість слідування за якорем.
* Прокручування всередині шару не змінює його розташування й не закриває його, тому власна область прокручування зберігає зсув і плавну прокрутку коліщатком та дотиком.
* Прокручування всередині якоря, наприклад текстового поля, що зсувається до курсора, так само не змінює розташування шару й не закриває його.
* Натискання поза шаром і якорем закриває його (`dismiss_on_outside`, типово ввімкнено).
  Шар, відкритий з іншого шару (`parent_layer`), вважається частиною батьківського, тому натискання в підменю зберігає меню відкритим.
* Escape закриває його (`dismiss_on_escape`, типово ввімкнено).
* Якщо шар закривається, коли фокус усередині нього, фокус повертається до елемента, який мав його до відкриття (`restore_focus`, типово ввімкнено).
* Шар `passive` пропускає події вказівника крізь себе (підказки).

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `open` | сигнал bool | обов’язковий | Показує шар. |
| `anchor` | сигнал `PopoverAnchor` | обов’язковий | Прямокутник елемента (`PopoverAnchor::of(el)`) або точка вказівника. |
| `placement` | сигнал `Placement` | `BelowStart` | Див. *Розташування*. |
| `gap` | реактивна метрика DU | `0` | Відстань до якоря. |
| `dismiss_on_outside` | bool | `true` | Закривати при натисканні зовні. |
| `dismiss_on_escape` | bool | `true` | Закривати за Escape. |
| `dismiss_on_resize` | bool | `false` | Закривати при зміні розміру замість слідування. |
| `dismiss_on_scroll` | bool | `false` | Закривати замість слідування, коли прокручується будь-що поза шаром. |
| `hold_open` | сигнал bool | `false` | Поки true, натискання поза шаром, Escape, прокручування й зміна розміру ніколи не закривають шар; прокручування й зміна розміру змінюють його розташування. |
| `restore_focus` | bool | `true` | Повертати фокус при закритті. |
| `passive` | bool | `false` | Події вказівника проходять наскрізь. |
| `class`, `role`, `label` | string | немає | Класи елемента шару, роль і підпис ARIA. |
| `node_ref` | посилання на елемент | немає | Елемент шару. |
| `layer_id`, `parent_layer` | ідентифікатор шару | новий ідентифікатор, немає | Пов'язує шар із шаром, з якого його відкрито (`new_layer_id()`). |
| `on_placed` | зворотний виклик | немає | Виконується після кожного розташування, наприклад для фокусування першого елемента. |
| `children` | view | обов’язковий | Вміст шару. |

Властивості кастомізації є необов’язковими та приймають реактивні значення там, де це вказано.

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `class`, `style` | реактивний string | немає | Кореневі хуки. |
| `offset_x` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-popover-offset-x`. |
| `offset_y` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-popover-offset-y`. |
| `header` | `Slot` | немає | Вміст перед типовими дочірніми елементами. |
| `actions` | `Slot` | немає | Вміст після типових дочірніх елементів, перед нижньою частиною. |
| `footer` | `Slot` | немає | Вміст після тіла та дій. |
| `aria_label` | реактивний string | `popover.label` | Доступна назва; має пріоритет над сумісним пропом `label`. |

## Кастомізація

`class` і `style` застосовуються до плавучого шару.
Метричні пропси записують відповідні змінні; явне оголошення `style` має перевагу.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `offset_x` | DU | `--op-popover-offset-x` | `0 DU` |
| `offset_y` | DU | `--op-popover-offset-y` | `0 DU` |
| `gap` | DU | `--op-popover-gap` | `0 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-popover-background` | `surface` |
| `--op-popover-border` | `accent` |
| `--op-popover-text` | `inherit` |

| Слот | Розташування |
| :--- | :--- |
| `header` | Вміст перед типовими дочірніми елементами. |
| `actions` | Вміст після типових дочірніх елементів, перед нижньою частиною. |
| `footer` | Вміст після тіла та дій. |

`placement` зберігає наявний перелік і API сигналу.
`gap` керує відстанню від якоря в DU для розташування знизу, зверху та збоку.
`offset_x` і `offset_y` зміщують розташований шар уздовж осей області перегляду після обмеження її межами.
Необов'язковий проп `label` залишається сумісним; `aria_label` додає реактивне перевизначення.
Внутрішній спостерігач розміру змінює розташування шару, коли метрики, слоти або перекладений вміст змінюють його розміри.
