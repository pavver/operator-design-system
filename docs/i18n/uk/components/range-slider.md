# RangeSlider

Два впорядковані бігунки зі спільними візуальними елементами доріжки та бігунка Slider.
Дозволяє вибирати інтервал між нижнім і верхнім значеннями.

Статус: **чернетка** у вебреалізації.

## Використання

* Налаштування діапазонів ціни, часу або частоти.
* Визначення числових меж фільтрації.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Висота | `row_compact` (`8 DU`). |
| Відступ доріжки | `3 DU`. |
| Висота доріжки | `2 DU`. |
| Бігунок | Коло діаметром `icon_large` (`6 DU`). Дозволено виняток для круглої форми. |
| Крапка в бігунку у стані спокою | Коло діаметром `pad_small` (`1.5 DU`). |

## Поведінка

* Клік або перетягування вибирає й переміщує найближчий бігунок.
* Бігунки зберігають порядок: нижній не може перевищувати верхній.
* Перетягування захоплює події вказівника для плавного перетягування поза межами елемента.
* Відпускання або крокова зміна з клавіатури викликає асинхронний обробник фіксації.
* У разі помилки значення відкочуються до попередньо зафіксованих.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал `(f32, f32)` | обов’язковий | Кортеж нижнього та верхнього значень. |
| `min` | f32 | `0.0` | Мінімальна межа діапазону. |
| `max` | f32 | `100.0` | Максимальна межа діапазону. |
| `step` | f32 | `1.0` | Крок зміни. |
| `readonly` | bool | `false` | Запобігає змінам. |
| `enabled` | bool | `true` | Вмикає введення. |
| `state` | `ControlState` | немає | Явне перевизначення стану елемента керування. |
| `on_change` | зворотний виклик `((f32, f32))` | немає | Оновлення інтервалу в реальному часі. |
| `on_commit` | `AsyncAction<(f32, f32)>` | немає | Асинхронний обробник фіксації з відкатом у разі збою. |
| `label` | string | `range-slider.label` | Доступний підпис групи. |
| `lower_label` | string | `range-slider.lower` | Доступний підпис нижнього бігунка. |
| `upper_label` | string | `range-slider.upper` | Доступний підпис верхнього бігунка. |
| `height` | метрика DU | `row_compact` | Загальна висота повзунка. |
| `rail_inset` | метрика DU | `3 DU` | Відступ для меж бігунків. |
| `track_height` | метрика DU | `2 DU` | Товщина лінії доріжки. |
| `thumb_size` | метрика DU | `icon_large` | Діаметр бігунків. |
| `dot_size` | метрика DU | `pad_small` | Діаметр центральної крапки бігунка. |
| `width` | метрика DU | немає | Явне перевизначення ширини. |
| `thumb` | `Slot` | немає | Замінює стандартний вигляд бігунка. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-slider-height` | `row_compact` (`8 DU`) |
| `rail_inset` | DU | `--op-slider-rail-inset` | `3 DU` |
| `track_height` | DU | `--op-slider-track-height` | `2 DU` |
| `thumb_size` | DU | `--op-slider-thumb-size` | `icon_large` (`6 DU`) |
| `dot_size` | DU | `--op-slider-dot-size` | `pad_small` (`1.5 DU`) |
| `width` | DU | `--op-slider-width` | заповнює батьківський елемент |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-slider-accent` | `accent` |
| `--op-slider-border` | `border` |

| Слот | Розташування |
| :--- | :--- |
| `thumb` | Власний вміст усередині слота бігунка. |

`class` і `style` застосовуються до кореневого елемента групи.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `range-slider.label` | `Range` |
| `range-slider.lower` | `Lower value` |
| `range-slider.upper` | `Upper value` |

### Піктограми

RangeSlider не визначає вбудованих піктограм.

## Доступність

Корінь представляє `group`, що містить два окремі елементи керування `slider`.
Кожен бігунок надає `aria-valuemin`, `aria-valuemax` і `aria-valuenow` з незалежним фокусуванням клавішами зі стрілками.
