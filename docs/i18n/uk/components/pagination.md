# Pagination

Навігація між нумерованими сторінками довгого списку або таблиці.

Статус: **reviewed** у вебреалізації.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Кнопки | Висота `8 DU`, ширина щонайменше `8 DU`, проміжок `1 DU`. |
| Попередня / наступна | [IconButton](icon-button.md) із `chevron_left` і `chevron_right`. |
| Поточна сторінка | Редаговане поле: фон `selection`, жирний текст `accent`, контур `Selected`; достатньо широке для цифр останньої сторінки. |
| Поточна сторінка під час редагування | Фон `surface`, текст `text_primary`, контур `Focused`, без зовнішньої рамки фокусу. |
| Трикрапка | `…` у кольорі `text_secondary`, завширшки `8 DU`. |
| Числа | Табличні цифри. |

## Вікно сторінок

Перша й остання сторінки показуються завжди.
Навколо поточної сторінки показується по `siblings` сторінок із кожного боку (типово 1).
Пропуск однієї сторінки заповнюється цією сторінкою; довший пропуск стає трикрапкою.

Приклад для сторінки 6 із 24: `1 … 5 6 7 … 24`.

## Введення сторінки

Поточна сторінка є полем, тому оператор може перейти до віддаленої сторінки без послідовного проклацування вікна.
При фокусуванні число виділяється, тому введення замінює його.
Можна вводити лише цифри.
Enter переходить до введеної сторінки; число за межами діапазону переходить до останньої сторінки, а `0` — до першої.
Escape відновлює поточну сторінку; вихід із поля відновлює її без переходу.
У компактному режимі після поля показується `/ total`.

## Поведінка

* Перехід до попередньої вимкнено на першій сторінці; до наступної — на останній.
* Компактний режим замінює числа полем поточної сторінки та `/ 24` для вузьких областей.
* Нумерація сторінок починається з 1.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `page` | сигнал цілого числа | обов’язковий | Поточна сторінка, починаючи з 1. |
| `total` | integer | обов’язковий | Кількість сторінок. |
| `siblings` | integer | `1` | Кількість сторінок із кожного боку від поточної. |
| `compact` | bool | `false` | Показує `page / total`. |
| `gap` | DU | `pad_tight` | Проміжок між елементами керування сторінками. |
| `page_size` | DU | `row_compact` | Розмір кнопок сторінок. |
| `page_padding_x` | DU | `pad_tight` | Горизонтальний внутрішній відступ кнопок сторінок. |
| `compact_gap` | DU | `pad_small` | Проміжок у компактному режимі. |
| `compact_padding_x` | DU | `pad_tight` | Горизонтальний внутрішній відступ у компактному режимі. |
| `label` | string | `pagination.label` | Доступна назва контейнера пагінації. |
| `prev_label` | string | `pagination.previous` | Доступний підпис кнопки попередньої сторінки. |
| `next_label` | string | `pagination.next` | Доступний підпис кнопки наступної сторінки. |
| `page_label` | string | `pagination.page` | Шаблон кнопок сторінок. |
| `current_page_label` | string | `pagination.current_page` | Шаблон поля введення поточної сторінки. |
| `prev_icon` | піктограма | `pagination.previous` | Перевизначення піктограми кнопки попередньої сторінки. |
| `next_icon` | піктограма | `pagination.next` | Перевизначення піктограми кнопки наступної сторінки. |
| `before` | слот | немає | Слот перед елементами пагінації. |
| `after` | слот | немає | Слот після елементів пагінації. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `gap` | DU | `--op-pagination-gap` | `pad_tight` |
| `page_size` | DU | `--op-pagination-page-size` | `row_compact` |
| `page_padding_x` | DU | `--op-pagination-page-padding-x` | `pad_tight` |
| `compact_gap` | DU | `--op-pagination-compact-gap` | `pad_small` |
| `compact_padding_x` | DU | `--op-pagination-compact-padding-x` | `pad_tight` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-pagination-page-background` | `surface` |
| `--op-pagination-page-text` | `text_primary` |
| `--op-pagination-current-background` | `selection` |
| `--op-pagination-current-text` | `accent` |
| `--op-pagination-gap-text` | `text_secondary` |
| `--op-pagination-compact-text` | `text_secondary` |

| Слот | Розташування |
| :--- | :--- |
| `before` | Перед кнопкою попередньої сторінки. |
| `after` | Після кнопки наступної сторінки. |

`class` і `style` застосовуються до кореневого елемента nav.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `pagination.label` | `Pagination` |
| `pagination.previous` | `Previous page` |
| `pagination.next` | `Next page` |
| `pagination.page` | `Page {n}` |
| `pagination.current_page` | `Page {page} of {total}, type a page number` |

### Піктограми

| Ключ | Типове значення |
| :--- | :--- |
| `pagination.previous` | `chevron_left` |
| `pagination.next` | `chevron_right` |

## Доступність

Орієнтир `navigation` із назвою «Pagination»; поточна сторінка має `aria-current="page"`.
Поле поточної сторінки має назву «Page 6 of 24, type a page number» і відкриває цифрову клавіатуру на сенсорних пристроях.
