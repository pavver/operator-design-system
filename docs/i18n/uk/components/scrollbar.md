# Scrollbar

Прямокутна накладена смуга прокручування, що замінює нативну в кожному компоненті з прокручуванням.

Статус: **reviewed** у вебреалізації.

## Використання

Кожен контейнер прокручування в бібліотеці використовує цю смугу, тому прокручування виглядає однаково в кожному браузері та на кожній платформі.
Для нових контейнерів прокручування використовуйте `ScrollView`; використовуйте `Scrollbar` безпосередньо, лише коли елемент прокручування заданий, як-от `textarea`.
Браузер далі володіє позицією прокручування, тому коліщатко, дотик, клавіатура та допоміжні технології поводяться нативно.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Зона влучання | `2 DU` (`gutter`) уздовж внутрішнього краю контейнера, поверх вмісту. |
| Бігунок у стані спокою | Смуга `1 DU` (`pad_tight`) на зовнішньому краї зони влучання. |
| Бігунок при наведенні та перетягуванні | Заповнює всю зону влучання `2 DU`. |
| Мінімальна довжина бігунка | `6 DU`. |
| Кут | Коли прокручуються обидві осі, кожна смуга закінчується за `2 DU` до спільного кута. |
| Форма | Радіус кута `0 DU`, без тіні. |

Смуга малюється всередині контуру контейнера та над його вмістом.
Вона не займає місця в компонуванні, тому вміст ніколи не зміщується при появі переповнення.

## Кольори та стани

| Стан | Доріжка | Бігунок |
| :--- | :--- | :--- |
| Стан спокою | Прозорий | `border_strong` |
| Наведення на доріжку (пристрої з вказівником) | `surface_alt` із лінією `0.25 DU` у кольорі `divider` на внутрішньому краї | `border_strong`, на всю ширину |
| Наведення на бігунок | Так само, як вище | `text_secondary` |
| Перетягування | Так само, як вище | `accent` |
| Без переповнення | Прихований | Прихований |

Зміни кольору й ширини тривають `state_color` (`150 ms`), лінійно.

## Взаємодія

1. Перетягування бігунка прокручує пропорційно; вказівник захоплюється до відпускання.
2. Натискання на порожній доріжці прокручує в бік вказівника на 90% видимої довжини.
3. Смуга слідує за прокручуванням, зміною розмірів контейнера та його дочірніх елементів і змінами вмісту.
4. Смуга прихована від допоміжних технологій; елемент прокручування залишається доступною областю прокручування.
5. `ScrollView` передає прокручування далі, як при нативному прокручуванні: коли прокручувати більше нічого, коліщатко або проведення пальцем рухає сторінку.
   Оверлеї (меню, списки вибору, Combobox, Dialog, Sheet) додають `op-scroll-contain`, тому сторінка під ними залишається нерухомою.

## Нативний запасний варіант

Контейнери прокручування, не побудовані на `ScrollView` (наприклад, вміст застосунку всередині `ThemeRoot`), отримують тонку нативну смугу прокручування.
Вона використовує бігунок `1 DU` у кольорі `border_strong` на прозорій доріжці.
Горизонтальні смуги, які навмисно приховують смугу прокручування, як-от [Tabs](tabs.md) і [Toolbar](toolbar.md), залишають її прихованою.

## API

### ScrollView

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `axis` | `ScrollAxis` | `Vertical` | `Vertical`, `Horizontal` або `Both`. |
| `class` | string | немає | Класи зовнішнього контейнера (розмір, роль у flex-компонуванні). |
| `viewport_class` | string | немає | Класи прокручуваного елемента (внутрішні відступи, проміжок, компонування). |
| `height` | DU | немає | Фіксована висота. |
| `max_height` | DU | немає | Максимальна висота. |
| `track_size` | DU | `gutter` | Розмір зони влучання доріжки. |
| `thumb_thickness` | DU | `pad_tight` | Товщина бігунка у стані спокою. |
| `node_ref` | посилання на ноду | немає | Посилання на прокручуваний елемент для програмного прокручування. |
| `focusable` | bool | `false` | Дозволяє прокручуваному елементу отримувати фокус для прокручування з клавіатури. |
| `label` | string | `scroll-view.label` | Доступна назва, коли можна отримувати фокус. |
| `header` | слот | немає | Фіксований вміст перед прокручуваною областю перегляду. |
| `footer` | слот | немає | Фіксований вміст після прокручуваної області перегляду. |
| `children` | view | обов’язковий | Вміст. |

### Scrollbar

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `target` | посилання на ноду | обов’язковий | Елемент прокручування; має містити клас `op-scroll-native-off`. |
| `axis` | `ScrollAxis` | `Vertical` | Вісь цієї смуги. |
| `corner` | bool | `false` | Залишає місце для перехресної смуги. |
| `track_size` | DU | `gutter` | Розмір зони влучання доріжки. |
| `thumb_thickness` | DU | `pad_tight` | Товщина бігунка у стані спокою. |

Розміщуйте `Scrollbar` поруч із цільовим елементом усередині позиційованого батьківського елемента.

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-scrollbar-height` | немає |
| `max_height` | DU | `--op-scrollbar-max-height` | `100%` |
| `track_size` | DU | `--op-scrollbar-track-size` | `gutter` |
| `thumb_thickness` | DU | `--op-scrollbar-thumb-thickness` | `pad_tight` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-scrollbar-thumb-color` | `border_strong` |
| `--op-scrollbar-thumb-hover-color` | `text_secondary` |
| `--op-scrollbar-thumb-active-color` | `accent` |
| `--op-scrollbar-track-hover-background` | `surface_alt` |
| `--op-scrollbar-track-active-background` | `surface_alt` |
| `--op-scrollbar-divider-color` | `divider` |

| Слот | Розташування |
| :--- | :--- |
| `header` | Фіксований вміст перед прокручуваною областю перегляду в ScrollView. |
| `footer` | Фіксований вміст після прокручуваної області перегляду в ScrollView. |

`class` і `style` застосовуються до кореневого елемента (`op-scrollbar` у Scrollbar, `op-scrollview` у ScrollView).
