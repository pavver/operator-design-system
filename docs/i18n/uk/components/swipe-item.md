# SwipeItem

Інтерактивний рядок списку, що відкриває контекстні дії ліворуч і праворуч при проведенні пальцем чи мишею.

Статус: **draft** у вебреалізації.

## Використання

Використовуйте SwipeItem у списках для швидких контекстних дій, таких як архівація, позначення прочитаним або видалення.
Компонент підтримує сенсорні та вказівні жести перетягування з напрямними порогами та плавним поверненням на місце.

## Геометрія

| Властивість | Типове значення | Змінна |
| :--- | :--- | :--- |
| Ширина області дії | `18 DU` | `--op-swipe-item-action-width` |
| Мінімальна висота рядка | `12 DU` | `--op-swipe-item-height` |
| Поріг спрацьовування | `15 DU` | `--op-swipe-item-threshold` |

## Поведінка

* Проведення праворуч відкриває лівий слот дії за вмістом.
* Проведення ліворуч відкриває правий слот дії.
* Перетягування далі за поріг із наступним відпусканням викликає `on_left` або `on_right`.
* Після відпускання рядок плавно повертається у вихідне положення.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `left` | слот | немає | Дії, що відкриваються при проведенні праворуч. |
| `right` | слот | немає | Дії, що відкриваються при проведенні ліворуч. |
| `on_left` | зворотний виклик `()` | немає | Спрацьовує при проведенні вправо за поріг. |
| `on_right` | зворотний виклик `()` | немає | Спрацьовує при проведенні вліво за поріг. |
| `threshold` | метрика DU | `15 DU` | Відстань перетягування для виклику дії. |
| `action_width` | метрика DU | `18 DU` | Мінімальна ширина відкритого слота дії. |
| `height` | метрика DU | `12 DU` | Мінімальна висота елемента. |
| `left_label` | рядок | `swipe-item.left` | Доступний підпис для лівої дії. |
| `right_label` | рядок | `swipe-item.right` | Доступний підпис для правої дії. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `action_width` | DU | `--op-swipe-item-action-width` | `18 DU` |
| `height` | DU | `--op-swipe-item-height` | `12 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-swipe-item-background` | `surface` |
| `--op-swipe-item-left-bg` | `accent` |
| `--op-swipe-item-right-bg` | `error` |

## Тексти

| Ключ | Типовий текст (uk) | Опис |
| :--- | :--- | :--- |
| `swipe-item.left` | `Дія ліворуч` | Доступна назва для лівої дії. |
| `swipe-item.right` | `Дія праворуч` | Доступна назва для правої дії. |

## Доступність

* Стандартний атрибут touch-action `pan-y` зберігає плавність вертикального прокручування сторінки.
