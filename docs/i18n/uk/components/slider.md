# Slider

Повзунок із доріжкою та бігунком, необов'язковими дискретними кроками, підказкою значення й асинхронною фіксацією після відпускання.

Статус: **reviewed** у вебреалізації.

## Використання

* Зміна числового параметра, як-от гучності, яскравості, масштабу або порога.
* Збереження значення на бекенді після відпускання користувачем.

## Анатомія

```
              ┌───┐
              │ 7 │                 tooltip
              └───┘
▓▓▓▓▓▓▓▓▓▓▓▓▓▓( • )·  ·  ·  ·  ·    track, fill, thumb, ticks
```

* **Доріжка:** прямокутник із власним контуром стану.
* **Заповнення:** покриває доріжку від мінімуму до поточного значення.
* **Поділки:** крапки в позиціях кожного кроку.
* **Бігунок:** коло, що містить вміст стану.
* **Підказка:** поточне значення над бігунком.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Ширина | Заповнює батьківський елемент. |
| Висота | `row_compact` (`8 DU`). |
| Відступ доріжки | `3 DU` з кожного боку, щоб бігунок ніколи не виходив за межі. |
| Висота доріжки | `2 DU`, радіус кута `0 DU`. |
| Бігунок | Коло діаметром `icon_large` (`6 DU`). Кругла форма — дозволений виняток. |
| Поділка | Коло діаметром `pad_tight` (`1 DU`). |
| Крапка в бігунку у стані спокою | Коло діаметром `pad_small` (`1.5 DU`). |
| Піктограма стану бігунка | `icon_xsmall` (`3.5 DU`); спінер `3 DU` із `spinner_stroke`. |
| Спливна підказка | `10 DU` над центром бігунка, стиль `caption`, жирний, контур `0.25 DU`. |

## Кольори

| Частина | Колір |
| :--- | :--- |
| Доріжка | `surface` із контуром стану. |
| Заповнення | `accent` із непрозорістю `35%`. |
| Поділка, незаповнена | `border` із непрозорістю `70%`. |
| Поділка, заповнена | `accent`. |
| Бігунок | `surface` із круговим контуром стану. |
| Вміст бігунка | Крапка `accent`; кольори результату відповідають стану. |
| Вимкнений | Заповнення та вміст `text_disabled`; поділки `text_disabled` із непрозорістю `40%` і `60%`. |

## Стани

| Стан | Доріжка | Бігунок |
| :--- | :--- | :--- |
| `Idle` | Контур `border`. | Контур `border`, крапка `accent`. |
| `Pending` | Рухомий сегмент `pending`. | Статичний контур; крапка, потім [спінер із затримкою](../foundations/states.md#delayed-spinner). |
| `Success` | Пульсівний контур `success`. | Пульсівний контур, піктограма `check`. |
| `Error` | Пульсівний контур `error`. | Пульсівний контур, піктограма `close`. |
| `Disabled` | `disabled_border`. | `disabled_surface`, без взаємодії. |

Бігунок не малює власного сегмента очікування; його натомість показує доріжка.
Доріжка, бігунок і вміст бігунка згасають зі стану результату разом.

## Поведінка

### Введення

* Натискання будь-де на елементі керування переміщує бігунок до вказівника й починає перетягування.
* Вказівник захоплюється, тому перетягування триває поза елементом керування.
* Під час перетягування бігунок точно слідує за вказівником без анімації.
* Стрибки без перетягування анімуються за `segment_slide` (`150 ms`) зі стандартною кривою: кліки на доріжці, кроки з клавіатури та відкати.
* За наявності кроку значення прив'язується до `min + n * step`.
* Клавіші зі стрілками змінюють значення на один крок або на 1% діапазону для неперервного повзунка.
* Натискання на елементі керування не має виділяти текст або починати нативне перетягування.
  Скасований жест вказівника відновлює останнє зафіксоване значення.

### Спливна підказка

* Підказка з'являється на початку перетягування.
* Вона залишається, поки триває перетягування, і ховається через `800 ms` після відпускання.
* Діапазони ширші за одну одиницю показують цілі числа або один десятковий знак; діапазони до однієї одиниці — два десяткові знаки.

### Асинхронна фіксація

1. Відпускання або крок із клавіатури фіксує нове значення, коли воно відрізняється від останнього зафіксованого.
2. Повзунок переходить у `Pending` та ігнорує введення.
3. У разі **успіху** значення стає новим зафіксованим, а повзунок показує `Success`.
4. У разі **помилки** значення анімовано повертається до останнього зафіксованого, а повзунок показує `Error`.
5. Через `800 ms` повзунок повертається в `Idle`, а результат згасає за `500 ms`.

Повзунок залишається інтерактивним під час `Success` і `Error`.
Нове перетягування під час спалаху результату починає новий цикл.

Зовнішня зміна значення у стані спокою стає новим зафіксованим значенням.

## Доступність

* Елемент керування має роль `slider` із мінімумом, максимумом і поточним значенням.
* Може отримувати фокус, поки інтерактивний.
* Кільце фокусу малюється навколо бігунка.

## Кастомізація

`class` та `style` застосовуються до кореневого елемента.
Метричні пропси приймають реактивні значення DU або TU; невстановлені пропси зберігають змінну CSS або її точний запасний варіант із дизайн-системи.
`style` викликача додається після оголошень метрик і має вищий пріоритет.
