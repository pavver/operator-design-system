# ButtonGroup

Контейнер, що групує пов'язані елементи керування [ActionButton](action-button.md) та [IconButton](icon-button.md) зі спільними межами.
Він створює візуально цілісні командні панелі та сегментовані панелі дій.

Статус: **reviewed** у вебреалізації.

## Використання

Використовуйте `ButtonGroup` для об'єднання дій, що належать до одного робочого процесу, як-от елементи керування вирівнюванням, режими редагування/попереднього перегляду чи елементи керування масштабуванням.
Не використовуйте `ButtonGroup` для взаємовиключного одиничного вибору, коли призначені [SegmentedControl](segmented-control.md) або [RadioGroup](radio-group.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Проміжок | `0 DU` (`--op-button-group-gap`). |
| Перекриття | Від'ємний відступ `0.25 DU` для наступних кнопок, завдяки чому суміжні межі зливаються в одну спільну стандартну межу. |

## Поведінка

* Сусідні кнопки мають спільні розділові межі.
* У разі фокусування або наведення активна кнопка піднімається над сусідніми, щоб її контур фокусу залишався повністю видимим.
* У режимі `spread` кожен дочірній елемент однаково розширюється, заповнюючи всю ширину контейнера.
* У режимі `vertical` кнопки розташовуються вертикально зі спільними горизонтальними межами.
* `enabled` вмикає або вимикає всі [ActionButton](action-button.md) та [IconButton](icon-button.md) усередині групи.
* Кожна кнопка зберігає власне [очікування](../foundations/states.md), успіх і помилку.
* З `exclusive` (типово) інші кнопки групи вимкнені, поки одна з них виконує дію, а група повідомляє `aria-busy`; з `exclusive = false` кожна кнопка працює незалежно.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `vertical` | bool | `false` | Розташовує кнопки вертикально. |
| `spread` | bool | `false` | Рівномірно розтягує кнопки на всю ширину. |
| `label` | string | `button-group.label` | Доступна назва для групи. |
| `gap` | DU | немає | Проміжок між кнопками в DU (типово `0 DU`). |
| `enabled` | сигнал bool | `true` | Вмикає або вимикає всі кнопки групи. |
| `exclusive` | bool | `true` | Блокує інші кнопки, поки одна виконує дію. |
| `class` | string | немає | Класи CSS на кореневому елементі. |
| `style` | string | немає | Інлайн-стилі CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `gap` | DU | `--op-button-group-gap` | `0` |

`class` та `style` застосовуються до кореневого `div`.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `button-group.label` | `"Button group"` |

### Піктограми

`ButtonGroup` не використовує внутрішніх піктограм; дочірні елементи надають власні піктограми.

## Доступність

`ButtonGroup` рендериться з `role="group"` та доступною назвою (`aria-label`).
У вимкненому стані група встановлює `aria-disabled`, а поки виконується ексклюзивна дія, — `aria-busy`.
