# Gallery

Адаптивна медіасітка фотографій та відео з вибором, підписами та лінивим завантаженням через `IntersectionObserver`.

Статус: **draft** на web.

## Призначення

Використовуйте `Gallery` для відображення альбому, вкладень повідомлень або медіатеки фотографій та відео.
Не використовуйте `Gallery` для однієї ізольованої фотографії; використовуйте [Image](image.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна пряма геометрія). |
| Ширина стовпця за замовчуванням | `30 DU` мінімум в адаптивному режимі. |
| Проміжок | Стандартний проміжок `0.5 DU`. |
| Межа | Стандартна межа `0.25 DU` всередині кожної комірки. |

## Поведінка

* Зображення за межами області перегляду відкладають завантаження до перетину з областю перегляду через `IntersectionObserver`.
* Підтримує як гнучку адаптивну CSS-сітку, так і компактну розкладку вкладень чату у стилі Telegram.
* Відео відображають індикатор відтворення поверх мініатюри.
* Опціональний режим вибору додає прапорці до кожного елемента та генерує події зміни вибору.
* Натискання на елемент за замовчуванням відкриває повноекранний [GalleryViewer](gallery-viewer.md) на цьому елементі (`viewer = true`), а в режимі вибору перемикає вибір.
* Натискання на елемент викликає зворотний виклик `on_item_click` з індексом елемента.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `items` | signal Vec MediaItem | обов'язковий | Колекція медіаелементів для відображення. |
| `layout` | GalleryLayout | `Grid` | Режим розкладки (`Grid` або `Telegram`). |
| `column_min_width` | DU | `30.0` | Мінімальна ширина стовпця в DU для адаптивної сітки. |
| `gap` | DU | `0.5` | Відстань між елементами в DU. |
| `selectable` | bool | `false` | Вмикає режим вибору кількох елементів. |
| `viewer` | bool | `true` | Автоматично відкриває `GalleryViewer` при натисканні, якщо режим вибору неактивний. |
| `selected_ids` | HashSet string | порожній | Множина ідентифікаторів вибраних медіаелементів. |
| `on_selection_change` | callback HashSet | немає | Викликається при зміні вибору. |
| `on_item_click` | callback usize | немає | Викликається при натисканні на медіаелемент. |
| `empty_slot` | Slot | немає | Користувацький слот, коли список елементів порожній. |
| `empty_label` | string | `"No media items"` | Текст, що відображається за відсутності елементів. |
| `class` | string | немає | CSS-класи кореневого елемента. |
| `style` | string | немає | Вбудовані стилі кореневого елемента. |

## Кастомізація

| Проп метрики | Одиниця | Змінна | За замовчуванням |
| :--- | :--- | :--- | :--- |
| `column_min_width` | DU | `--op-gallery-column-min-width` | `30 DU` |
| `gap` | DU | `--op-gallery-gap` | `0.5 DU` |

| Змінна кольору | За замовчуванням |
| :--- | :--- |
| `--op-gallery-item-bg` | `var(--op-surface)` |
| `--op-gallery-border` | `var(--op-border)` |
| `--op-gallery-item-hover-border` | `var(--op-border-strong)` |

`class` та `style` застосовуються до кореневого контейнера.

## Доступність

Кожен елемент містить доступний альтернативний текст або назву.
Прапорці вибору мають доступні мітки.
Фокус клавіатури та кліки працюють передбачувано у всіх комірках сітки.
