# PullToRefresh

Сенсорний жест потягування вниз для асинхронного оновлення зі станами Operator.

Статус: **draft** у вебреалізації.

## Використання

Використовуйте PullToRefresh для підтримки жестів оновлення на мобільних і сенсорних пристроях.
Компонент виявляє рух вниз від самого верху контейнера, показує стан натягування та виконує асинхронну дію оновлення.

## Геометрія

| Властивість | Типове значення | Змінна |
| :--- | :--- | :--- |
| Поріг натягування | `15 DU` | `--op-pull-to-refresh-threshold` |

## Поведінка

* Спрацьовує лише тоді, коли прокручування контейнера перебуває на самому початку.
* Потягування вниз розкриває верхню область індикатора з опором.
* Якщо потягнути далі за поріг, стрілка повертається й підказує відпустити.
* Після відпускання за порогом запускається дія `on_refresh`.
* Під час оновлення показується спінер, а введення жестів блокується.
* Після завершення стан результату (Success або Error) відображається протягом періоду утримання перед поверненням у початковий стан.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `on_refresh` | `AsyncAction` | обов’язковий | Обробник виконання операції оновлення. |
| `enabled` | сигнал bool | `true` | Вмикає або вимикає відстеження жесту. |
| `threshold` | метрика DU | `15 DU` | Відстань натягування для запуску оновлення. |
| `pull_label` | рядок | `pull-to-refresh.pull` | Текст-підказка під час натягування. |
| `release_label` | рядок | `pull-to-refresh.release` | Текст-підказка при досягненні порогу. |
| `refreshing_label` | рядок | `pull-to-refresh.refreshing` | Текст статусу оновлення. |
| `puller` | слот | немає | Власний слот замість стандартного блоку індикатора. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |

| `threshold` | DU | `--op-pull-to-refresh-threshold` | `15 DU` |

## Тексти

| Ключ | Типовий текст (uk) | Опис |
| :--- | :--- | :--- |
| `pull-to-refresh.pull` | `Потягніть для оновлення` | Початкова підказка потягування. |
| `pull-to-refresh.release` | `Відпустіть для оновлення` | Підказка при досягненні порогу спрацьовування. |
| `pull-to-refresh.refreshing` | `Оновлення…` | Повідомлення під час активного оновлення. |
| `pull-to-refresh.success` | `Оновлено` | Повідомлення про успішне оновлення. |
| `pull-to-refresh.error` | `Помилка оновлення` | Повідомлення про помилку оновлення. |

## Доступність

* Тексти станів інформують користувачів про хід жесту та результат оновлення.
