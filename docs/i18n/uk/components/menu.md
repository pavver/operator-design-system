# Menu

Плавучий список команд.
Відкривається з кнопки додаткових дій (⋮) або як контекстне меню біля вказівника.

Статус: **чернетка** у вебреалізації.

## Використання

* Другорядні команди, що не потребують видимої кнопки.
* Команди для одного елемента списку або таблиці через правий клік чи довге натискання.
* Для вибору значення використовуйте [DropdownMenu](dropdown-menu.md); меню виконує команди.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Ширина | Від `45 DU` до `80 DU`, за найдовшим елементом. |
| Висота | За висотою вмісту, щонайбільше висота області перегляду мінус `8 DU`, далі прокручується. |
| Внутрішній відступ | `1 DU` над елементами та під ними. |
| Контур | Спільна рамка [Popover](popover.md), `0.25 DU` у кольорі `accent`, плюс м'яка тінь. |
| Елемент | Висота щонайменше `8 DU`, початковий внутрішній відступ `2 DU`, кінцевий `3 DU`. |
| Слот піктограми | `4 DU`, залишається порожнім для елементів без піктограми, щоб підписи вирівнювалися. |
| Сполучення клавіш | Стиль `caption`, `text_secondary`, у кінці. |
| Розділювач | `0.25 DU` у кольорі `divider` з відступом `1 DU` зверху та знизу. |
| Заголовок і нижній колонтитул | Відступи пунктів, `1 DU` зверху й знизу та розділювач `0.25 DU` у кольорі `divider` з боку пунктів. |
| Стрілка підменю | `chevron_right`, `4 DU`, `text_secondary`, у кінці елемента з підменю. |

## Елементи

* Типовий: `text_primary`, піктограма в `icon`.
* Небезпечна дія: підпис і піктограма в `error`; розміщуйте останньою, після розділювача.
* Вимкнений: `text_disabled`, не можна вибрати або сфокусувати.
* Наведення: тло `hover`.
* Клавіатурний фокус: рамка `0.5 DU` у кольорі `accent` усередині пункту й тло `hover`, як у [Станах](../foundations/states.md).

## Підменю

* Елемент із дочірніми елементами (`MenuItem::submenu`) відкриває підменю поруч із собою замість виконання команди.
* Підменю відкривається при наведенні, кліку або Arrow Right, вирівнюється до верху елемента, праворуч або, за браку місця, ліворуч.
* Елемент залишається підсвіченим, поки його підменю відкрите; наведення на інший елемент закриває його.
* Arrow Left закриває підменю й повертає фокус до його елемента.
* Вибір команди на будь-якому рівні закриває весь ланцюжок меню; натискання всередині будь-якого підменю не закриває батьківські меню.
* Підменю можуть бути вкладеними; обмежуйте глибину двома рівнями.
* Підменю переймають метричні пропи, кольори й слоти вмісту свого меню, крім `header` і `footer`, які обрамлюють лише кореневе меню.

## Розташування

* Із кнопки: під кнопкою, вирівнювання до її кінцевого краю; над нею, коли знизу бракує місця.
* Контекстне меню: біля вказівника, зі зміщенням для утримання в області перегляду.

## Поведінка

* Прокручування сторінки чи іншого контейнера поза меню закриває його; прокручування всередині меню — ні.
* Відкриття переносить фокус до першого ввімкненого елемента.
* Клавіші зі стрілками циклічно переміщують фокус між увімкненими елементами.
* Enter або клік виконує дію елемента й закриває меню.
* Escape, Tab, натискання зовні або зміна розміру вікна закриває меню.
* Кнопка додаткових дій показує контур `Selected`, поки її меню відкрите; повторне натискання закриває меню.
* З погляду меню команди виконуються синхронно.
  Асинхронна команда показує результат деінде, наприклад у [Toast](toast.md) або на відповідному рядку.
* Меню є шаром [Popover](popover.md): монтується в хості оверлеїв, тому предки з обрізанням або трансформаціями ніколи його не обрізають.

## API

Поля `MenuItem`: `id`, `label`, `icon`, `shortcut`, `danger`, `enabled`, `separator`.

| Компонент | Властивості |
| :--- | :--- |
| `Menu` | `open`, `anchor` (під елементом, у точці або поруч з елементом), `items`, `on_select(id)`, `label`, `parent_layer` (для підменю). |
| `MenuItem` | `new(id, label)`, `icon`, `shortcut`, `danger`, `disabled`, `separated`, `submenu(items)`. |
| `MenuButton` | `items`, `on_select(id)`, `icon` (`more_vert`), `label` (`"More actions"`), `size` (`8 DU`). |
| `ContextMenu` | `items`, `on_select(id)`, `children`: область, що відкриває меню. |

## Кастомізація

`class` і `style` застосовуються до плавучого шару меню; MenuButton і ContextMenu застосовують їх до коренів своїх елементів відкриття.
Метричні пропси записують відповідні змінні; явне оголошення `style` має перевагу.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `min_width` | DU | `--op-menu-min-width` | `45 DU` |
| `max_width` | DU | `--op-menu-max-width` | `80 DU` |
| `viewport_margin` | DU | `--op-menu-viewport-margin` | `margin_screen` |
| `shadow_y` | DU | `--op-menu-shadow-y` | `2 DU` |
| `shadow_blur` | DU | `--op-menu-shadow-blur` | `6 DU` |
| `gap` | DU | `--op-menu-gap` | `gutter` |
| `item_height` | DU | `--op-menu-item-height` | `row_compact` |
| `padding_end` | DU | `--op-menu-padding-end` | `pad_card` |
| `padding_start` | DU | `--op-menu-padding-start` | `gutter` |
| `icon_size` | DU | `--op-menu-icon-size` | `icon_small` |
| `shortcut_font_size` | TU | `--op-menu-shortcut-font-size` | `caption_size` |
| `padding_y` | DU | `--op-menu-padding-y` | `pad_tight` |
| `font_size` | TU | `--op-menu-font-size` | `body_size` |
| `line_height` | TU | `--op-menu-line-height` | `body_line` |
| `max_height` | DU | `--op-menu-max-height` | `calc(100vh - var(--op-menu-viewport-margin, margin_screen) * 2)` |
| `MenuButton.size` | DU | `--op-menu-button-size` | `row_compact` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-menu-background` | `surface` |
| `--op-menu-border` | `accent` |
| `--op-menu-shadow` | `rgb(0 0 0 / 35%)` |
| `--op-menu-text` | `text_primary` |
| `--op-menu-hover` | `hover` |
| `--op-menu-focus` | `accent` |
| `--op-menu-danger` | `error` |
| `--op-menu-disabled` | `text_disabled` |
| `--op-menu-icon` | `icon` |
| `--op-menu-secondary` | `text_secondary` |
| `--op-menu-divider` | `divider` |
| `--op-menu-pressed` | `pressed` |
| `--op-menu-ripple` | `ripple` |

| Слот | Розташування |
| :--- | :--- |
| `option` | Вміст `MenuItem` з областю видимості всередині наявної кнопки menuitem; зберігає поведінку клавіатури, вимкнення, небезпечних дій, вибору та підменю. |
| `empty` | Вміст за відсутності елементів. |
| `before_options` | Вміст перед прокручуваними елементами. |
| `after_options` | Вміст після прокручуваних елементів. |
| `header` | Над пунктами, з відступами пунктів і розділювачем знизу. |
| `footer` | Під пунктами, з відступами пунктів, розділювачем зверху й текстом `caption` у кольорі `text_secondary`. |

Метричні змінні, `class`, `style`, усі слоти меню та перевизначення піктограми підменю поширюються на кожне підменю.
Слот `option` замінює лише вміст рядка; не додавайте до нього вкладених інтерактивних елементів керування.

## Доступність

`menu` із дочірніми елементами `menuitem`; вимкнені елементи позначені `aria-disabled`.
Кнопка додаткових дій має `aria-haspopup` і `aria-expanded`.
