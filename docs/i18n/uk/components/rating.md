# Rating

Дискретна оцінка з попереднім переглядом вказівником і рухомим клавіатурним фокусом.
Дозволяє швидко візуально вибирати дискретну числову оцінку.
Розміщується безпосередньо на поверхні сторінки як вбудований елемент керування без власного фону або рамки.

Статус: **чернетка** у вебреалізації.

## Використання

* Збирання відгуків користувачів, рецензій або оцінок пріоритету.
* Відображення якісних оцінок елементів.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Розмір елемента | `row_compact` (`8 DU`). |
| Проміжок між елементами | `gap_micro` (`0.5 DU`). |
| Радіус заокруглення кутів | `0 DU`. |

## Поведінка

* Розміщується безпосередньо на поверхні сторінки без зовнішньої рамки або фону.
* Наведення на елементи показує попередній перегляд оцінки в реальному часі.
* Клік на елементі вибирає оцінку й запускає обробник фіксації.
* Клік на поточній вибраній оцінці скидає значення до нуля, якщо не активовано `no_reset`.
* Клавіатурний фокус створює кільце фокусу лише навколо зірки у фокусі.
* Клавіші зі стрілками збільшують або зменшують оцінку з рухомим фокусом.
* Під час очікування асинхронного збереження всередині вибраної зірки обертається малий спінер.
* Зворотний зв'язок успіху та збою відтворює спалах результату Operator на вибраній зірці.
* Невдале асинхронне збереження відкочує значення до попереднього з тією самою анімацією, що й зміна вперед.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал u32 | обов’язковий | Поточна оцінка. |
| `max` | u32 | `5` | Максимальна кількість елементів. |
| `readonly` | bool | `false` | Запобігає зміні значення. |
| `enabled` | bool | `true` | Вмикає введення. |
| `state` | `ControlState` | немає | Явне перевизначення стану елемента керування. |
| `on_change` | зворотний виклик `(u32)` | немає | Сповіщає про зміну значення. |
| `on_commit` | `AsyncAction<u32>` | немає | Асинхронний обробник фіксації з відкатом у разі помилки. |
| `no_reset` | bool | `false` | Забороняє скидання до нуля при кліку на поточному значенні. |
| `label` | string | `rating.label` | Доступний підпис групи. |
| `item_label` | string | `rating.item` | Рядок шаблону підпису кожного елемента. |
| `icon` | піктограма | `rating.icon` | Піктограма невибраних елементів. |
| `icon_selected` | піктограма | `rating.icon-selected` | Піктограма вибраних елементів. |
| `size` | метрика DU | `row_compact` | Ширина й висота кнопки елемента. |
| `gap` | метрика DU | `gap_micro` | Проміжок між елементами оцінки. |
| `leading` | `Slot` | немає | Слот перед елементами оцінки. |
| `trailing` | `Slot` | немає | Слот після елементів оцінки. |
| `content` | `Slot` | немає | Власний вміст усередині групи оцінки. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `size` | DU | `--op-rating-size` | `row_compact` (`8 DU`) |
| `gap` | DU | `--op-rating-gap` | `gap_micro` (`0.5 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-rating-background` | `transparent` |
| `--op-rating-text` | `text_secondary` |
| `--op-rating-accent` | `accent` |
| `--op-rating-hover` | `hover` |
| `--op-rating-focus` | `accent` |
| `--op-rating-pending` | `pending` |
| `--op-rating-success` | `success` |
| `--op-rating-error` | `error` |
| `--op-rating-disabled-text` | `text_disabled` |

| Слот | Розташування |
| :--- | :--- |
| `leading` | Перед елементами оцінки. |
| `trailing` | Після елементів оцінки. |
| `content` | Перед елементами всередині групи. |

`class` і `style` застосовуються до кореневого елемента radiogroup.

### Рядки

### Піктограми

## Доступність

Rating діє як доступна `radiogroup` з елементами-радіокнопками.
Клавіші зі стрілками циклічно переміщують фокус між елементами, а рухомий `tabindex` забезпечує передбачувану клавіатурну навігацію.
Індикатор клавіатурного фокусу відображається лише навколо зірки у фокусі.
