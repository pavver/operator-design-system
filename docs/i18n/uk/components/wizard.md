# Wizard

Багатокроковий майстер із номерами кроків, перевіркою кожного кроку та асинхронним завершенням.

Статус: **draft** у вебреалізації.

## Використання

Використовуйте Wizard для послідовних складних завдань, таких як створення облікового запису або налаштування системи.
Не плутайте цей компонент із числовим [Stepper](stepper.md), який призначений для регулювання чисел `- значення +`.

## Геометрія

| Властивість | Типове значення | Змінна |
| :--- | :--- | :--- |
| Розмір значка кроку | `8 DU` | `--op-wizard-step-size` |
| Відступ у заголовку | `2 DU` | `--op-wizard-header-gap` |
| Внутрішній відступ | `4 DU` | `--op-wizard-padding` |
| Відступ між блоками | `4 DU` | `--op-wizard-content-gap` |

## Поведінка

* Кроки показують номери або позначки завершення, з'єднані лініями.
* Користувачі можуть натискати на завершені кроки для повернення назад.
* Натискання кнопки «Далі» викликає необов'язковий зворотний виклик `on_validate_step` для поточного кроку.
* Якщо перевірка не вдається, повідомлення про помилку відображається під вмістом кроку, кнопка «Далі» блимає станом помилки, а майстер залишається на поточному кроці.
* Помилка валідації зникає, коли крок стає коректним або змінюється активний крок.
* Якщо перевірка успішна або відсутня, майстер переходить до наступного кроку.
* На останньому кроці кнопка «Завершити» виконує асинхронну дію зі станами Operator.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `steps` | `Vec<WizardStep>` | обов’язковий | Список кроків з ідентифікатором, назвою та підзаголовком. |
| `current` | сигнал rw-signal usize | обов’язковий | Індекс активного кроку (починаючи з 0). |
| `on_validate_step` | зворотний виклик `(usize) -> Result<(), String>` | немає | Перевіряє поточний крок перед переходом далі; повертає Ok(()) або Err(повідомлення). |
| `error` | сигнал rw-signal Option<String> | немає | Необов'язковий зовнішній сигнал повідомлення про помилку валідації. |
| `error_slot` | слот | немає | Власний слот для відображення помилки кроку замість стандартного. |
| `on_finish` | `AsyncAction` | немає | Асинхронна дія завершення на останньому кроці. |
| `next_label` | рядок | `wizard.next` | Текст кнопки переходу вперед. |
| `back_label` | рядок | `wizard.back` | Текст кнопки повернення назад. |
| `finish_label` | рядок | `wizard.finish` | Текст кнопки завершення. |
| `navigation` | слот | немає | Власний слот навігації замість стандартного рядка. |
| `header_gap` | метрика DU | `2 DU` | Проміжок між значком і підписами кроку. |
| `step_size` | метрика DU | `8 DU` | Розмір квадратного значка кроку. |
| `padding` | метрика DU | `4 DU` | Зовнішній відступ контейнера. |
| `content_gap` | метрика DU | `4 DU` | Вертикальний відступ між частинами майстра. |

## Доступність

* Список кроків позначено орієнтиром `role="region"` та `aria-label="Steps"`.
* Кнопка активного кроку має `aria-current="step"`.
* Квадратні значки кроків мають радіус заокруглення `0 DU`.
