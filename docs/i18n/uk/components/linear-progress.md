# LinearProgress

Горизонтальна смуга прогресу тривалої операції, як-от завантаження або сканування.

Статус: **reviewed** у вебреалізації.

## Використання

* Визначений прогрес: частка виконаної роботи відома.
* Невизначений прогрес: робота триває, але її обсяг невідомий.
* Усередині елемента керування надавайте перевагу контуру стану; смуга призначена для цілих представлень, карток і заголовків таблиць.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Товщина | Типово `1 DU`; довільне значення в DU, наприклад `0.5 DU` у заголовку таблиці або `6 DU` для виразної смуги. |
| Ширина | Повна ширина свого контейнера. |
| Доріжка | Колір смуги з непрозорістю 20% поверх `surface_alt`. |
| Зовнішній підпис значення | Необов'язковий, стиль `caption`, `text_secondary`, завширшки щонайменше `9 DU`, на відстані `2 DU` після смуги. |
| Внутрішній підпис значення | Починаючи з товщини `5 DU`, підпис центрується всередині смуги, стиль `caption`, жирний. |
| Кольори внутрішнього підпису | `text_primary` над доріжкою та `on_accent` над заповненням; підпис розділяється точно на межі заповнення. |
| Кути | `0 DU`. |

## Формат значення

* Відсотки: `54%`, типовий формат.
* Кількість: `543 / 1000`, значення й максимум; цілі числа без десяткових знаків, решта — із двома.
* Використовуйте кількість, коли одиниці важливі оператору, як-от файли, камери або мегабайти.

## Кольори

* Виконання: `pending`, оскільки прогрес означає роботу, що триває.
* Завершено: `success`.
* Збій: `error`; смуга зупиняється там, де стався збій.

## Рух

* Ширина визначеного прогресу змінюється за `state_color` (`150 ms`).
* Невизначений прогрес: сегмент завдовжки 35% доріжки проходить зліва направо раз на `pending_lap` (`2000 ms`) за плавною кривою.
* За налаштування зменшеного руху прохід відбувається зі зменшеною швидкістю, визначеною в [motion.md](../foundations/motion.md).

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | `0.0..max` | немає | Прогрес; відсутність означає невизначений прогрес. |
| `max` | number | `1.0` | Значення завершеної операції. |
| `state` | стан елемента керування | немає | `Success` або `Error` змінює колір смуги. |
| `show_value` | bool | `false` | Показує значення, усередині смуги — починаючи з товщини `5 DU`. |
| `format` | `Percent` або `Count` | `Percent` | Спосіб запису значення. |
| `thickness` | DU | `1.0` | Товщина смуги. |
| `label` | string | `linear-progress.label` | Доступна назва. |
| `gap` | DU | `2.0` | Проміжок між доріжкою та підписом значення. |
| `value_min_width` | DU | `9.0` | Мінімальна ширина підпису значення. |
| `value_slot` | слот | немає | Слот власного підпису значення. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `thickness` | DU | `--op-linear-progress-thickness` | `1 DU` |
| `gap` | DU | `--op-linear-progress-gap` | `gutter` (`2 DU`) |
| `value_min_width` | DU | `--op-linear-progress-value-min-width` | `9 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-linear-progress-bar` | `pending` |
| `--op-linear-progress-track` | `color-mix(in srgb, var(--bar) 20%, surface_alt)` |
| `--op-linear-progress-success` | `success` |
| `--op-linear-progress-error` | `error` |
| `--op-linear-progress-value-color` | `text_secondary` |
| `--op-linear-progress-inner-track-text` | `text_primary` |
| `--op-linear-progress-inner-fill-text` | `on_accent` |

| Слот | Розташування |
| :--- | :--- |
| `value_slot` | Власний підпис значення замість форматованого тексту прогресу. |

`class` і `style` застосовуються до кореня.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |

## Доступність

Доріжка має роль `progressbar` із `aria-valuenow` і `aria-valuemax` в одиницях `value` для визначеного прогресу.
`aria-valuetext` містить підпис у тому самому вигляді, що й на екрані, тому формат кількості оголошується як записано.
Копії внутрішнього підпису приховані від допоміжних технологій.
