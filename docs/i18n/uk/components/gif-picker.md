# GifPicker

Панель вибору анімованих GIF-кліпів із циклічним відтворенням та автопаузою через IntersectionObserver.
Кліпи транслюються як зациклені відео MP4/WebM і автоматично призупиняються при виході за межі видимої області.

Статус: **draft** на web.

## Застосування

Використовуйте `GifPicker` у полях введення чату, діалогах реакцій та формах коментарів.
Кліпи та список популярних тегів повністю надаються хост-застосунком.
Компонент рендерить енергоефективні беззвучні зациклені відео замість застарілих ресурсномістких растрових файлів `.gif`.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` контурна рамка. |
| Висота контейнера | `60 DU` (`--op-gif-picker-height`). |
| Висота комірки | `30 DU` (`--op-gif-picker-cell-height`). |

## Поведінка

* Відео автоматично відтворюються без звуку в циклі при появі у зоні видимості.
* `IntersectionObserver` ставить на паузу невидимі відео для економії ресурсів процесора.
* Натискання тегу фільтрує список за цим тегом, повторне натискання скидає фільтр.
* Вибір кліпу викликає зворотний виклик `on_select` із даними `GifItem`.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `on_select` | `Callback<GifItem>` | немає | Подія вибору елемента GIF. |
| `gifs` | `Option<Vec<GifItem>>` | немає | Колекція кліпів від хост-застосунку. |
| `trending_tags` | `Option<Vec<String>>` | немає | Список швидких тегів від застосунку. |
| `height` | `f32` | `60.0` | Висота контейнера в Design Units. |
| `cell_height` | `f32` | `30.0` | Висота комірки в Design Units. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Налаштування

### Метричні параметри

| Параметр | Змінна CSS | За замовчуванням | Одиниця |
| :--- | :--- | :--- | :--- |
| `height` | `--op-gif-picker-height` | `60.0` | DU |
| `cell_height` | `--op-gif-picker-cell-height` | `30.0` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-gif-picker-bg` | `var(--op-surface)` | Фон панелі. |
| `--op-gif-picker-border` | `var(--op-border)` | Рамка панелі. |
| `--op-gif-picker-accent` | `var(--op-accent)` | Активний тег та рамка виділення. |
| `--op-gif-picker-text` | `var(--op-text-primary)` | Колір тексту заголовків. |

## Рядки

| Ключ | Англійський текст | Опис |
| :--- | :--- | :--- |
| `gif-picker.search` | `"Search GIFs..."` | Підказка в полі пошуку. |
| `gif-picker.tags` | `"Trending GIF tags"` | Доступна назва панелі тегів. |
| `gif-picker.empty` | `"No GIFs found"` | Текст відсутності результатів. |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |

## Доступність

* Відеоролики є беззвучними (`muted`) та циклічними (`loop playsinline`).
* Кожна комірка містить доступний підпис назви кліпу.
