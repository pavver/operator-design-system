# GifPicker

Компонент вибору зациклених відеокліпів із популярними тегами та керуванням паузою у полі зору.
GIF-елементи відображаються як короткі зациклені відеокліпи MP4/WebM і призупиняються при виході з поля зору за допомогою `IntersectionObserver`.

Статус: **draft** на web.

## Застосування

Використовуйте `GifPicker` у медіа-клавіатурах чату, панелях реакцій та діалогах повідомлень.
Справжні файли `.gif` повільно декодуються та навантажують процесор; сучасні клієнти транслюють зациклені беззвучні відеокліпи.
Компонент автоматично призупиняє кліпи, які виходять за межі видимої області прокручування.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` контурна рамка контейнера. |
| Висота за замовчуванням | `60 DU` (`--op-gif-picker-height`). |
| Висота комірки | `30 DU` (`--op-gif-picker-cell-height`). |

## Поведінка

* Клік на популярний тег фільтрує сітку за тематичним ключовим словом.
* Пошуковий запит фільтрує одночасно заголовки та теги.
* `IntersectionObserver` відстежує вихід відеоелементів за межі видимості та призупиняє їх.
* При поверненні комірки у поле зору відтворення плавно поновлюється.
* Клік на комірку обирає елемент через зворотний виклик `on_select`.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `on_select` | `Callback<GifItem>` | немає | Подія вибору елемента GIF. |
| `gifs` | `Option<Vec<GifItem>>` | немає | Колекція зациклених відеокліпів. |
| `trending_tags` | `Option<Vec<String>>` | немає | Список кнопок популярних тегів. |
| `height` | `f32` | `60.0` | Висота контейнера в Design Units. |
| `cell_height` | `f32` | `30.0` | Висота комірки в Design Units. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |

| `--op-gif-picker-accent` | `var(--op-color-accent)` | Активний тег та рамка виділення. |

## Доступність

* Відеокліпи завжди беззвучні (`muted`) та відтворюються зациклено (`loop playsinline`).
* Кожна комірка має текстовий підпис назви кліпу для зчитувачів екрана.
