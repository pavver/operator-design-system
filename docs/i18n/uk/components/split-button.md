# SplitButton

Кнопка основної дії з приєднаною кнопкою перемикання, яка відкриває стос додаткових дій.
Клік на основній кнопці запускає типову дію, а кнопка перемикання відкриває [ActionStack](action-stack.md) під усім елементом керування.

Статус: **reviewed** у вебреалізації.

## Використання

* Групування пов'язаних дій в одному візуальному елементі керування за браку місця.
* Швидкий доступ до основної дії зі збереженням доступності альтернативних команд.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Висота | `row_standard` (`10 DU`). |
| Ширина кнопки перемикання | `row_standard` (`10 DU`). |
| Розмір піктограми | `icon_small` (`4 DU`). |
| Радіус заокруглення кутів | `0 DU`. |

## Поведінка

* Основна кнопка запускає основну дію зі станами [ActionButton](action-button.md).
* Кнопка перемикання — це піктограмна кнопка відкриття [ActionStack](action-stack.md), прив'язаного до всього елемента керування.
* Стос типово відкривається знизу, вирівняний за початковим краєм елемента керування, і дотримується правил розміщення, прокручування й закриття [ActionStack](action-stack.md).
* Кожна додаткова дія показує власне очікування, успіх і помилку, а після успіху стос закривається.
* Поки виконується основна дія, кнопка перемикання вимкнена; поки виконується додаткова дія, вимкнена основна кнопка.
* Коли елемент керування вимкнений або `state` має значення очікування чи вимкнення, кнопка перемикання неактивна.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `actions` | `Vec<ActionStackItem>` | обов’язковий | Додаткові дії в стосі. |
| `on_click` | `AsyncAction` | немає | Обробник основної дії. |
| `text` | string | `split-button.text` | Підпис основної кнопки. |
| `enabled` | bool | `true` | Вмикає взаємодію. |
| `state` | `ControlState` | немає | Явний стан основної кнопки. |
| `toggle_label` | string | `split-button.toggle` | Доступна назва й підказка кнопки перемикання. |
| `toggle_icon` | піктограма | `split-button.toggle` | Піктограма кнопки перемикання. |
| `side` | `LayerSide` | `Below` | Бажана сторона стосу. |
| `align` | `LayerAlign` | `Start` | Бажане вирівнювання стосу відносно елемента керування. |
| `height` | метрика DU | `row_standard` | Висота всього елемента керування. |
| `toggle_size` | метрика DU | `row_standard` | Ширина кнопки перемикання. |
| `icon_size` | метрика DU | `icon_small` (`4 DU`) | Розмір піктограми кнопки перемикання. |
| `leading` | `Slot` | немає | Початковий слот в основній кнопці. |
| `trailing` | `Slot` | немає | Кінцевий слот в основній кнопці. |
| `content` | `Slot` | немає | Замінює текст основної кнопки. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-split-button-height` | `row_standard` (`10 DU`) |
| `toggle_size` | DU | `--op-split-button-toggle-size` | `row_standard` (`10 DU`) |
| `icon_size` | DU | `--op-split-button-icon-size` | `icon_small` (`4 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-split-button-text` | `inherit` |
| `--op-split-button-background` | `surface` |

Кнопка перемикання бере кольори наведення, фокуса й вимкнення з [IconButton](icon-button.md), а стос — змінні [ActionStack](action-stack.md).

| Слот | Розташування |
| :--- | :--- |
| `leading` | Початкова область основної кнопки. |
| `trailing` | Кінцева область основної кнопки. |
| `content` | Власний вміст замість основного тексту. |

`class` та `style` застосовуються до кореневого елемента.

## Доступність

Кнопка перемикання має `aria-haspopup="menu"`, повідомляє `aria-expanded` і використовує `toggle_label` як доступну назву й підказку.
Стос — це `menu` з діями `menuitem` і клавіатурною підтримкою [ActionStack](action-stack.md): стрілки вниз і вгору на кнопці перемикання відкривають його, стрілки, Home і End переходять між діями, а Escape чи Tab закривають.
