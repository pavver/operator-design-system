# SplitButton

Кнопка основної дії з приєднаною кнопкою перемикання меню.
Клік на основній кнопці виконує типову дію, а клік на приєднаній кнопці відкриває прикріплене меню додаткових дій.

Статус: **чернетка** у вебреалізації.

## Використання

* Групування пов'язаних дій в одному візуальному елементі керування за браку місця.
* Швидкий доступ до основної дії зі збереженням доступності альтернативних команд.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Висота | `row_standard` (`10 DU`). |
| Ширина кнопки перемикання | `row_standard` (`10 DU`). |
| Розмір піктограми | `icon_small` (`4 DU`). |
| Радіус заокруглення кутів | `0 DU`. |

## Поведінка

* Основна кнопка безпосередньо запускає основну дію.
* Приєднана кнопка відкриває або закриває прикріплене меню.
* Arrow Down на кнопці перемикання відкриває меню.
* Коли елемент керування вимкнений або очікує завершення, і основна дія, і кнопка перемикання неактивні.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `items` | `Vec<MenuItem>` | обов’язковий | Дії, що відображаються в меню вибору. |
| `on_select` | зворотний виклик `(String)` | обов’язковий | Передає ідентифікатор вибраного елемента меню. |
| `on_click` | `AsyncAction` | немає | Обробник основної дії. |
| `text` | string | `split-button.text` | Підпис основної кнопки. |
| `enabled` | bool | `true` | Вмикає взаємодію. |
| `state` | `ControlState` | немає | Явне перевизначення стану елемента керування. |
| `toggle_label` | string | `split-button.toggle` | Доступна назва кнопки перемикання меню. |
| `toggle_icon` | піктограма | `split-button.toggle` | Семантична піктограма кнопки перемикання меню. |
| `height` | метрика DU | `row_standard` | Висота всього елемента керування. |
| `toggle_size` | метрика DU | `row_standard` | Ширина кнопки перемикання. |
| `icon_size` | метрика DU | `icon_small` | Розмір піктограми кнопки перемикання. |
| `leading` | `Slot` | немає | Початковий слот в основній кнопці. |
| `trailing` | `Slot` | немає | Кінцевий слот в основній кнопці. |
| `content` | `Slot` | немає | Замінює текст основної кнопки. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-split-button-height` | `row_standard` (`10 DU`) |
| `toggle_size` | DU | `--op-split-button-toggle-size` | `row_standard` (`10 DU`) |
| `icon_size` | DU | `--op-split-button-icon-size` | `icon_small` (`4 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-split-button-text` | `inherit` |
| `--op-split-button-background` | `surface` |
| `--op-split-button-border` | `border` |
| `--op-split-button-hover` | `hover` |
| `--op-split-button-accent` | `accent` |
| `--op-split-button-disabled-text` | `text_disabled` |

| Слот | Розташування |
| :--- | :--- |
| `leading` | Початкова область основної кнопки. |
| `trailing` | Кінцева область основної кнопки. |
| `content` | Власний вміст замість основного тексту. |

`class` та `style` застосовуються до кореневого елемента.

### Рядки

| `split-button.text` | `Action` |

### Піктограми

| Ключ | Типове значення |
| :--- | :--- |
| `split-button.toggle` | `arrow_drop_down` |

## Доступність

Кнопка перемикання має `aria-haspopup="menu"` і повідомляє `aria-expanded`.
Клавіатурна навігація стрілками на кнопці перемикання відкриває меню.
