# Knob

Круглий елемент керування значенням із захопленням вказівника та кроковою зміною з клавіатури.
Дозволяє радіальне налаштування неперервних або дискретних числових значень.

Статус: **чернетка** у вебреалізації.

## Використання

* Регулятори звуку, вимірювальні прилади й компактне налаштування параметрів.
* Обертове регулювання на сенсорних екранах та екранах із вказівником.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Розмір | `24 DU`. |
| Товщина штриха | `pad_small` (`1.5 DU`). |
| Форма | Кругла межа. Дозволено виняток для круглої форми. |

## Поведінка

* Перетягування навколо центра змінює значення радіально.
* Захоплення вказівника забезпечує неперервне перетягування поза межами елемента керування.
* Клавіші зі стрілками змінюють значення на `step`.
* Page Up і Page Down змінюють значення на 10 кроків.
* Home і End встановлюють мінімум і максимум.
* Асинхронна дія фіксації виконується після відпускання вказівника або зміни з клавіатури.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал f32 | обов’язковий | Поточне числове значення. |
| `min` | f32 | `0.0` | Мінімальне дозволене значення. |
| `max` | f32 | `100.0` | Максимальне дозволене значення. |
| `step` | f32 | `1.0` | Крок зміни. |
| `readonly` | bool | `false` | Забороняє зміну значення. |
| `enabled` | bool | `true` | Вмикає взаємодію. |
| `state` | `ControlState` | немає | Явне перевизначення стану елемента керування. |
| `on_change` | зворотний виклик `(f32)` | немає | Сповіщає про оновлення значення. |
| `on_commit` | `AsyncAction<f32>` | немає | Асинхронна фіксація після відпускання з відкатом у разі помилки. |
| `label` | string | `knob.label` | Доступний підпис повзунка. |
| `size` | метрика DU | `24 DU` | Діаметр круглого елемента керування. |
| `thickness` | метрика DU | `pad_small` | Товщина штриха доріжки та дуги. |
| `font_size` | метрика TU | `type_body_size` | Розмір шрифту центрованого тексту. |
| `content` | `Slot` | немає | Власний центральний вміст замість типового показу значення. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `size` | DU | `--op-knob-size` | `24 DU` |
| `thickness` | DU | `--op-knob-thickness` | `pad_small` (`1.5 DU`) |
| `font_size` | TU | `--op-knob-font-size` | `type_body_size` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-knob-text` | `text_primary` |
| `--op-knob-background` | `surface` |
| `--op-knob-border` | `border` |
| `--op-knob-accent` | `accent` |
| `--op-knob-disabled-text` | `text_disabled` |

| Слот | Розташування |
| :--- | :--- |
| `content` | Замінює центрований показ тексту. |

`class` та `style` застосовуються до кореневого елемента.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `knob.label` | `Value` |

### Піктограми

Knob не визначає вбудованих піктограм.

## Доступність

Knob має роль `slider` із `aria-valuemin`, `aria-valuemax` та `aria-valuenow`.
Клавіші зі стрілками та клавіші сторінок надають стандартне доступне керування значенням.
