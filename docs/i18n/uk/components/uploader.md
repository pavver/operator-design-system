# Uploader

Черга файлів із наданими застосунком future завантаження та прогресом для кожного файлу.
Координує вибір файлів, повідомлення відсотка завантаження, повторні спроби та вилучення елементів.

Статус: **чернетка** у вебреалізації.

## Використання

* Пакетне завантаження файлів у хмару або на віддалену кінцеву точку.
* Детальний прогрес для кожного файлу та відновлення після збоїв.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Проміжок | `gap_small` (`2 DU`). |
| Внутрішній відступ | `0 DU`. |
| Радіус заокруглення кутів | `0 DU`. |

## Поведінка

* Вбудований [FileField](file-field.md) приймає вибрані та скинуті файли.
* Клік на завантаженні виконує асинхронний обробник для кожного файлу зі зворотним викликом повідомлення прогресу.
* Під час завантаження окремі лінійні смуги прогресу відображають поточні частки.
* Невдалі елементи показують повідомлення про помилки та кнопку повторної спроби.
* Вилучення елемента скасовує його спробу завантаження та вилучає зі списку.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `on_upload` | `AsyncAction<UploadRequest>` | обов’язковий | Обробник завантаження, що отримує файл і зворотний виклик прогресу. |
| `files` | `RwSignal<Vec<PickedFile>>` | внутрішній | Сигнал із вибраними файлами. |
| `enabled` | bool | `true` | Вмикає дії завантаження. |
| `accept` | string | немає | Фільтр MIME-типів і розширень файлів. |
| `label` | string | `uploader.label` | Доступний заголовок розділу завантажувача. |
| `upload_label` | string | `uploader.upload` | Підпис кнопки дії завантаження. |
| `retry_label` | string | `uploader.retry` | Підпис кнопок повторної спроби для невдалих елементів. |
| `remove_label` | string | `uploader.remove` | Підпис кнопок вилучення елементів. |
| `empty_label` | string | `uploader.empty` | Повідомлення для порожньої черги. |
| `on_change` | зворотний виклик `(Vec<PickedFile>)` | немає | Сповіщає про зміни списку файлів. |
| `on_complete` | зворотний виклик `((u64, ActionResult))` | немає | Сповіщає про завершення окремого завантаження. |
| `row` | `ScopedSlot<(PickedFile, UploadStatus)>` | немає | Власний засіб рендерингу рядка черги файлів. |
| `header` | `Slot` | немає | Слот вмісту заголовка над полем файлів. |
| `actions` | `Slot` | немає | Слот власних кнопок дій. |
| `footer` | `Slot` | немає | Слот вмісту нижньої частини під списком черги. |
| `gap` | метрика DU | `gap_small` | Проміжок між елементами та розділами. |
| `padding` | метрика DU | немає | Необов'язковий внутрішній відступ навколо завантажувача. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `gap` | DU | `--op-uploader-gap` | `gap_small` (`2 DU`) |
| `padding` | DU | `--op-uploader-padding` | `0 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-uploader-background` | `surface` |
| `--op-uploader-text` | `text_primary` |

| Слот | Розташування |
| :--- | :--- |
| `header` | Перед полем файлів. |
| `actions` | Між полем файлів і списком черги. |
| `footer` | Під списком файлів. |
| `row` | Слот з областю видимості, що перевизначає кожен елемент рядка черги. |

`class` і `style` застосовуються до кореневого елемента section.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `uploader.label` | `Upload files` |
| `uploader.upload` | `Upload` |
| `uploader.retry` | `Retry` |
| `uploader.remove` | `Remove` |
| `uploader.empty` | `No files selected` |

### Піктограми

Uploader повторно використовує піктограми FileField і LinearProgress.

## Доступність

Корінь відображає доступний `section` із `aria-label`.
Кожен рядок завантаження повідомляє стани прогресу та збою через `role="status"` і доступні кнопки дій.
