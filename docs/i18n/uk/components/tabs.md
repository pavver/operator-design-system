# Tabs

Перемикає між представленнями одного рівня, як-от чатами та функціями на головному екрані.

Статус: **reviewed** у вебреалізації.

## Варіанти

### Folder

Варіант головного екрана Android.
Неактивні вкладки розташовані в панелі `surface_alt` із `0.25 DU` у кольорі `border`.
Активна вкладка вирізана з панелі: має колір `background` вмісту під нею, контур `0.5 DU` у кольорі `accent` зверху та з боків і не має нижнього краю.
Базова лінія `0.5 DU` у кольорі `accent` проходить під усією панеллю, тому активна вкладка відкривається у вміст як тека.

### Line

`0.25 DU` у кольорі `divider` під вкладками та підкреслення `0.5 DU` у кольорі `accent` під активною вкладкою.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Висота вкладки | `10 DU`. |
| Внутрішній відступ вкладки | `2.5 DU` по горизонталі; ширина відповідає підпису. |
| Підпис | Розмір `caption`, великі літери, середня насиченість; жирний `accent` в активному стані, `text_secondary` в інших. |
| Піктограма | `icon_small` (`4 DU`), на відстані `1 DU` перед підписом. |
| Лічильник | Після підпису, мінімальна ширина `4 DU`; фон `accent` на активній вкладці. |
| Заповнення | Необов'язково: вкладки порівну ділять усю ширину. |

## Поведінка

* Активна поверхня (folder) або підкреслення (line) лінійно ковзає до нової вкладки за `segment_slide` (`150 ms`), як кожен рухомий індикатор, і змінює розмір до її ширини.
* Колір підпису змінюється за той самий час.
* Вкладки, що не вміщуються, прокручуються горизонтально без видимої смуги прокручування.
* Компонент лише перемикає вибір; панель відображає викликач.
  Із пейджером викликач може керувати індикатором через зміщення прокручування, як це робить застосунок Android.

## API

Поля `TabItem`: `label`, `icon`, `count` (прихований при нулі).

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `items` | список елементів вкладок | обов’язковий | Вкладки. |
| `selected` | сигнал індексу | обов’язковий | Активна вкладка. |
| `variant` | Folder або Line | Folder | Стиль. |
| `fill` | bool | `false` | Однакова ширина на весь рядок. |
| `label` | string | `tabs.label` | Доступна назва списку вкладок. |
| `height` | DU | `row_standard` | Висота вкладки. |
| `padding_x` | DU | `pad_content` | Горизонтальний внутрішній відступ вкладки. |
| `gap` | DU | `pad_tight` | Проміжок між піктограмою та підписом. |
| `font_size` | TU | `type_caption_size` | Розмір шрифту підпису. |
| `count_min_width` | DU | `4 DU` | Мінімальна ширина бейджа лічильника. |
| `count_padding_x` | DU | `pad_tight` | Горизонтальний внутрішній відступ бейджа лічильника. |
| `indicator_thickness` | DU | `border_thick` | Товщина лінії індикатора. |
| `option` | слот з областю видимості | немає | Власний рендеринг кожної вкладки. |
| `before_options` | слот | немає | Вміст перед списком вкладок. |
| `after_options` | слот | немає | Вміст після списку вкладок. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-tabs-height` | `row_standard` |
| `padding_x` | DU | `--op-tabs-padding-x` | `pad_content` |
| `gap` | DU | `--op-tabs-gap` | `pad_tight` |
| `font_size` | TU | `--op-tabs-font-size` | `type_caption_size` |
| `count_min_width` | DU | `--op-tabs-count-min-width` | `4 DU` |
| `count_padding_x` | DU | `--op-tabs-count-padding-x` | `pad_tight` |
| `indicator_thickness` | DU | `--op-tabs-indicator-thickness` | `border_thick` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-tabs-text` | `text_secondary` |
| `--op-tabs-text-hover` | `text_primary` |
| `--op-tabs-text-active` | `accent` |
| `--op-tabs-count-background` | `surface_alt` |
| `--op-tabs-count-text` | `text_secondary` |
| `--op-tabs-count-active-background` | `accent` |
| `--op-tabs-count-active-text` | `on_accent` |
| `--op-tabs-divider` | `divider` |
| `--op-tabs-indicator-color` | `accent` |
| `--op-tabs-dock-background` | `surface_alt` |
| `--op-tabs-dock-border` | `border` |
| `--op-tabs-active-background` | `background` |

| Слот | Розташування |
| :--- | :--- |
| `option` | Слот з областю видимості замість типового вмісту вкладки. |
| `before_options` | Перед списком вкладок. |
| `after_options` | Після списку вкладок. |

`class` і `style` застосовуються до кореневого елемента вкладок.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `tabs.label` | `Tabs` |

### Піктограми

Tabs не має вбудованих семантичних піктограм.

## Доступність

* `tablist` із елементами `tab` та `aria-selected`.
* Одна зупинка Tab на активній вкладці; стрілки Left і Right, Home та End переміщують і вибирають.
