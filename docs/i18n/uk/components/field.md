# Field

Спільна оболонка для всіх текстових полів введення: підпис, поле з контуром стану та слотами, рядок підказки або помилки.
На ній побудовано TextField, SearchField, поля значень і Combobox; застосунок може обгорнути нею власний елемент керування, щоб він виглядав як нативне поле.

Статус: **чернетка** у вебреалізації.

## Геометрія

| Частина | Значення |
| :--- | :--- |
| Висота поля | `--op-field-height`, типово `row_standard` (`10 DU`). |
| Внутрішні відступи поля | `--op-field-padding-x` з обох боків, типово `pad_card`; без відступу після кінцевої кнопки на всю висоту. |
| Підпис | Стиль `caption` у кольорі `text_secondary` над полем; `accent`, коли поле у фокусі. |
| Підказка, помилка | Стиль `caption` під полем; помилка використовує `error` і малює стандартний контур `error` на полі. |
| Проміжки | `--op-field-gap` між підписом, рядком і підказкою та між полем і слотами `before`/`after`, типово `gap_micro`. |
| Внутрішні слоти | `prepend` і `append` розташовані всередині поля з відступом `pad_tight` до елемента керування. |

## Варіанти

| Варіант | Вигляд |
| :--- | :--- |
| `outlined` | `--op-field-background` (`surface`) із контуром стану. |
| `borderless` | Без фону й базового контуру у стані спокою або вимкненому стані; контури фокусу та результату залишаються видимими. Для полів у комірках таблиць, рядках властивостей і рядках нод. |

## Поведінка

* Поле показує стан елемента керування за описом у [states.md](../foundations/states.md): фокус, вимкнення, очікування (рухомий сегмент), успіх і помилка.
* Явний `error` зберігає контур у варіанті без рамки, зокрема у стані спокою або вимкненому стані.
* `error` замінює `hint`; обидва оголошуються (`role="alert"` для помилки).
* Поле ніколи не володіє значенням; ним володіє обгорнутий елемент керування.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| children | view | обов’язковий | Елемент керування, зазвичай `<input class="op-field-input">`. |
| `state` | сигнал стану елемента керування | обов’язковий | Стан, показаний контуром. |
| `label` | string | немає | Текст над полем. |
| `hint` | string | немає | Текст під полем. |
| `error` | string | немає | Текст помилки під полем. |
| `variant` | `outlined`, `borderless` | `outlined` | Вигляд поля. |
| `trailing` | сигнал bool | `false` | Поле завершується кнопкою на всю висоту (без кінцевого внутрішнього відступу). |
| `pending_run` | bool | `false` | Малює рухомий сегмент очікування. |
| `role` | string | немає | Роль ARIA поля. |
| `box_class` | string | немає | Додатковий клас поля для компонентів на основі Field. |
| `metrics` | `FieldMetrics` | не встановлено | Перевизначення метрик, див. нижче. |

## Кастомізація

| Метрика | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-field-height` | `row_standard` |
| `padding_x` | DU | `--op-field-padding-x` | `pad_card` |
| `slot_size` | DU | `--op-field-slot-size` | `row_standard` |
| `gap` | DU | `--op-field-gap` | `gap_micro` |
| `font_size` | TU | `--op-field-font-size` | `type_body_size` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-field-background` | `surface` |
| `--op-field-text` | `text_primary` |

| Слот | Розташування |
| :--- | :--- |
| `prepend`, `append` | Усередині поля, перед елементом керування та після нього. |
| `before`, `after` | Зовні поля, у тому самому рядку. |
| `label_slot` | Замінює підпис. |
| `hint_slot` | Замінює рядок підказки та помилки. |

`class` і `style` застосовуються до кореня.

## Доступність

* Обгорнутий елемент керування має доступну назву; компоненти на основі Field використовують видимий `label`, коли його встановлено.
* Рядок помилки має `role="alert"`.

## Живі приклади

Демонстрація Field показує підпис і підказку, помилку, оформлення без рамки, усі чотири навколишні слоти та власний нативний повзунок.
