# Toast

Коротке повідомлення біля краю екрана про те, що щойно сталося.
Це місце для тексту помилки, який елемент керування не може показати власним контуром.

Статус: **reviewed** у вебреалізації.

## Використання

* Підтвердження фонової дії без видимого елемента керування, наприклад «Налаштування збережено».
* Повідомлення причини невдалої асинхронної дії: елемент керування пульсує червоним, а toast пояснює чому.
* Одна швидка наступна дія, як-от скасування або повторення спроби.
* Не використовуйте toast для інформації, на яку користувач має відреагувати перед продовженням; використовуйте [Dialog](dialog.md) або [Banner](banner.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Позиція | Одна із шести позицій: угорі або внизу, кожна на початку, по центру або в кінці; на відстані `4 DU` від країв області перегляду. |
| Типова позиція | Унизу по центру. |
| Ширина | `min(105 DU, viewport − 8 DU)`. |
| Висота | Щонайменше `12 DU`; зростає з переносами тексту. |
| Внутрішній відступ | `1 DU` по вертикалі, `3 DU` на початку, `1 DU` у кінці. |
| Початкова смуга | `0.5 DU` у кольорі тону. |
| Контур | `0.25 DU` у кольорі `border` плюс м'яка тінь. |
| Піктограма | `8 DU`, колір тону. |
| Високе компонування | Від 4 рядків перенесеного тексту: заголовок із піктограмою, назвою тону (великими літерами у стилі `caption`, колір тону), дією та кнопкою закриття; текст займає всю ширину нижче, нижній внутрішній відступ `3 DU`. |
| Кнопки | Дія та закриття мають висоту `8 DU`; дія — підпис великими літерами у стилі `caption` в кольорі `accent`. |
| Стос | До 3 повідомлень із проміжком `2 DU`; найстаріше вилучається першим. |
| Порядок | Найновіше повідомлення найближче до краю області перегляду: унизу нижнього стосу, угорі верхнього. |

## Тони

| Тон | Колір | Піктограма | Роль |
| :--- | :--- | :--- | :--- |
| Інформація | `info` | `info` | Нейтральні новини. |
| Успіх | `success` | `check_circle` | Підтверджений результат. |
| Попередження | `warning` | `warning` | Увага без збою. |
| Помилка | `error` | `error` | Збій із причиною. |

## Поведінка

* Повідомлення залишається на `toast_duration` (`4000 ms`); повідомлення про помилки — на `toast_error_duration` (`8000 ms`).
* Поки вказівник над повідомленням, його таймер призупинений; коли час вичерпано, повідомлення закривається після виходу вказівника за межі.
* Дія виконує свій обробник і закриває повідомлення.
* Кнопка закриття закриває негайно.
* Повідомлення рахує рядки перенесеного тексту й переходить до високого компонування при 4 або більше рядках.
* Повертається назад лише при 2 або менше рядках, оскільки високе компонування надає тексту більше ширини.
* Підрахунок слідує за змінами ширини та масштабуванням тексту.
* Поява: проявлення й переміщення на `2 DU` від найближчого краю за `150 ms`; зникнення відтворює рух навпаки.
* Позиція задається на хості й може змінюватися під час виконання; уже показані повідомлення рухаються разом зі стосом.
* Повідомлення створюються через дескриптор toaster, який надає хост у корені застосунку.
* `report(result, what)` показує повідомлення про помилку для невдалого результату й нічого не робить при успіху.

## API

| Елемент | Опис |
| :--- | :--- |
| `ToastHost` | Обгортає застосунок; надає toaster і відображає стос у початковій позиції. |
| `ToastPosition` | `TopStart`, `TopCenter`, `TopEnd`, `BottomStart`, `BottomCenter` (типово), `BottomEnd`. |
| `set_position(position)` | Переміщує стос. |
| `use_toaster()` | Повертає toaster або нічого поза хостом. |
| `show(spec)` | Показує повідомлення, описане тоном, текстом, необов'язковою дією та необов'язковою тривалістю; повертає його ідентифікатор. |
| `message(tone, text)` | Скорочення без дії. |
| `report(result, what)` | Повідомлення про помилку «`what` failed: reason» для невдалого результату. |
| `dismiss(id)` | Закриває повідомлення. |

## Кастомізація

`class` і `style` застосовуються до стосу ToastHost або контейнера окремого Toast.
Метричні пропси записують відповідні змінні; явне оголошення `style` має перевагу.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `shift` | DU | `--op-toast-shift` | `2 DU` |
| `viewport_margin` | DU | `--op-toast-viewport-margin` | `margin_screen` |
| `gap` | DU | `--op-toast-gap` | `gutter` |
| `width` | DU | `--op-toast-width` | `105 DU` на хості; `100%` для окремого повідомлення |
| `min_height` | DU | `--op-toast-min-height` | `row_control` |
| `padding_y` | DU | `--op-toast-padding-y` | `pad_tight` |
| `padding_start` | DU | `--op-toast-padding-start` | `pad_card` |
| `shadow_blur` | DU | `--op-toast-shadow-blur` | `6 DU` |
| `label_font_size` | TU | `--op-toast-label-font-size` | `caption_size` |
| `label_line_height` | TU | `--op-toast-label-line-height` | `caption_line` |
| `text_padding_end` | DU | `--op-toast-text-padding-end` | `pad_small` |
| `button_size` | DU | `--op-toast-button-size` | `row_compact` |
| `font_size` | TU | `--op-toast-font-size` | `body_size` |
| `line_height` | TU | `--op-toast-line-height` | `body_line` |
| `icon_size` | DU | `--op-toast-icon-size` | `8 DU` |
| `close_icon_size` | DU | `--op-toast-close-icon-size` | `icon_small` |
| `letter_spacing` | TU | `--op-toast-letter-spacing` | `0.04em (relative to caption size)` |
| `padding_end` | DU | `--op-toast-padding-end` | `pad_tight` |
| `shadow_y` | DU | `--op-toast-shadow-y` | `2 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-toast-background` | `surface` |
| `--op-toast-tone` | `var(--tone)` |
| `--op-toast-border` | `border` |
| `--op-toast-shadow` | `rgb(0 0 0 / 35%)` |
| `--op-toast-text` | `text_primary` |
| `--op-toast-action` | `accent` |
| `--op-toast-secondary` | `text_secondary` |
| `--op-toast-hover` | `hover` |
| `--op-toast-ripple` | `ripple` |

| Слот | Розташування |
| :--- | :--- |
| `header` | Замінює заголовок тону. |
| `actions` | Дії перед необов'язковою дією ToastSpec. |
| `footer` | Вміст після тіла та дій. |

ToastHost приймає ті самі метрики вигляду, змінні кольорів, слоти й перевизначення піктограм, що й Toast.
Його метричні змінні успадковуються кожним повідомленням хоста; його слоти відображаються всередині кожного повідомлення.
`viewport_margin` розташовує стос і обмежує ширину окремого повідомлення відступами області перегляду.
`gap` також розділяє повідомлення хоста.
Окремий Toast делегує вилучення й керування тривалістю життя викликачу.
Хост зберігає наявну поведінку таймера, паузи при наведенні, ліміту, порядку й анімації зникнення.

## Доступність

* Повідомлення про помилки мають роль `alert`; решта — роль `status`, щоб читачі екрана їх оголошували.
* Стос є регіоном із назвою «Notifications».
* Повідомлення ніколи не забирає фокус.
