# Tooltip

Коротка підказка, прикріплена до елемента керування або фрагмента тексту.
Називає кнопку лише з піктограмою або пояснює скорочення; ніколи не містить інтерактивного вмісту.

Статус: **чернетка** у вебреалізації.

## Використання

* Кнопки з піктограмами без видимого підпису.
* Скорочення, усічені значення та одиниці, що потребують короткого пояснення.
* Не розміщуйте дії, посилання або важливу інформацію у спливній підказці; користувачі сенсорних пристроїв можуть її не побачити.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Тип | Стиль `caption`. |
| Тло | `surface_alt` зі спільною рамкою [Popover](popover.md) `0.25 DU` у кольорі `accent` і тією самою тінню, що й [Menu](menu.md), щоб вирізнятися на сторінці. |
| Внутрішній відступ | `1 DU` × `2 DU`. |
| Ширина | За шириною вмісту, до `75 DU`; щонайбільше 6 рядків, потім трикрапка. |
| Зміщення | `1.5 DU` від якоря. |
| Кути | `0 DU`. |

## Поведінка

### Відкриття

* Миша: відкривається після наведення протягом `tooltip_show_delay` (`500 ms`); вихід за межі якоря закриває негайно.
* Клавіатура: відкривається при отриманні якорем фокусу й закривається при втраті фокусу або за Escape.
* Дотик: `long_press` (`500 ms`) відкриває її; закривається через `3500 ms` після підняття пальця.
* Довге натискання, яке відкрило підказку, не активує якір одночасно.
* Натискання будь-де поза якорем закриває її.
* Із порожнім текстом або у вимкненому стані підказка ніколи не відкривається.
* Нативна підказка браузера (атрибут `title`) ніколи не використовується, тому може з'явитися лише одна підказка.
* [IconButton](icon-button.md) сам показує `label` у підказці; обгортання в `Tooltip` замінює цей текст замість додавання другої підказки.

### Розташування

1. По центру над якорем.
2. Перевертається вниз, коли зверху бракує місця.
3. По горизонталі обмежується областю перегляду.

Такі самі розташування та вигляд використовує підказка [MarqueeText](marquee-text.md).
* Підказка є пасивним шаром [Popover](popover.md) у хості оверлеїв.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `text` | string | обов’язковий | Текст підказки. |
| `delay_ms` | integer | `500` | Затримка наведення перед відкриттям. |
| `enabled` | bool | `true` | Вимикає підказку без її видалення. |
| `children` | view | обов’язковий | Якір. |

Властивості кастомізації є необов’язковими та приймають реактивні значення там, де це вказано.

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `class`, `style` | реактивний string | немає | Кореневі хуки. |
| `padding_y` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-tooltip-padding-y`. |
| `padding_x` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-tooltip-padding-x`. |
| `shadow_y` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-tooltip-shadow-y`. |
| `shadow_blur` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-tooltip-shadow-blur`. |
| `font_size` | реактивна метрика TU | значення дизайн-системи | Встановлює `--op-tooltip-font-size`. |
| `line_height` | реактивна метрика TU | значення дизайн-системи | Встановлює `--op-tooltip-line-height`. |
| `offset` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-tooltip-offset`. |
| `max_width` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-tooltip-max-width`. |
| `content` | `Slot` | немає | Замінює текст підказки всередині бульбашки; лише інформаційний вміст. |

## Кастомізація

`class` і `style` застосовуються до плавучого шару підказки.
Метричні пропси записують відповідні змінні; явне оголошення `style` має перевагу.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `padding_y` | DU | `--op-tooltip-padding-y` | `pad_tight` |
| `padding_x` | DU | `--op-tooltip-padding-x` | `gutter` |
| `shadow_y` | DU | `--op-tooltip-shadow-y` | `2 DU` |
| `shadow_blur` | DU | `--op-tooltip-shadow-blur` | `6 DU` |
| `font_size` | TU | `--op-tooltip-font-size` | `caption_size` |
| `line_height` | TU | `--op-tooltip-line-height` | `caption_line` |
| `offset` | DU | `--op-tooltip-offset` | `1.5 DU` |
| `max_width` | DU | `--op-tooltip-max-width` | `75 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-tooltip-background` | `surface_alt` |
| `--op-tooltip-border` | `accent` |
| `--op-tooltip-shadow` | `rgb(0 0 0 / 35%)` |
| `--op-tooltip-text` | `text_primary` |

| Слот | Розташування |
| :--- | :--- |
| `content` | Замінює текст підказки всередині бульбашки; лише інформаційний вміст. |

### Рядки

| Ключ | Типове значення | Проп |
| :--- | :--- | :--- |
| `tooltip.text` | `empty; required caller text` | `text` |

### Піктограми

Цей компонент не має вбудованих піктограм.

## Доступність

* Бульбашка має роль `tooltip`.
* Якір зберігає власну доступну назву; кнопка з піктограмою все ще потребує `label`.
