# PttButton

Тактичний елемент керування push-to-talk для голосового зв'язку, телеметричних ліній та диспетчерського контролю.
Він підтримує передачу аудіо натисканням та утриманням, жест проведення вгору для фіксації режиму вільних рук та рамки станів Operator.

Статус: **draft** на web.

## Застосування

Використовуйте `PttButton` у тактичних радіостанціях, голосових інтеркомах, диспетчерських терміналах та командних екранах.
Не використовуйте `PttButton` для звичайних дій текстових повідомлень; натомість оберіть [ActionButton](action-button.md) або [MediaRecordButton](media-record-button.md).
У зафіксованому стані одне натискання знімає фіксацію та негайно завершує передачу.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія; кругле виключення `50%` при прапорці `circular`). |
| Стандартна рамка | `0.25 DU` стандартна товщина лінії. |
| Акцентна рамка | `0.5 DU` рамка активної передачі (`--op-ptt-button-border-width`). |
| Розмір за замовчуванням | `22.5 DU` квадратний розмір (`--op-ptt-button-size`). |

## Поведінка

* Натискання вказівника негайно розпочинає передачу та переводить кнопку в активний стан.
* Проведення вгору понад поріг фіксує передачу в режимі вільних рук.
* Відпускання вказівника без фіксації припиняє передачу.
* Одне натискання під час фіксації вимикає режим вільних рук та завершує передачу.
* Компонент повідомляє про зміни через зворотний виклик `on_state_change` зі значеннями `(talking, locked)`.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `talking` | `bool` | `false` | True, коли активно триває передача аудіо. |
| `locked` | `bool` | `false` | True, коли увімкнено фіксацію вільних рук. |
| `state` | `Option<ControlState>` | `None` | Перевизначення стану Operator. |
| `disabled` | `bool` | `false` | Вимикає взаємодію з кнопкою. |
| `circular` | `bool` | `false` | Кругле виключення форми кнопки. |
| `size` | `f32` | `22.5` | Розмір кнопки в Design Units. |
| `border_width` | `f32` | `0.5` | Товщина рамки в Design Units. |
| `label` | `string` | немає | Текстовий підпис кнопки. |
| `on_state_change` | `Callback<(bool, bool)>` | немає | Подія зміни стану `(is_talking, is_locked)`. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Налаштування

### Метричні параметри

| Параметр | Змінна CSS | За замовчуванням | Одиниця |
| :--- | :--- | :--- | :--- |
| `size` | `--op-ptt-button-size` | `22.5` | DU |
| `border_width` | `--op-ptt-button-border-width` | `0.5` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-ptt-button-bg` | `var(--op-color-surface)` | Фон у стані спокою. |
| `--op-ptt-button-border` | `var(--op-color-border)` | Рамка у стані спокою. |
| `--op-ptt-button-color` | `var(--op-color-text)` | Колір піктограми та підпису. |
| `--op-ptt-button-active-bg` | відтінок акценту | Фон під час активної передачі. |
| `--op-ptt-button-active-border` | `var(--op-color-accent)` | Рамка активної передачі. |
| `--op-ptt-button-locked-bg` | відтінок успіху | Фон зафіксованого режиму. |
| `--op-ptt-button-locked-border` | `var(--op-color-success)` | Рамка зафіксованого режиму. |

## Рядки

| Ключ | Англійський текст | Опис |
| :--- | :--- | :--- |
| `ptt-button.idle` | `"PUSH TO TALK"` | Підпис у стані спокою. |
| `ptt-button.talking` | `"TALKING"` | Підпис під час передачі. |
| `ptt-button.locked` | `"HANDS-FREE"` | Підпис зафіксованого стану. |
| `ptt-button.hint` | `"Slide up to lock"` | Підказка під час утримання. |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `ptt-button.mic` | `icons::ARROW_UPWARD` | Піктограма напрямку передачі. |
| `ptt-button.lock` | `icons::LOCK` | Піктограма фіксації. |

## Доступність

* Відображається як елемент HTML `<button>` з атрибутом `aria-pressed`, що відповідає стану передачі.
* Доступні мітки стану транслюються через `aria-label`.
* Фокус клавіатури чітко позначається висококонтрастним контуром.
