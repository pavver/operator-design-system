# PttButton

Тактична кнопка push-to-talk із передачею при утриманні, блокуванням hands-free свайпом угору та станами Operator.
Забезпечує чіткий візуальний відгук для режимів передачі, блокування, помилки та вимкненого стану.

Компонент є частиною розширення media: фіча `ptt-button` належить до груп `media` та `extensions`, а не до `full`.

Статус: **draft** на web.

## Застосування

Використовуйте `PttButton` у диспетчерських інтерфейсах, тактичних аудіоканалах та голосових комунікаторах hands-free.
Утримання кнопки активує передачу голосу; свайп угору фіксує канал відкритим для розмови без рук.
Швидке натискання у зафіксованому стані переводить передачу назад у режим очікування.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` стандартно (підтримує круглу форму як виняток). |
| Стандартна рамка | `0.5 DU` акцентна рамка (`--op-ptt-button-border-width`). |
| Розмір за замовчуванням | `22.5 DU` (`--op-ptt-button-size`). |

## Поведінка

* Натискання вказівника активує передачу аудіо (`is_talking = true`).
* Свайп угору за поріг блокування переводить кнопку в зафіксований режим (`is_locked = true`).
* Відпускання вказівника повертає незафіксовану кнопку в стан спокою (`is_talking = false`).
* Натискання у зафіксованому стані повертає передачу в стан спокою.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `talking` | `bool` | `false` | Чи активна передача звуку. |
| `locked` | `bool` | `false` | Чи зафіксовано передачу hands-free. |
| `state` | `ControlState` | `Idle` | Перевизначення стану автомата Operator. |
| `disabled` | `bool` | `false` | Вимикає взаємодію з кнопкою. |
| `circular` | `bool` | `false` | Опціональний виняток круглої форми. |
| `size` | `f32` | `22.5` | Розмір кнопки в Design Units. |
| `border_width` | `f32` | `0.5` | Товщина рамки в Design Units. |
| `label` | `string` | немає | Власний напис кнопки. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |
| `on_state_change` | `Option<Callback<(bool, bool)>>` | немає | Подія зміни стану `(is_talking, is_locked)`. |

## Налаштування

### Метричні параметри

| Параметр | Змінна CSS | За замовчуванням | Одиниця |
| :--- | :--- | :--- | :--- |
| `size` | `--op-ptt-button-size` | `22.5` | DU |
| `border_width` | `--op-ptt-button-border-width` | `0.5` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-ptt-button-bg` | `var(--op-surface)` | Фон у стані спокою. |
| `--op-ptt-button-border` | `var(--op-border)` | Рамка у стані спокою. |
| `--op-ptt-button-color` | `var(--op-text-primary)` | Колір піктограми та підпису. |
| `--op-ptt-button-active-border` | `var(--op-accent)` | Рамка активної передачі. |
| `--op-ptt-button-locked-border` | `var(--op-success)` | Рамка зафіксованого режиму. |

## Рядки

| Ключ | Англійський текст | Опис |
| :--- | :--- | :--- |
| `ptt-button.idle` | `"PUSH TO TALK"` | Напис у стані спокою. |
| `ptt-button.talking` | `"TALKING"` | Напис активної передачі. |
| `ptt-button.locked` | `"HANDS-FREE"` | Напис зафіксованого режиму. |
| `ptt-button.hint` | `"Slide up to lock"` | Підказка під час утримання. |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `ptt-button.mic` | `icons::ARROW_UPWARD` | Піктограма напрямку передачі. |
| `ptt-button.lock` | `icons::LOCK` | Піктограма фіксації режиму. |

## Доступність

* Рендериться як HTML-елемент `<button>` з атрибутом `aria-pressed`, що віддзеркалює стан передачі.
* Доступні оголошення оновлюються для станів спокою, розмови та фіксації через `aria-label`.
* Фокус клавіатури позначається висококонтрастною рамкою.
