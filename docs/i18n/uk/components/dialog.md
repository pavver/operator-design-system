# Dialog

Модальне вікно для окремого завдання: короткої форми, подробиць або вибору між варіантами.
Це оболонка для кожного модального вікна; [ConfirmDialog](confirm-dialog.md) — його готовий варіант для підтвердження однієї дії.

Статус: **reviewed** у вебреалізації.

## Геометрія

Діалогове вікно є динамічним контейнером і дотримується моделі clamp із [units.md](../foundations/units.md).

| Властивість | Значення |
| :--- | :--- |
| Ширина | `clamp(75 DU, 90% of the viewport, 140 DU)`, не ширше за область перегляду. |
| Висота | За висотою вмісту, щонайбільше висота області перегляду мінус `8 DU`; тіло прокручується. |
| Тло | `surface` із контуром стану з [states.md](../foundations/states.md). |
| Заголовок | Заголовок у стилі `screen_title`; кнопка закриття в кінці, якщо діалог не має дії підтвердження; знизу `0.25 DU` у кольорі `divider`. |
| Внутрішній відступ заголовка | `2 DU`, на початку `4 DU`. |
| Тіло | Внутрішній відступ `4 DU`, проміжок між блоками `3 DU`. |
| Дії | Вирівнювання праворуч, внутрішні відступи `3 DU` × `4 DU`, зверху `0.25 DU` у кольорі `divider`. |
| Затемнення | Чорний із непрозорістю 55%. |
| Кути | `0 DU`. |

## Поведінка

* Поява: затемнення проявляється, а діалог масштабується від 95% за `dialog_enter` (`150 ms`).
* Відкриття переносить фокус у діалог.
* Поки діалог відкритий, сторінка позаду нього не прокручується.
* Коли `dismissible`, Escape, клік на затемненні та кнопка закриття закривають діалог.
  Діалог, який не можна закрити зовнішніми засобами, приховує кнопку закриття й має закриватися дією.
* Без `on_confirm` кнопки надходять із `actions`, а діалог закриває викликач.
* Із `on_confirm` діалог додає кнопку скасування та [ActionButton](action-button.md) підтвердження після `actions`, а скасування замінює кнопку закриття.
* Підтвердження запускає дію, не закриваючи діалог.
  Контур діалогу та кнопка підтвердження переходять у `Pending`; скасування вимкнено, діалог не можна закрити.
* У разі **успіху** діалог показує `Success` протягом `500 ms`, потім негайно закривається без згасання.
* У разі **помилки** діалог показує `Error` протягом `500 ms`, потім повертається в `Idle` і згасає колір результату.
  Підтвердження та скасування розблоковуються через `300 ms`, щоб користувач міг повторити спробу або скасувати дію.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `open` | сигнал bool | обов’язковий | Видимість. |
| `title` | string | обов’язковий | Заголовок і доступна назва. |
| `actions` | `Slot` | немає | Додаткові кнопки внизу, перед скасуванням і підтвердженням. |
| `dismissible` | bool | `true` | Escape, затемнення та кнопка закриття. |
| `min_width` | реактивна метрика DU | `75` | Мінімум clamp. |
| `max_width` | реактивна метрика DU | `140` | Максимум clamp. |
| `on_confirm` | асинхронний `() -> ActionResult` | немає | Дія підтвердження; додає кнопки скасування та підтвердження. |
| `confirm_text` | string | `"OK"` | Підпис кнопки підтвердження. |
| `cancel_text` | string | `"Cancel"` | Підпис кнопки скасування. |
| `destructive` | bool | `false` | Кнопка небезпечної дії підтвердження. |
| `alert` | bool | `false` | Роль `alertdialog`. |
| `children` | view | обов’язковий | Тіло. |

Властивості кастомізації є необов’язковими та приймають реактивні значення там, де це вказано.

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `class`, `style` | реактивний string | немає | Кореневі хуки. |
| `padding` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-dialog-padding`. |
| `header_padding` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-dialog-header-padding`. |
| `title_font_size` | реактивна метрика TU | значення дизайн-системи | Встановлює `--op-dialog-title-font-size`. |
| `title_line_height` | реактивна метрика TU | значення дизайн-системи | Встановлює `--op-dialog-title-line-height`. |
| `gap` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-dialog-gap`. |
| `button_height` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-dialog-button-height`. |
| `font_size` | реактивна метрика TU | значення дизайн-системи | Встановлює `--op-dialog-font-size`. |
| `line_height` | реактивна метрика TU | значення дизайн-системи | Встановлює `--op-dialog-line-height`. |
| `close_size` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-dialog-close-size`. |
| `close_icon_size` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-dialog-close-icon-size`. |
| `max_height` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-dialog-max-height`. |
| `header` | `Slot` | немає | Замінює вміст заголовка. |
| `footer` | `Slot` | немає | Вміст після тіла та дій. |
| `close_label` | реактивний string | `dialog.close` | Доступна назва кнопки закриття. |
| `close_icon` | піктограма | `dialog.close` | Піктограма кнопки закриття. |

## Кастомізація

`class` і `style` застосовуються до кореня затемнення, а змінні успадковуються панеллю діалогу.
Метричні пропси записують відповідні змінні; явне оголошення `style` має перевагу.
Змінна тексту задає колір панелі та заголовка; вкладені компоненти зберігають власні хуки кольорів.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `padding` | DU | `--op-dialog-padding` | `margin_screen` |
| `header_padding` | DU | `--op-dialog-header-padding` | `gutter` |
| `title_font_size` | TU | `--op-dialog-title-font-size` | `screen_title_size` |
| `title_line_height` | TU | `--op-dialog-title-line-height` | `screen_title_line` |
| `gap` | DU | `--op-dialog-gap` | `pad_card` |
| `button_height` | DU | `--op-dialog-button-height` | `row_compact` |
| `min_width` | DU | `--op-dialog-min-width` | `75 DU` |
| `max_width` | DU | `--op-dialog-max-width` | `140 DU` |
| `font_size` | TU | `--op-dialog-font-size` | `body_size` |
| `line_height` | TU | `--op-dialog-line-height` | `body_line` |
| `close_size` | DU | `--op-dialog-close-size` | `row_compact` |
| `close_icon_size` | DU | `--op-dialog-close-icon-size` | `icon_small` (`4 DU`) |
| `max_height` | DU | `--op-dialog-max-height` | `calc(100vh - var(--op-dialog-padding, margin_screen) * 2)` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-dialog-scrim` | `rgb(0 0 0 / 55%)` |
| `--op-dialog-background` | `surface` |
| `--op-dialog-divider` | `divider` |
| `--op-dialog-text` | `text_primary` |
| `--op-dialog-border` | `border` |
| `--op-dialog-success` | `success` |
| `--op-dialog-error` | `error` |
| `--op-dialog-pending` | `pending` |

| Слот | Розташування |
| :--- | :--- |
| `header` | Замінює вміст заголовка. |
| `actions` | Додаткові дії перед вбудованими кнопками дій. |
| `footer` | Вміст після тіла та дій. |

### Рядки

| Ключ | Типове значення | Проп |
| :--- | :--- | :--- |
| `dialog.confirm` | `OK` | `confirm_text` |
| `dialog.cancel` | `Cancel` | `cancel_text` |
| `dialog.close` | `Close` | `close_label` |

### Піктограми

| Ключ | Типове значення | Проп |
| :--- | :--- | :--- |
| `dialog.close` | `close` | `close_icon` |

## Доступність

Роль `dialog` або `alertdialog`, коли встановлено `alert`, з `aria-modal` та заголовком як назвою.
