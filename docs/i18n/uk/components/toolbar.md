# Toolbar

Горизонтальна панель команд для представлення під нею.

Статус: **чернетка** у вебреалізації.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Висота | Щонайменше `10 DU`; щільний варіант `8 DU`. |
| Внутрішній відступ | `1 DU` по горизонталі. |
| Проміжок | `1 DU`; щільний варіант `0.5 DU`. |
| Тло | `surface` із лінією `0.25 DU` у кольорі `border` знизу. |
| Назва | Середня насиченість, горизонтальний внутрішній відступ `1 DU`, далі розділювач. |
| Розділювач | `0.25 DU` × `6 DU` у кольорі `divider` із зовнішніми відступами `1 DU`. |
| Команди | [IconButton](icon-button.md), `8 DU`; щільний варіант `6 DU`. |
| Кнопка додаткових команд | Такий самий розмір, як у команди, піктограма `more_vert`, відразу після останньої видимої команди. |
| Кінцеві елементи керування | Після вільного місця, у кінці панелі; поля заввишки `8 DU`. |

## Компонування

```
[ Title | ⟳  ⏷  ⤓  ⋮            ( Search…     ) ]
          commands  overflow      end controls
```

## Поведінка

* Команди є даними, а не довільними дочірніми елементами, тому кожна може бути або кнопкою на панелі, або рядком у меню додаткових команд.
* Коли команди не вміщуються, вони по одній переходять із кінця в [Menu](menu.md) додаткових команд і повертаються, коли місце з'являється.
  Кнопка додаткових команд з'являється, лише коли в меню є хоча б одна команда.
* У меню команда показує піктограму й підпис; відокремлена команда починає групу в обох місцях.
* Команди з позначкою `overflow` завжди містяться в меню, після команд, що не вмістилися, окремою групою.
  Використовуйте їх для рідкісних або деструктивних команд.
* Заголовок і кінцеві елементи керування ніколи не переходять у меню.
* Кожна кнопка команди має спливну підказку зі своїм підписом.
* Асинхронна команда показує стани на власній кнопці.
  При запуску з меню її стани показуються на кнопці додаткових команд.
* Стрілки Left і Right переміщують фокус між видимими елементами керування, крім текстових полів.

## API

`Toolbar`:

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `items` | список `ToolbarItem` | обов’язковий | Команди за порядком. |
| `title` | сигнал рядка | немає | Заголовок на початку. |
| `start` | слот | немає | Елементи керування перед заголовком на початку панелі. |
| `end` | слот | немає | Елементи керування в кінці, що ніколи не переходять у меню, як-от поле пошуку. |
| `label` | string | `toolbar.label` | Доступна назва. |
| `dense` | bool | `false` | Менший варіант. |
| `height` | DU | `row_standard` | Висота панелі. |
| `dense_height` | DU | `row_compact` | Висота щільної панелі. |
| `padding_x` | DU | `pad_tight` | Горизонтальний внутрішній відступ. |
| `gap` | DU | `pad_tight` | Проміжок між елементами. |
| `dense_gap` | DU | `gap_micro` | Проміжок між елементами щільного варіанта. |
| `title_padding_x` | DU | `pad_tight` | Горизонтальний внутрішній відступ заголовка. |
| `title_font_size` | TU | `inherit` | Розмір шрифту заголовка. |
| `separator_width` | DU | `border` | Товщина лінії розділювача. |
| `separator_height` | DU | `icon_large` | Висота лінії розділювача. |
| `separator_margin_x` | DU | `pad_tight` | Горизонтальні зовнішні відступи розділювача. |
| `button_size` | DU | `row_compact` (щільний варіант: `row_dense`) | Розмір кнопки команди. |
| `more_label` | string | `toolbar.more` | Доступна назва кнопки додаткових команд. |
| `more_icon` | піктограма | `toolbar.more` | Перевизначення піктограми кнопки додаткових команд. |
| `class` | string | немає | Класи кореневого елемента. |
| `style` | string | немає | Інлайн-стилі кореневого елемента. |

`ToolbarItem`:

| Конструктор | Опис |
| :--- | :--- |
| `new(id, label, icon)` | Команда; підпис є спливною підказкою, доступною назвою та текстом меню. |
| `on_click(callback)` | Виконує зворотний виклик. |
| `on_async(action)` | Виконує асинхронну дію зі зворотним зв'язком стану. |
| `separated()` | Починає нову групу. |
| `overflow()` | Завжди в меню додаткових команд. |
| `danger()` | Деструктивна; колір помилки в меню. |
| `disabled()` | Недоступна. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-toolbar-height` | `row_standard` (`10 DU`) |
| `dense_height` | DU | `--op-toolbar-dense-height` | `row_compact` (`8 DU`) |
| `padding_x` | DU | `--op-toolbar-padding-x` | `pad_tight` (`1 DU`) |
| `gap` | DU | `--op-toolbar-gap` | `pad_tight` (`1 DU`) |
| `dense_gap` | DU | `--op-toolbar-dense-gap` | `gap_micro` (`0.5 DU`) |
| `title_padding_x` | DU | `--op-toolbar-title-padding-x` | `pad_tight` (`1 DU`) |
| `title_font_size` | TU | `--op-toolbar-title-font-size` | `inherit` |
| `separator_width` | DU | `--op-toolbar-separator-width` | `border` (`0.25 DU`) |
| `separator_height` | DU | `--op-toolbar-separator-height` | `icon_large` (`6 DU`) |
| `separator_margin_x` | DU | `--op-toolbar-separator-margin-x` | `pad_tight` (`1 DU`) |
| `button_size` | DU | `--op-toolbar-button-size` | `row_compact` (`8 DU`), щільний варіант `row_dense` (`6 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-toolbar-background` | `surface` |
| `--op-toolbar-border` | `border` |
| `--op-toolbar-title-color` | `text_primary` |
| `--op-toolbar-separator-color` | `divider` |

| Слот | Розташування |
| :--- | :--- |
| `start` | На початку панелі інструментів перед заголовком. |
| `end` | У кінці панелі інструментів після вільного місця. |

`class` та `style` застосовуються до кореневого елемента.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `toolbar.label` | `Toolbar` |
| `toolbar.more` | `More commands` |

### Піктограми

| Ключ | Типове значення |
| :--- | :--- |
| `toolbar.more` | `more_vert` |

## Доступність

Панель має роль `toolbar` і задану назву.
Кнопка додаткових команд має назву «More commands» і відкриває `menu`.
