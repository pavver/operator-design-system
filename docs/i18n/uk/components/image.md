# Image

Розширений контейнер зображення з резервуванням співвідношення сторін, режимами вписування, каркасними плейсхолдерами завантаження, запасними варіантами для помилок і накладеними підписами.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `Image` для фотографій, попередніх переглядів, ілюстрацій та медіаресурсів, коли стабільність компонування під час завантаження зображень є критичною.
Не використовуйте `Image` для малих піктограм усередині рядків; натомість використовуйте [Icon](primitives.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус заокруглення кутів | `0 DU` (стандартна прямокутна геометрія). |
| Розміри | Налаштовуються через `width`, `height` і пропорційне `ratio`. |

## Поведінка

* Поки віддалене зображення завантажується, відображається плейсхолдер [Skeleton](skeleton.md).
* Після успішного завантаження зображення плавно з'являється.
* Якщо завантаження не вдалося, запасний вміст показує піктограму й повідомлення про помилку.
* Зміна `src` автоматично скидає стани завантаження та помилки.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `src` | сигнал рядка | обов’язковий | URL зображення. |
| `alt` | string | `""` | Доступний альтернативний текст. |
| `ratio` | f32 | немає | Співвідношення сторін (ширина / висота). |
| `fit` | ImageFit | `Cover` | Режим вписування (`Cover`, `Contain`, `Fill`, `None`, `ScaleDown`). |
| `position` | string | `"center"` | Значення CSS object-position. |
| `loading` | string | `"lazy"` | Нативний атрибут завантаження браузера. |
| `caption` | string | немає | Текст накладеного підпису. |
| `caption_slot` | Слот | немає | Слот власного підпису. |
| `loading_slot` | Слот | немає | Власний слот завантаження замість типового каркаса. |
| `error_slot` | Слот | немає | Власний слот помилки замість типового стану помилки. |
| `error_label` | string | `image.error` | Рядок повідомлення про помилку. |
| `width` | DU | немає | Ширина в DU. |
| `height` | DU | немає | Висота в DU. |
| `on_load` | зворотний виклик `()` | немає | Спрацьовує після успішного завантаження зображення. |
| `on_error` | зворотний виклик `()` | немає | Спрацьовує при помилці завантаження. |
| `class` | string | немає | CSS-класи на кореневому елементі. |
| `style` | string | немає | Інлайн-CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `width` | DU | `--op-image-width` | `100%` |
| `height` | DU | `--op-image-height` | `auto` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-image-background` | `var(--op-surface-subtle)` |
| `--op-image-placeholder-bg` | `var(--op-surface-subtle)` |
| `--op-image-caption-bg` | `rgba(0, 0, 0, 0.7)` |
| `--op-image-caption-text` | `#ffffff` |

`class` та `style` застосовуються до кореневого `div`.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `image.error` | `"Failed to load image"` |

### Піктограми

| Ключ | Типове значення |
| :--- | :--- |
| Піктограма запасного вмісту при помилці | `icons::ERROR` |

## Доступність

Внутрішній `<img>` отримує наданий опис `alt`.
Декоративні плейсхолдери та запасні варіанти для помилок не заважають стандартним описам для читачів екрана.
