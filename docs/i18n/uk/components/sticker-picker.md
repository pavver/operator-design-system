# StickerPicker

Панель вибору векторних та анімованих стікерів із навігацією за паками та попереднім переглядом.
Підтримує растрові формати PNG/WebP, векторний SVG та анімовані стікери.

Компонент є частиною розширення media: фіча `sticker-picker` належить до груп `media` та `extensions`, а не до `full`.

Статус: **draft** на web.

## Застосування

Використовуйте `StickerPicker` у панелях чату, медіа-клавіатурах та формах коментарів.
Бібліотека не містить попередньо встановлених паків: застосунок передає їх за допомогою моделей `StickerPack`.
Наведення курсору або тривале натискання відкриває збільшений попередній перегляд стікера.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` контурна рамка. |
| Висота контейнера | `60 DU` (`--op-sticker-picker-height`). |
| Розмір комірки | `18 DU` (`--op-sticker-picker-cell-size`). |

## Поведінка

* Натискання вкладки пака прокручує список до відповідного набору стікерів.
* Пошукове поле фільтрує стікери за назвою або емодзі в усіх паках.
* Вибір стікера викликає подію `on_select` із даними `StickerAttachment`.
* Наведення курсору відображає збільшений оверлей попереднього перегляду.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `on_select` | `Callback<StickerAttachment>` | немає | Подія вибору стікера. |
| `sticker_packs` | `Option<Vec<StickerPack>>` | немає | Встановлені паки стікерів із метаданими. |
| `recent_stickers` | `Option<Vec<StickerItem>>` | немає | Історія нещодавно використаних стікерів. |
| `render_sticker` | `Option<Callback<StickerAttachment, AnyView>>` | немає | Слот власного рендерера для анімацій. |
| `height` | `f32` | `60.0` | Висота панелі в Design Units. |
| `cell_size` | `f32` | `18.0` | Розмір комірки в Design Units. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Налаштування

### Метричні параметри

| Параметр | Змінна CSS | За замовчуванням | Одиниця |
| :--- | :--- | :--- | :--- |
| `height` | `--op-sticker-picker-height` | `60.0` | DU |
| `cell_size` | `--op-sticker-picker-cell-size` | `18.0` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-sticker-picker-bg` | `var(--op-surface)` | Фон панелі. |
| `--op-sticker-picker-border` | `var(--op-border)` | Рамка панелі. |
| `--op-sticker-picker-accent` | `var(--op-accent)` | Підсвічування вкладки та фокус комірки. |
| `--op-sticker-picker-text` | `var(--op-text-primary)` | Колір тексту заголовків. |

## Рядки

| Ключ | Англійський текст | Опис |
| :--- | :--- | :--- |
| `sticker-picker.search` | `"Search stickers..."` | Підказка в полі пошуку. |
| `sticker-picker.recent` | `"Recent stickers"` | Заголовок розділу та вкладки останніх стікерів. |
| `sticker-picker.packs` | `"Sticker packs"` | Доступна назва панелі вкладок паків. |
| `sticker-picker.search-prefix` | `"Search results"` | Префікс заголовка результатів пошуку. |
| `sticker-picker.empty` | `"No stickers found"` | Повідомлення про відсутність результатів. |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `sticker-picker.search-icon` | `icons::SEARCH` | Піктограма пошуку. |
| `sticker-picker.recent-icon` | `icons::REFRESH` | Піктограма останніх стікерів. |

## Доступність

* Вкладки паків мають доступні назви заголовків і атрибут `role="tab"`.
* Кожна комірка стікера містить доступний опис відповідно до назви та емодзі.
