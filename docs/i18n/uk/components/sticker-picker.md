# StickerPicker

Компонент вибору стікерів із навігацією за паками, пошуковою фільтрацією та збільшеним переглядом.
Він підтримує растрові зображення, векторні SVG та анімовані формати, візуалізовані застосунком.

Статус: **draft** на web.

## Застосування

Використовуйте `StickerPicker` у медіа-клавіатурах, полях введення чату та інтерфейсах обміну повідомленнями.
Компонент не постачає вбудованих стікерів: усі паки, метадані та графіку передає хост-застосунок.
Утримання або наведення курсору на стікер показує збільшений спливаючий блок попереднього перегляду.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія). |
| Стандартна рамка | `0.25 DU` контур контейнера. |
| Висота за замовчуванням | `60 DU` (`--op-sticker-picker-height`). |
| Розмір комірки | `18 DU` (`--op-sticker-picker-cell-size`). |

## Поведінка

* Клік на значок паку в навігаційній стрічці перемикає активну колекцію стікерів.
* Живий пошук шукає збіги за назвами стікерів та закріпленими емодзі.
* Вибір стікера викликає зворотний виклик `on_select` із поліморфним `StickerAttachment`.
* Наведення курсору відкриває збільшений блок попереднього перегляду.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `on_select` | `Callback<StickerAttachment>` | немає | Подія вибору стікера. |
| `sticker_packs` | `Option<Vec<StickerPack>>` | немає | Набори стікерів з іконками та метаданими. |
| `recent_stickers` | `Option<Vec<StickerItem>>` | немає | Список нещодавно використаних стікерів. |
| `render_sticker` | `Option<Callback<StickerAttachment, AnyView>>` | немає | Слот рендерера для анімованих/векторних форматів. |
| `height` | `f32` | `60.0` | Висота в Design Units. |
| `cell_size` | `f32` | `18.0` | Розмір комірки в Design Units. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Налаштування

### Метричні параметри

| Параметр | Змінна CSS | За замовчуванням | Одиниця |
| :--- | :--- | :--- | :--- |
| `height` | `--op-sticker-picker-height` | `60.0` | DU |
| `cell_size` | `--op-sticker-picker-cell-size` | `18.0` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-sticker-picker-bg` | `var(--op-color-surface)` | Фон панелі. |
| `--op-sticker-picker-border` | `var(--op-color-border)` | Рамка панелі. |
| `--op-sticker-picker-accent` | `var(--op-color-accent)` | Підсвічування вкладки та виділення. |

| :--- | :--- | :--- |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |

## Доступність

* Вкладки паків мають назви відповідних колекцій та атрибут `role="tab"`.
* Кожна комірка стікера містить доступний опис з назвою та емодзі.
