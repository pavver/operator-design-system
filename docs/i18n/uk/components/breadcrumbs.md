# Breadcrumbs

Навігаційний ланцюжок шляху, що вказує розташування поточної сторінки в ієрархії.
Довгі шляхи згортають проміжні кроки в меню переповнення.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `Breadcrumbs` угорі сторінок із глибокою ієрархічною структурою (наприклад, дерево файлів, розділи налаштувань або багаторівневі каталоги).
Не використовуйте `Breadcrumbs` для пласкої навігації або лінійних послідовностей кроків; натомість використовуйте [Stepper](stepper.md) чи [Tabs](tabs.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Розмір шрифту | Успадкований або `--op-breadcrumbs-font-size`. |
| Проміжок | `1 DU` між елементами та розділювачами (`--op-breadcrumbs-gap`). |

## Поведінка

* Елементи перед поточною сторінкою рендеряться як клікабельні навігаційні посилання або кнопки.
* Поточний (останній) елемент рендериться з `aria-current="page"` у кольорі основного тексту.
* Якщо встановлено `max_items` і кількість елементів перевищує це значення, середні елементи згортаються в кнопку переповнення, яка розкриває їх у [Menu](menu.md).

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `items` | signal `Vec<BreadcrumbItem>` | обов'язковий | Елементи шляху від кореня до поточної сторінки. |
| `max_items` | usize | немає | Максимальна кількість видимих елементів до згортання середніх елементів. |
| `separator` | string | `"/"` | Текстовий розділювач між елементами. |
| `separator_icon` | Icon | немає | Піктограма-розділювач між елементами (перевизначає текст). |
| `separator_slot` | Slot | немає | Користувацький слот розділювача. |
| `label` | string | `breadcrumbs.label` | Доступна мітка орієнтира. |
| `more_label` | string | `breadcrumbs.more` | Доступна мітка для кнопки меню згортання. |
| `font_size` | TU | `--op-breadcrumbs-font-size` | Розмір тексту. |
| `gap` | DU | `--op-breadcrumbs-gap` | Проміжок між елементами. |
| `class` | string | немає | Класи CSS на кореневому елементі. |
| `style` | string | немає | Інлайн-стилі CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `font_size` | TU | `--op-breadcrumbs-font-size` | `inherit` |
| `gap` | DU | `--op-breadcrumbs-gap` | `1 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-breadcrumbs-text` | `var(--op-text-secondary)` |
| `--op-breadcrumbs-active-text` | `var(--op-text-primary)` |
| `--op-breadcrumbs-separator-color` | `var(--op-text-secondary)` |

`class` та `style` застосовуються до кореневого `<nav>`.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `breadcrumbs.label` | `"Breadcrumbs"` |
| `breadcrumbs.more` | `"More pages"` |

### Піктограми

| Ключ | Типове значення |
| :--- | :--- |
| Кнопка меню згортання | `icons::MORE_VERT` |

## Доступність

`Breadcrumbs` рендериться як орієнтир `<nav>` із доступною міткою (`aria-label`).
Елементи організовані у впорядкований список (`<ol>`), а поточна сторінка позначена як `aria-current="page"`.
Розділювачі приховані від допоміжних технологій за допомогою `aria-hidden="true"`.
