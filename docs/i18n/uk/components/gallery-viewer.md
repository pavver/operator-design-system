# GalleryViewer

Повноекранний діалог перегляду медіа з масштабуванням мультитачем, панорамуванням, навігацією мініатюрами, відтворенням відео та слотами дій.

Компонент є частиною розширення media: фіча `gallery-viewer` належить до груп `media` та `extensions`, а не до `full`.

Статус: **draft** на web.

## Призначення

Використовуйте `GalleryViewer`, коли користувачам потрібно детально оглянути, масштабувати, переглядати та завантажувати фотографії та відео у повноекранному режимі.
Не використовуйте `GalleryViewer` для стандартних запитів підтвердження; використовуйте [ConfirmDialog](confirm-dialog.md) або [Dialog](dialog.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Область перегляду | Повний екран (`100vw` на `100vh`). |
| Радіус кутів | `0 DU` (стандартна пряма геометрія). |
| Розмір мініатюри | `12 DU` у каруселі. |
| Кнопка закриття | `9 DU`. |

## Поведінка

* Відкривається поверх усього екрана із затемненим фоном.
* Блокує прокручування фонового документа під час активності.
* Колесо миші змінює масштаб у діапазоні від `1.0x` до `5.0x`.
* Подвійний клік або подвійний тап перемикає масштаб між `3.0x` та стандартним `1.0x`.
* Перетягування панорамує медіа по екрану у збільшеному масштабі.
* Стрілки клавіатури (`ArrowLeft`, `ArrowRight`) та кліки по краях перемикають елементи, коли масштаб дорівнює `1.0x`.
* Клік по центру перемикає видимість верхньої панелі, лічильника та нижнього опису.
* При невдалому завантаженні відео відображається шар помилки поверх постера замість чорного екрана.
* Закривається клавішею `Escape` або кліком на кнопку закриття.
* Утримує фокус клавіатури всередині діалогу.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `open` | RwSignal bool | обов'язковий | Стан видимості. |
| `items` | signal Vec MediaItem | обов'язковий | Колекція медіаелементів для відображення. |
| `current_index` | RwSignal usize | `0` | Індекс поточного медіаелемента. |
| `label` | string | `"Media gallery viewer"` | Доступна назва діалогу. |
| `close_label` | string | `"Close"` | Текст кнопки закриття. |
| `prev_label` | string | `"Previous item"` | Текст кнопки переходу до попереднього елемента. |
| `next_label` | string | `"Next item"` | Текст кнопки переходу до наступного елемента. |
| `empty_label` | string | `"Media not found"` | Текст за відсутності медіа. |
| `video_error_label` | string | `"Video unavailable"` | Текст повідомлення про помилку відтворення відео. |
| `download_slot` | Slot | немає | Користувацький слот для завантаження файлу. |
| `share_slot` | Slot | немає | Користувацький слот для надсилання/поширення. |
| `actions_slot` | Slot | немає | Додаткові кнопки дій у шапці. |
| `thumbnail_size` | DU | `12.0` | Розмір мініатюри в DU у нижній стрічці. |
| `on_change` | callback usize | немає | Викликається при зміні активного елемента. |
| `class` | string | немає | CSS-класи кореневого елемента. |
| `style` | string | немає | Вбудовані стилі кореневого елемента. |

## Кастомізація

| Проп метрики | Одиниця | Змінна | За замовчуванням |
| :--- | :--- | :--- | :--- |
| `thumbnail_size` | DU | `--op-gallery-viewer-thumb-size` | `12 DU` |

| Змінна кольору | За замовчуванням |
| :--- | :--- |
| `--op-gallery-viewer-bg` | `rgba(0, 0, 0, 0.92)` |

`class` та `style` застосовуються до повноекранного контейнера діалогу.

## Доступність

Діалог використовує `role="dialog"` із `aria-modal="true"`.
Фокус утримується всередині діалогу під час відкриття.
Натискання `Escape` закриває переглядач та повертає фокус.
Медіаелементи мають текстові описи, якщо вони передані.
