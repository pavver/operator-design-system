# VirtualList

Вертикальний список рядків фіксованої висоти, який рендерить лише рядки всередині області перегляду.
Зберігає довгі списки (тисячі варіантів, сутностей або записів) такими ж швидкими, як короткі.

Статус: **чернетка** у вебреалізації.

## Використання

* Списки, що можуть зрости понад кілька сотень рядків: варіанти вибору, каталоги сутностей, результати пошуку.
* Список прокручується всередині [ScrollView](scrollbar.md), тому використовує смугу прокручування Operator.
* Рядки мають одну фіксовану висоту; вміст із переносами або змінною висотою не підходить для віртуального списку.
  Вміст зі змінною висотою, як-от рядки [ConsoleTerminal](console-terminal.md), не віртуалізується.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Висота рядка | Фіксована, у DU, задається викликачем (наприклад, `row_control` для варіантів меню, `row_compact` для щільних списків). |
| Висота | Фіксована `height` або `max_height` у DU; висота списку відповідає його рядкам до досягнення межі. |
| Відрендерені рядки | Видимі рядки плюс `6` зверху та знизу (`overscan`). |

## Поведінка

* Прокручування й зміна розміру області перегляду оновлюють вікно рендерингу в тому самому кадрі.
* DOM містить щонайбільше видимі рядки та запас поза екраном незалежно від кількості елементів.
* Рядки зберігають ідентичність за ключем викликача, тому фокус і стан переживають прокручування в межах вікна.
* `VirtualListHandle::reveal(index, center)` прокручує рядок у видиму область, за потреби до середини; компоненти використовують це для клавіатурної навігації.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `items` | сигнал списку | обов’язковий | Усі елементи. |
| `handle` | `VirtualListHandle` | обов’язковий | Висота рядка в DU; прокручує список ззовні. |
| `height` | DU | немає | Фіксована висота. |
| `max_height` | DU | немає | Обмеження висоти. |
| `row_height` | DU | із `handle` | Перевизначення висоти рядка. |
| `overscan` | integer | `6` | Додаткові рядки над вікном і під ним. |
| `focusable` | bool | `false` | Дозволяє прокручуваному елементу отримувати фокус для прокручування з клавіатури. |
| `header` | слот | немає | Слот перед прокручуваною областю перегляду. |
| `footer` | слот | немає | Слот після прокручуваної області перегляду. |
| `empty` | слот | немає | Слот за порожнього items. |
| `class` | string | немає | Класи зовнішнього контейнера. |
| `style` | string | немає | Інлайн-стилі зовнішнього контейнера. |
| `key` | `item -> key` | обов’язковий | Стабільна ідентичність елемента. |
| `children` | `(index, item) -> view` | обов’язковий | Рендерить один рядок. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-virtual-list-height` | немає |
| `max_height` | DU | `--op-virtual-list-max-height` | немає |
| `row_height` | DU | `--op-virtual-list-row-height` | висота рядка з дескриптора |

| Слот | Розташування |
| :--- | :--- |
| `header` | Перед прокручуваною областю перегляду. |
| `footer` | Після прокручуваної області перегляду. |
| `empty` | Коли items порожній. |

`class` та `style` застосовуються до кореневого елемента.

### Рядки

Компонент не має вбудованих рядків.

### Піктограми

Компонент не має вбудованих піктограм.

## Доступність

* Компонент не додає роль; її задає викликач (наприклад, `listbox` із рядками `option`).
* Рядки поза вікном відсутні в дереві доступності, тому задавайте `aria-setsize` і `aria-posinset` на рядках, коли важлива повна кількість.
