# TextField

Однорядкове текстове поле з вбудованою асинхронною кнопкою SAVE та необов'язковим перемикачем показу пароля.

Статус: **чернетка** у вебреалізації (збереження через Enter додано 2026-11-17, очікує перевірки).

## Використання

* Редагування короткого значення, яке зберігається на бекенді: назви, адреси, URL.
* Введення секретних даних із перемикачем показу.

## Анатомія

```
┌──────────────────────────────────────────────┬────┬──────────┐
│ value text                                   │ () │ ✓ SAVE   │
└──────────────────────────────────────────────┴────┴──────────┘
  input                                   reveal    save button
```

* **Контейнер:** має контур стану.
* **Поле введення:** заповнює решту ширини.
* **Перемикач показу** (поля пароля): квадратний, впритул праворуч.
* **Кнопка збереження** (після зміни): [ActionButton](action-button.md), впритул до правого краю.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Ширина | Заповнює батьківський елемент. |
| Висота | `row_standard` (`10 DU`). |
| Радіус заокруглення кутів | `0 DU`. |
| Лівий внутрішній відступ | `pad_card` (`3 DU`). |
| Правий внутрішній відступ | `pad_card` або `0 DU`, поки показується кінцевий елемент керування. |
| Перемикач показу | `10 DU` × повна висота, піктограма `icon_small` (`4 DU`). |
| Кнопка збереження | На всю висоту, ширина від `12 DU` до `30 DU`, визначається підписом. |
| Текст | Стиль `body`, `text_primary`; курсор введення в `accent`. |
| Плейсхолдер | `text_disabled`. |

## Стани

| Стан | Вигляд |
| :--- | :--- |
| `Idle` | Фон `surface`, контур `border`. |
| `Focused` | Контур `accent` із товщиною штриха 1.5x. |
| `Pending` | Рухомий сегмент `pending` на контурі поля. |
| `Success` / `Error` | Пульсівний контур результату на полі. |
| `Disabled` | Фон `disabled_surface`, `disabled_border`, текст `text_disabled`. |

Контур поля малюється над кінцевими елементами керування.
Тому контури фокусу та результату охоплюють перемикач показу й кнопку збереження як один блок.
Кнопка збереження зберігає власний лівий край як розділювач.

## Поведінка

### Кнопка збереження

* Кнопка збереження з'являється, коли значення відрізняється від базового (`initial_value`) і є обробник збереження.
* Вона зникає, коли значення повертається до базового, якщо цикл збереження не виконується.
* Натискання кнопки збереження не забирає фокус із поля введення, тому поле зберігає контур `Focused`.
* Enter у полі введення запускає обробник збереження, поки кнопка збереження показується.
* Кнопка збереження не малює власного сегмента очікування; його натомість показує контур поля.
* У разі успіху кнопка збереження зберігає піктограму позначки протягом усієї фази результату замість повернення до підпису.
* Поки запит збереження очікує завершення, кнопка збереження ігнорує кліки.
  Редагування тексту залишається можливим.

### Цикл збереження

1. Поле переходить у `Pending`.
2. У разі **успіху** поле показує `Success`.
   Через `700 ms` кнопка збереження ховається.
   Ще через `100 ms` поле повертається в `Idle`, а контур результату згасає за `500 ms`.
   Батьківський компонент оновлює базове значення до збереженого.
3. У разі **помилки** поле показує `Error` протягом `1000 ms`, потім повертається в `Idle`.
   Кнопка збереження залишається видимою, щоб користувач міг повторити спробу.

Кнопка збереження ховається за `100 ms` до виходу поля зі стану результату, тому її підпис ніколи не блимає знову.

### Показ пароля

* Поле пароля типово показує перемикач показу.
* Перемикач змінює введення між прихованим і відкритим текстом.
* Піктограма показує дію, а не стан: `visibility` для прихованого тексту, `visibility_off` для відкритого.
* Піктограма має колір `text_secondary`, а при наведенні або показі тексту — `accent`.
* Натискання перемикача не забирає фокус із поля введення.
* Перемикач можна вимкнути через `show_reveal = false`.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | рядок для читання й запису | обов’язковий | Поточний текст. |

| `enabled` | bool | `true` | Інтерактивність. |

## Доступність

* Поле введення має `label` як доступну назву.
* Перемикач показу є кнопкою з назвою «Show password» або «Hide password» і станом натискання.
* Кнопка збереження повідомляє про зайнятість під час очікування.

## Кастомізація

`class` та `style` застосовуються до кореня; явні оголошення `style` йдуть після метричних пропсів і мають перевагу.
Невстановлені метричні пропси зберігають значення токенів як запасні варіанти.
Усі текстоподібні поля введення надають ті самі шість слотів поля.

| Метричний проп | Одиниця | Змінна | Типове значення | Компоненти |
| :--- | :--- | :--- | :--- | :--- |
| `height` | DU | `--op-field-height` | `row_standard` | TextField |
| `padding_x` | DU | `--op-field-padding-x` | `pad_card` | TextField |
| `slot_size` | DU | `--op-field-slot-size` | `row_standard` | TextField |
| `gap` | DU | `--op-field-gap` | `gap_micro` | TextField |
| `font_size` | TU | `--op-field-font-size` | `type_body_size` | TextField |
| `icon_size` | DU | `--op-field-icon-size` | `icon_small; 5 DU for picker arrows` | TextField |
| `save_min_width` | DU | `--op-field-save-min-width` | `12 DU` | TextField |
| `save_max_width` | DU | `--op-field-save-max-width` | `30 DU` | TextField |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-field-background` | `surface` |
| `--op-field-text` | `text_primary` |

| Слот | Розташування |

| `append` | Усередині поля перед вбудованими елементами розкриття, збереження або вибору. |
| `before` | Зовні поля перед ним. |
| `after` | Зовні поля після нього. |
| `label_slot` | Замінює видиму мітку. |
| `hint_slot` | Замінює рядок підказки та помилки. |
