# TabPanels

Анімовані контейнери вмісту, синхронізовані з вибраним індексом вкладки.

Статус: **draft** у вебреалізації.

## Використання

Використовуйте TabPanels разом із [Tabs](tabs.md) для відображення панелей вкладок із плавними переходами появи.
Компонент підтримує як умовне монтування, так і режим збереження стану форми (keep-alive) під час перемикання.

## Геометрія

| Властивість | Типове значення | Змінна |
| :--- | :--- | :--- |
| Внутрішній відступ | `0 DU` | `--op-tab-panels-padding` |

## Поведінка

* Видимою є лише та панель, індекс якої відповідає поточному значенню вибору.
* В анімованому режимі панель під час появи виконує плавний перехід прозорості та зсуву.
* Якщо `keep_alive` вимкнено, неактивні панелі демонтуються з DOM.
* Якщо `keep_alive` увімкнено, неактивні панелі залишаються в DOM із `display: none`.

## API

### TabPanels

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `value` | сигнал usize | обов’язковий | Поточний індекс вкладки, що визначає активну панель. |
| `animated` | сигнал bool | `true` | Вмикає анімовані переходи під час зміни вкладок. |
| `keep_alive` | bool | `false` | Залишає неактивні панелі змонтованими в DOM. |
| `padding` | метрика DU | немає | Внутрішній відступ контейнера панелей. |

### TabPanel

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `index` | usize | обов’язковий | Індекс, що відповідає елементу вкладки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `padding` | DU | `--op-tab-panels-padding` | `0 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-tab-panels-background` | `transparent` |
| `--op-tab-panels-text` | `text_primary` |

## Доступність

* Панелі мають `role="tabpanel"` та `tabindex="0"`.
* Неактивні панелі в режимі збереження приховані від допоміжних технологій через `display: none`.
