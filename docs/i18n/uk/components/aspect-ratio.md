# AspectRatio

Контейнер, що зберігає певне співвідношення сторін незалежно від зміни розмірів контейнера.
Він підходить для вбудованих відео, попереднього перегляду мап і фотографічних банерів.

Статус: **чернетка** у вебреалізації.

## Використання

Використовуйте `AspectRatio` щоразу, коли вміст має зберігати пропорційні розміри ширини до висоти (наприклад, 16:9, 4:3 або 1:1) у гнучких grid- чи flex-контейнерах.
Не використовуйте `AspectRatio`, коли вміст має природно розширюватися відповідно до обсягу тексту.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Типове співвідношення | `16 / 9` (`1.7778`). |
| Межі вмісту | Дочірній контейнер заповнює `100%` ширини та висоти розрахованого блока співвідношення. |

## Поведінка

* Компонент використовує сучасну властивість CSS `aspect-ratio`, щоб резервувати простір до завершення завантаження дочірніх ресурсів, запобігаючи зсуву макета (Cumulative Layout Shift, CLS).
* Дочірні елементи прикріплені до внутрішнього блока (`inset: 0`).

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `ratio` | f32 | `16.0 / 9.0` | Пропорційне співвідношення ширини, поділеної на висоту. |
| `max_width` | DU | немає | Обмеження максимальної ширини контейнера. |
| `max_height` | DU | немає | Обмеження максимальної висоти контейнера. |
| `class` | string | немає | CSS-класи на кореневому елементі. |
| `style` | string | немає | Інлайн-CSS на кореневому елементі. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `max_width` | DU | `--op-aspect-ratio-max-width` | `none` |
| `max_height` | DU | `--op-aspect-ratio-max-height` | `none` |

`class` та `style` застосовуються до кореневого `div`.

### Рядки

`AspectRatio` не рендерить текстових рядків.

### Піктограми

`AspectRatio` не використовує піктограм.

## Доступність

`AspectRatio` забезпечує структурне компонування та не змінює дерево доступності своїх дочірніх компонентів.
