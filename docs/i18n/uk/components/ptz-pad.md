# PtzPad

Контролер панорамування, нахилу та масштабування камери (PTZ) з інтерактивним джойстиком, навігацією стрілками та зворотним зв'язком станів Operator.

Статус: **draft** на web.

## Призначення

Використовуйте `PtzPad` для керування моторизованими або цифровими камерами з підтримкою PTZ, робототехнікою або напрямними оглядовими вікнами.
Не використовуйте `PtzPad` для простих лінійних покрокових налаштувань; використовуйте [Stepper](stepper.md) або [Slider](slider.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | Круглий (виняток радіуса `50%`, задокументований для джойстика напрямку). |
| Діаметр панелі за замовчуванням | `40 DU`. |
| Діаметр ручки | `15 DU`. |
| Межа | Стандартна межа `0.25 DU` всередині меж елемента. |

## Поведінка

* Перетягування центральної ручки або клік по панелі активує панорамування та нахил у відповідному напрямку.
* Після відпускання курсора ручка плавно повертається в центр та відправляє команду зупинки.
* Вісім індикаторів напрямку підсвічуються для відображення поточної орієнтації.
* Підтримує клавіатурну навігацію за допомогою стрілок (`ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`).
* Клавіші `+` та `-` викликають наближення та віддалення масштабу.
* Асинхронні дії відображають стани `Pending`, `Success` та `Error` безпосередньо на панелі та центральній точці.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `on_move` | callback `(PtzDirection, f32)` | немає | Передає активний напрямок та нормалізовану швидкість `[0.0, 1.0]`. |
| `on_zoom` | callback `PtzZoomDirection` | немає | Передає команду наближення або віддалення. |
| `on_async_command` | AsyncAction | немає | Обробник асинхронних команд. |
| `state` | ControlState | немає | Явне перевизначення стану контролера. |
| `enabled` | bool | `true` | Прапорець активності; блокує взаємодію, якщо false. |
| `show_diagonals` | bool | `true` | Відображає діагональні стрілки напрямку. |
| `show_zoom` | bool | `true` | Відображає вбудовані кнопки наближення та віддалення. |
| `size` | DU | `40.0` | Зовнішній діаметр панелі в DU (`--op-ptz-pad-size`). |
| `thumb_size` | DU | `15.0` | Діаметр ручки в DU (`--op-ptz-pad-thumb-size`). |
| `border_width` | DU | `0.25` | Товщина межі в DU (`--op-ptz-pad-border-width`). |
| `label` | string | `"PTZ Camera Control"` | Доступна мітка. |
| `zoom_in_label` | string | `"Zoom In"` | Доступна мітка для наближення. |
| `zoom_out_label` | string | `"Zoom Out"` | Доступна мітка для віддалення. |
| `center_slot` | Slot | немає | Слот замість центрального індикатора ручки. |
| `zoom_in_slot` | Slot | немає | Слот замість стандартної кнопки наближення. |
| `zoom_out_slot` | Slot | немає | Слот замість стандартної кнопки віддалення. |
| `extra_controls` | Slot | немає | Додаткові елементи керування під панеллю. |
| `class` | string | немає | CSS-класи кореневого елемента. |
| `style` | string | немає | Вбудовані стилі кореневого елемента. |

## Кастомізація

| Проп метрики | Одиниця | Змінна | За замовчуванням |
| :--- | :--- | :--- | :--- |
| `size` | DU | `--op-ptz-pad-size` | `40 DU` |
| `thumb_size` | DU | `--op-ptz-pad-thumb-size` | `15 DU` |
| `border_width` | DU | `--op-ptz-pad-border-width` | `0.25 DU` |

| Змінна кольору | За замовчуванням |
| :--- | :--- |
| `--op-ptz-pad-bg` | `var(--op-surface-alt)` |
| `--op-ptz-pad-border` | `var(--op-border)` |
| `--op-ptz-pad-active-color` | `var(--op-accent)` |
| `--op-ptz-pad-inactive-color` | `rgba(255, 255, 255, 0.4)` |
| `--op-ptz-thumb-bg` | `var(--op-surface)` |
| `--op-ptz-thumb-border` | `var(--op-border-strong)` |
| `--op-ptz-pad-disabled-bg` | `var(--op-disabled-surface)` |
| `--op-ptz-pad-disabled-border` | `var(--op-disabled-border)` |

`class` та `style` застосовуються до кореневого елемента.

## Доступність

Панель підтримує фокусування та сприймає навігацію клавішами зі стрілками.
Програми зчитування з екрана отримують описову назву з параметра `label`.
Кнопки масштабування є доступними кнопками-піктограмами з явними мітками.
