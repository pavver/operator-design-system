# Fab

Плавуча кнопка дії, яка розгортає стос дій.
Кнопка залишається закріпленою на екрані або в контейнері й відкриває контекстні дії при активації.

Статус: **чернетка** у вебреалізації.

## Використання

* Виділення ключового контекстного сценарію у представленні.
* Розгортання додаткових швидких дій за потреби.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Розмір | `row_standard` (`10 DU`). |
| Проміжок між діями | `gap_small` (`2 DU`). |
| Радіус заокруглення кутів | `0 DU`. |
| Стос дій | Завширшки з найширшу дію, але не вужчий за елемент відкриття; спільна рамка `accent` шару [Popover](popover.md). |

## Поведінка

* Клік на головній FAB перемикає прикріплений оверлей.
* Стос відкривається по центру над елементом відкриття, або під ним із `below`.
* Він перевертається на інший бік, коли вміщується лише там, і зсувається вбік біля краю екрана.
* Коли він не вміщується з жодного боку, то займає бік, де більше місця, і прокручується бібліотечним [Scrollbar](scrollbar.md).
* У відкритому стані клік на будь-якій дії виконує її та закриває шар.
* Дії закриваються при вимкненні, кліку зовні або прокручуванні сторінки чи іншого контейнера; прокручування самого стосу лишає його відкритим.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `actions` | `Vec<FabAction>` | обов’язковий | Дії у списку швидких дій. |
| `open` | сигнал bool | внутрішній | Сигнал стану розгортання. |
| `enabled` | bool | `true` | Вмикає взаємодію. |
| `below` | bool | `false` | Віддає перевагу місцю під FAB замість місця над нею. |
| `label` | string | `fab.label` | Доступний підпис головного елемента відкриття. |
| `icon` | піктограма | `fab.open` | Піктограма головного елемента відкриття. |
| `size` | метрика DU | `row_standard` | Діаметр або розмір елемента відкриття. |
| `gap` | метрика DU | `gap_small` | Проміжок між діями у стосі. |
| `content` | `Slot` | немає | Власний вміст замість тексту елемента відкриття. |
| `leading` | `Slot` | немає | Початковий вміст усередині елемента відкриття. |
| `trailing` | `Slot` | немає | Кінцевий вміст усередині елемента відкриття. |
| `class`, `style` | string | немає | Кореневі хуки. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `size` | DU | `--op-fab-size` | `row_standard` (`10 DU`) |
| `gap` | DU | `--op-fab-gap` | `gap_small` (`2 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-fab-background` | `surface` |
| `--op-fab-text` | `text_primary` |
| `--op-fab-border` | `accent` |

| Слот | Розташування |
| :--- | :--- |
| `leading` | Початкова область усередині кнопки відкриття. |
| `trailing` | Кінцева область усередині кнопки відкриття. |
| `content` | Замінює текст кнопки відкриття. |

`class` і `style` застосовуються до кореневої обгортки.

## Доступність

Кнопка відкриття встановлює `aria-haspopup="dialog"` і `aria-expanded`.
Відкриття списку швидких дій автоматично фокусує першу кнопку дії.
