# ScrollArea

Контейнер вертикального прокручування з тонкою смугою прокручування та розтягуванням за межами країв.

Статус: **reviewed** у вебреалізації.

## Використання

Кожна стрічка, список і панель із вертикальним прокручуванням використовують однакову фізику виходу за межі на всіх платформах.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Смуга прокручування | Бібліотечний [Scrollbar](scrollbar.md). |
| Висота | Заповнює батьківський елемент або має фіксовану чи максимальну висоту в DU. |
| Фокус | Контур `0.25 DU` у кольорі `accent` всередині меж. |

## Розтягування при прокручуванні за межі

Потягування за край розтягує вміст замість різкої зупинки або світіння.

1. На верхньому краї потягування вниз, а на нижньому — вгору розтягує вміст уздовж осі прокручування.
   Розтягування закріплене на краї, за який тягнуть.
2. Розтягування зростає з відстанню потягування й досягає насичення: на 60% висоти області перегляду вміст стає на 8% вищим, і це межа.
3. Відпускання пружно повертає вміст за `overscroll_release` (`300 ms`) зі стандартною кривою.
4. Потягування назад до початкової позиції зменшує розтягування; після її проходження відновлюється звичайне прокручування.
5. Ефект працює, навіть коли вміст коротший за область перегляду.

* Дотик керує розтягуванням безпосередньо через перетягування.
* Коліщатко миші керує ним через зміну прокручування на краю й пружно повертає через `120 ms` після останньої події коліщатка.
* За налаштування зменшеного руху розтягування немає.
* Сторінка позаду ніколи не прокручується, коли область досягає краю.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `height` | DU | немає | Фіксована висота. |
| `max_height` | DU | немає | Максимальна висота. |
| `focus_outline_width` | DU | `border` | Ширина контуру фокусу. |
| `stretch` | bool | `true` | Вмикає розтягування при прокручуванні за межі. |
| `label` | string | `scroll-area.label` | Робить область іменованим регіоном. |
| `header` | слот | немає | Вміст перед прокручуваною областю перегляду. |
| `footer` | слот | немає | Вміст після прокручуваної області перегляду. |
| `children` | view | обов’язковий | Вміст. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-scroll-area-height` | немає (заповнює батьківський елемент) |
| `max_height` | DU | `--op-scroll-area-max-height` | `100%` |
| `focus_outline_width` | DU | `--op-scroll-area-focus-outline-width` | `border` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-scroll-area-focus-outline-color` | `accent` |

| Слот | Розташування |
| :--- | :--- |
| `header` | Фіксований вміст над прокручуваною областю перегляду. |
| `footer` | Фіксований вміст під прокручуваною областю перегляду. |

`class` і `style` застосовуються до кореневого елемента scrollview.

### Рядки

| Ключ | Типове значення |
| :--- | :--- |
| `scroll-area.label` | `""` |

### Піктограми

ScrollArea не має вбудованих семантичних піктограм.

## Доступність

Область може отримувати фокус, щоб користувачі клавіатури могли її прокручувати; із підписом вона є `region`.
