# Layout

Контейнер структури оболонки програми із заголовком, підвалом, бічними панелями та вмістом сторінки.
Містить допоміжні компоненти PageSticky та PageScroller.

Статус: **draft** у вебреалізації.

## Використання

Використовуйте Layout як каркас верхнього рівня програми або окремої області перегляду.
Він керує областями компонування, не дублюючи компоненти на зразок [Header](header.md), [NavigationRail](navigation-rail.md) чи [SidePanel](side-panel.md).

## Геометрія

| Область | Типове значення | Змінна |
| :--- | :--- | :--- |
| Висота шапки | `14 DU` | `--op-layout-header-height` |
| Висота підвалу | `12 DU` | `--op-layout-footer-height` |
| Ширина початкової панелі | `60 DU` | `--op-layout-start-drawer-width` |
| Ширина кінцевої панелі | `60 DU` | `--op-layout-end-drawer-width` |
| Зсув Sticky X | `4 DU` | `--op-page-sticky-offset-x` |
| Зсув Sticky Y | `4 DU` | `--op-page-sticky-offset-y` |

## Поведінка

* У режимі вікна перегляду (`container = false`) Layout займає весь екран (`100vw`, `100vh`) із фіксованим позиціюванням.
* У контейнерному режимі (`container = true`) Layout заповнює батьківський елемент (`100%` ширини та висоти).
* Бічні панелі відкриваються та згортаються плавно за допомогою токенів руху.
* PageScroller відстежує позицію прокручування та з'являється після подолання порогу.
* Натискання на PageScroller плавно повертає прокручування на початок (або в кінець у зворотному режимі).

## API

### Layout

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `container` | сигнал bool | `false` | Обмежує структуру батьківським контейнером замість усього вікна. |
| `header` | слот | немає | Вміст верхньої панелі. |
| `footer` | слот | немає | Вміст нижнього підвалу. |
| `start_drawer` | слот | немає | Вміст лівої або початкової навігаційної панелі. |
| `end_drawer` | слот | немає | Вміст правої або кінцевої службової панелі. |
| `start_drawer_open` | сигнал bool | `true` | Керує видимістю початкової панелі. |
| `end_drawer_open` | сигнал bool | `true` | Керує видимістю кінцевої панелі. |
| `header_height` | метрика DU | `14 DU` | Висота шапки. |
| `footer_height` | метрика DU | `12 DU` | Висота підвалу. |
| `start_drawer_width` | метрика DU | `60 DU` | Ширина початкової панелі. |
| `end_drawer_width` | метрика DU | `60 DU` | Ширина кінцевої панелі. |

### PageSticky

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `position` | `StickyPosition` | `BottomEnd` | Точка прив'язки до краю чи кута. |
| `offset_x` | метрика DU | `4 DU` | Горизонтальний зсув від точки прив'язки. |
| `offset_y` | метрика DU | `4 DU` | Вертикальний зсув від точки прив'язки. |

### PageScroller

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `scroll_offset` | метрика DU | `50 DU` | Відстань прокручування до появи кнопки. |
| `position` | `StickyPosition` | `BottomEnd` | Положення кнопки прокручування. |
| `reverse` | bool | `false` | Прокручує до кінця замість початку. |
| `aria_label` | рядок | `layout.scroll-top` | Доступна назва для екранних дикторів. |

## Тексти

| Ключ | Типовий текст (uk) | Опис |
| :--- | :--- | :--- |
| `layout.scroll-top` | `Прокрутити вгору` | Доступний підпис кнопки прокручування вгору. |
| `layout.scroll-bottom` | `Прокрутити вниз` | Доступний підпис кнопки зворотного прокручування. |

## Піктограми

| Ключ | Типове значення | Опис |
| :--- | :--- | :--- |
| `icons::ARROW_UPWARD` | Material arrow upward | Типова піктограма для кнопки PageScroller. |
| `icons::ARROW_DOWNWARD` | Material arrow downward | Піктограма у зворотному режимі. |

## Доступність

* Використано орієнтири: `role="banner"` для шапки, `role="contentinfo"` for підвалу, `role="complementary"` для бічних панелей та `role="main"` для вмісту.
* Плаваючі кнопки мають мінімальну зону натискання `8 DU`.
