# SegmentedControl

Рядок взаємовиключних варіантів із рухомим індикатором вибору.
Асинхронний варіант підтверджує кожен вибір на бекенді й відкочує його в разі помилки.

Статус: **reviewed** у вебреалізації.

## Використання

* Вибір одного з двох–п'яти коротких варіантів: режиму, рівня якості, фільтра.
* Компактні панелі інструментів із сегментами лише з піктограмами або з піктограмами та текстом.

## Анатомія

```
┌───────────────────────────────────────────┐
│┌─────────────┐                            │
││    Auto     │     Day          Night     │
│└─────────────┘                            │
└───────────────────────────────────────────┘
  indicator      items
```

* **Контейнер:** заглиблена доріжка з контуром.
* **Індикатор:** завширшки один сегмент; ковзає під елементами та має контур стану.
* **Елементи:** текст, піктограма або піктограма з текстом після неї.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Ширина | Заповнює батьківський елемент; елементи ділять ширину порівну. |
| Висота | `9 DU` за замовчуванням. |
| Внутрішній відступ | `gap_micro` (`0.5 DU`). |
| Радіус заокруглення кутів | `0 DU`. |
| Піктограма елемента | `icon_small` (`4 DU`). |
| Проміжок між піктограмою та текстом | `pad_small` (`1.5 DU`). |
| Текст | Стиль `body_small`; насиченість 500, у вибраному стані 700. |

## Кольори

| Частина | Колір |
| :--- | :--- |
| Контейнер | `surface_alt` із контуром `border`. |
| Індикатор | `accent` із непрозорістю `15%`, контур `accent`. |
| Індикатор (асинхронний) | `accent` із непрозорістю `15%`, контур `border`, щоб контур стану залишався читабельним. |
| Невибраний елемент | `text_secondary`. |
| Вибраний елемент | `accent`. |
| Вимкнений | `disabled_surface`, `disabled_border`, `text_disabled`; без індикатора. |

## Поведінка

### Синхронний

* Клік на елементі негайно вибирає його.
* Індикатор лінійно ковзає до нового елемента за `segment_slide` (`150 ms`).
* Кольори тексту елементів змінюються за ту саму тривалість і криву, тому акцент рухається разом з індикатором.

### Асинхронний

1. Клік на невибраному елементі переміщує індикатор до нього.
   Індикатор переходить у `Pending`, а цільовий елемент зберігає вміст, доки його не замінить [спінер із затримкою](../foundations/states.md#delayed-spinner).
2. Під час очікування всі елементи ігнорують введення.
3. У разі **успіху** вибір фіксується.
   Індикатор і вибраний елемент спалахують кольором `Success` на `500 ms`, потім згасають до вигляду вибраного стану.
4. У разі **помилки** індикатор ковзає назад до попереднього елемента з тим самим лінійним рухом тривалістю `150 ms`.
   Індикатор і попередній елемент спалахують кольором `Error` на `600 ms`, потім згасають до вигляду вибраного стану.

Анімація ковзання не залежить від контуру стану.
Стани результату змінюють кольори миттєво, але ніколи не скасовують і не скорочують ковзання.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `items` | список `SegmentItem` | обов’язковий | Варіанти. |
| `selected` | індекс для читання й запису | обов’язковий | Зафіксований вибір. |
| `enabled` | bool | `true` | Інтерактивність. |
| `on_select` | асинхронний `(usize) -> ActionResult` | немає | Вмикає асинхронний варіант. |
| `height` | DU | `9` | Висота елемента керування. |
| `padding` | реактивний DU | не встановлено | Перевизначає `--op-segmented-control-padding`; див. Кастомізація. |
| `gap` | реактивний DU | не встановлено | Перевизначає `--op-segmented-control-gap`; див. Кастомізація. |
| `icon_size` | реактивний DU | не встановлено | Перевизначає `--op-segmented-control-icon-size`; див. Кастомізація. |
| `font_size` | реактивний TU | не встановлено | Перевизначає `--op-segmented-control-font-size`; див. Кастомізація. |
| `line_height` | реактивний TU | не встановлено | Перевизначає `--op-segmented-control-line-height`; див. Кастомізація. |
| `spinner_stroke` | реактивний DU | не встановлено | Перевизначає `--op-segmented-control-spinner-stroke`; див. Кастомізація. |
| `width` | реактивний DU | не встановлено | Перевизначає `--op-segmented-control-width`; див. Кастомізація. |
| `class` | реактивний string | немає | Застосовується до кореневого елемента. |
| `style` | реактивний string | немає | Застосовується до кореневого елемента. |
| `option` | слот з областю видимості | немає | Замінює мітку варіанта; отримує елемент. |
| `before_options` | слот | немає | Перед варіантами вибору. |
| `after_options` | слот | немає | Після варіантів вибору. |
| `loading_label` | реактивний string | `segmented-control.loading` | Перевизначення рядка; див. Рядки. |
| `label` | реактивний string | `segmented-control.label` | Перевизначення рядка; див. Рядки. |

`SegmentItem` містить необов'язковий текст і необов'язкову піктограму.
Принаймні один із них має бути присутнім.

## Доступність

* Контейнер має роль `tablist`.
* Кожен елемент має роль `tab` і повідомляє, чи його вибрано.

## Кастомізація

`class` та `style` застосовуються до кореневого елемента.
Метричні пропси приймають реактивні значення DU або TU; невстановлені пропси зберігають змінну CSS або її точний запасний варіант із дизайн-системи.
`style` викликача додається після оголошень метрик і має вищий пріоритет.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `height` | DU | `--op-segmented-control-height` | `calc(var(--op-du) * 9)` |
| `padding` | DU | `--op-segmented-control-padding` | `var(--op-dim-gap-micro)` |
| `gap` | DU | `--op-segmented-control-gap` | `var(--op-dim-pad-small)` |
| `icon_size` | DU | `--op-segmented-control-icon-size` | `var(--op-dim-icon-small)` |
| `font_size` | TU | `--op-segmented-control-font-size` | `var(--op-type-body-small-size)` |
| `line_height` | TU | `--op-segmented-control-line-height` | `var(--op-type-body-small-line)` |
| `spinner_stroke` | DU | `--op-segmented-control-spinner-stroke` | `var(--op-dim-spinner-stroke)` |
| `width` | DU | `--op-segmented-control-width` | `100%` |

Наявні числові пропси розміру зберігають назви та значення в DU й тепер також приймають реактивні значення.

### Піктограми

Немає вбудованих семантичних піктограм.

Піктограми, передані як дані елемента або через наявний проп `icon`, залишаються у власності викликача.

Новий запит замінює попередній таймер результату, тому той не може очистити новіший зворотний зв'язок.
