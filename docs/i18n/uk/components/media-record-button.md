# MediaRecordButton

Тактична кнопка запису медіа, що підтримує голосові аудіонотатки та відеоповідомлення.
Вона підтримує утримання для запису, свайп ліворуч для скасування та свайп угору для фіксації.

Статус: **draft** на web.

## Застосування

Використовуйте `MediaRecordButton` поруч із панелями введення чату та формами діалогів.
Швидке натискання перемикає режими між записом голосу та круглим відеоповідомленням.
Натискання й утримання розпочинає запис; проведення вліво скасовує запис без збереження, а проведення вгору фіксує запис у режимі hands-free.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` стандартно (підтримує круглу форму як виняток). |
| Стандартна рамка | `0.25 DU` контурна рамка кнопки. |
| Розмір за замовчуванням | `12 DU` (квадратний розмір кнопки; `--op-media-record-button-size`). |

## Поведінка

* Швидке натискання без утримання перемикає режими аудіо та відеонотаток.
* Утримання понад 200 мс запускає подію `on_record_start`.
* Проведення вліво скасовує активний запис і викликає `on_record_cancel`.
* Проведення вгору фіксує запис у режимі hands-free і викликає `on_record_locked`.
* Відпускання кнопки після утримання завершує запис і викликає `on_record_stop`.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `mode` | `MediaRecordMode` | `Voice` | Режим запису (`Voice` або `Video`). |
| `recording` | `bool` | `false` | Чи активний процес запису. |
| `locked` | `bool` | `false` | Стан зафіксованого запису. |
| `disabled` | `bool` | `false` | Вимикає взаємодію з кнопкою. |
| `circular` | `bool` | `false` | Опціональний виняток круглої форми. |
| `size` | `f32` | `12.0` | Розмір кнопки в Design Units. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |
| `on_mode_change` | `Callback<MediaRecordMode>` | немає | Зміна режиму запису. |
| `on_record_start` | `Callback<MediaRecordMode>` | немає | Початок процесу запису. |
| `on_record_stop` | `Callback<()>` | немає | Завершення процесу запису. |
| `on_record_cancel` | `Callback<()>` | немає | Скасування активного запису. |
| `on_record_locked` | `Callback<()>` | немає | Фіксація запису в режимі hands-free. |

## Налаштування

### Метричні параметри

| Параметр | Змінна CSS | За замовчуванням | Одиниця |
| :--- | :--- | :--- | :--- |
| `size` | `--op-media-record-button-size` | `12.0` | DU |

### Кольорові змінні

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |
| `--op-media-record-button-bg` | `var(--op-surface)` | Фон у стані спокою. |
| `--op-media-record-button-border` | `var(--op-border)` | Рамка у стані спокою. |
| `--op-media-record-button-color` | `var(--op-text-primary)` | Колір піктограми у стані спокою. |
| `--op-media-record-button-active-border` | `var(--op-accent)` | Рамка активного запису. |
| `--op-media-record-button-locked-border` | `var(--op-success)` | Рамка зафіксованого запису. |
| `--op-media-record-button-canceling-border` | `var(--op-error)` | Рамка скасування запису. |

## Рядки

| Ключ | Англійський текст | Опис |
| :--- | :--- | :--- |
| `media-record.audio` | `"Voice note"` | Доступна назва аудіорежиму. |
| `media-record.video` | `"Video note"` | Доступна назва відеорежиму. |
| `media-record.locked-label` | `"Locked recording (click to stop)"` | Доступна назва зафіксованого стану. |
| `media-record.cancel-hint` | `"< Slide to cancel"` | Підказка скасування проведенням. |
| `media-record.lock-hint` | `"^ Slide to lock"` | Підказка блокування проведенням. |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `media-record.voice` | `icons::ARROW_UPWARD` | Індикатор аудіонотатки. |
| `media-record.video` | `icons::VIDEOCAM` | Індикатор відеонотатки. |
| `media-record.lock` | `icons::LOCK` | Індикатор фіксації режиму. |

## Доступність

* Доступні назви автоматично оновлюються залежно від режиму та фіксації.
* Таймер запису позначається контрастною пульсуючою міткою.
