# MediaRecordButton

Тактична кнопка запису медіа, яка сповіщає програму про наміри захоплення голосових та круглих відеоповідомлень.
Вона підтримує перемикання режимів кліком, утримання для запису, проведення вліво для скасування, проведення вгору для фіксації та відображення таймера тривалості.

Статус: **draft** на web.

## Застосування

Використовуйте `MediaRecordButton` у полях введення чату, диспетчерських панелях та мультимедійних каналах зв'язку.
Кнопка передає наміри запису (`on_record_start`, `on_record_stop`, `on_record_cancel`, `on_record_locked`) до застосунку.
Застосунок відповідає за апаратний доступ до мікрофона/камери та формування файлів медіа.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Радіус кутів | `0 DU` (стандартна квадратна геометрія; кругле виключення `50%` при прапорці `circular`). |
| Стандартна рамка | `0.25 DU` стандартна рамка в стані спокою. |
| Акцентна рамка | `0.5 DU` рамка під час активного або зафіксованого запису. |
| Розмір за замовчуванням | `12 DU` (48px квадратний розмір кнопки; `--op-media-record-button-size`). |

## Поведінка

* Короткий клік перемикає режим запису між голосовим та круглим відеоповідомленням.
* Утримання кнопки понад 200 мс розпочинає процес запису.
* Проведення вліво понад 15 DU скасовує запис та відкидає поточні дані.
* Проведення вгору понад 15 DU фіксує запис у режимі вільних рук.
* У зафіксованому стані один клік завершує та надсилає запис.
* Відпускання кнопки без фіксації чи скасування штатно завершує запис.

## API

| Властивість | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `mode` | `MediaRecordMode` | `Voice` | Поточний режим запису (`Voice` або `Video`). |
| `recording` | `bool` | `false` | True, коли запис активно триває. |
| `locked` | `bool` | `false` | True, коли запис зафіксовано в режимі вільних рук. |
| `disabled` | `bool` | `false` | Вимикає взаємодію з кнопкою. |
| `circular` | `bool` | `false` | Кругле виключення форми кнопки. |
| `size` | `f32` | `12.0` | Розмір у Design Units. |
| `on_mode_change` | `Callback<MediaRecordMode>` | немає | Подія перемикання режиму запису. |
| `on_record_start` | `Callback<MediaRecordMode>` | немає | Подія початку запису після утримання. |
| `on_record_stop` | `Callback<()>` | немає | Подія завершення запису. |
| `on_record_cancel` | `Callback<()>` | немає | Подія скасування запису проведенням вліво. |
| `on_record_locked` | `Callback<()>` | немає | Подія фіксації запису проведенням вгору. |
| `class` | `string` | немає | Додаткові класи CSS. |
| `style` | `string` | немає | Вбудовані стилі CSS. |

## Налаштування

| Змінна | За замовчуванням | Роль |
| :--- | :--- | :--- |

| `--op-media-record-button-border` | `var(--op-color-border)` | Рамка у стані спокою. |
| `--op-media-record-button-active-bg` | відтінок акценту | Фон активного запису. |
| `--op-media-record-button-active-border` | `var(--op-color-accent)` | Рамка активного запису. |
| `--op-media-record-button-locked-bg` | відтінок успіху | Фон зафіксованого запису. |
| `--op-media-record-button-locked-border` | `var(--op-color-success)` | Рамка зафіксованого запису. |

## Рядки

| Ключ | Англійський текст | Опис |
| :--- | :--- | :--- |
| `media-record.audio` | `"Voice note"` | Доступна назва голосового запису. |
| `media-record.video` | `"Video note"` | Доступна назва відеоповідомлення. |
| `media-record.cancel-hint` | `"< Slide to cancel"` | Підказка скасування проведенням вліво. |
| `media-record.lock-hint` | `"^ Slide to lock"` | Підказка фіксації проведенням вгору. |

## Піктограми

| Ключ | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `media-record.voice` | `icons::ARROW_UPWARD` | Позначка голосового запису. |
| `media-record.video` | `icons::VIDEOCAM` | Позначка відеоповідомлення. |
| `media-record.lock` | `icons::LOCK` | Позначка фіксації запису. |

## Доступність

* Доступні підписи автоматично оновлюються залежно від режиму та фіксації.
* Таймер запису супроводжується контрастним пульсуючим індикатором.
