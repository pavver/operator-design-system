# Avatar

Зображення або ініціал людини, групи чи каналу з необов’язковим бейджем статусу.

Статус: **reviewed** у вебреалізації.

## Форма

Форма вказує на те, що саме представляє аватар.
Заокруглені форми тут є дозволеним винятком із прямокутної геометрії.

| Вид | Форма |
| :--- | :--- |
| `Direct` (людина) | Коло. |
| `ThreadedGroup` | Квадрат, радіус `0`. |
| `Channel` | Заокруглений квадрат, радіус `15%` від розміру. |
| `SimpleGroup` | Заокруглений квадрат, радіус `35%` від розміру. |

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Розмір | `avatar_header` (`10 DU`) типово; `avatar_small` (`6 DU`) та `avatar_default` (`8 DU`) для компактних списків. |
| Контур | `0.25 DU` у кольорі `border`, присутній завжди. |
| Ініціал | Перша літера імені, велика, напівжирна, `45%` від розміру. |
| Спінер завантаження | `80%` від розміру, `pending`, центрований навколо ініціала. |
| Бейдж статусу | Нижній правий кут із накладанням на контур. |

## Колір

Аватари без зображення використовують колір, обчислений на основі їхнього id, тому одна й та сама сутність має однаковий колір усюди.

1. Обчисліть Java `String.hashCode` для id: для кожної кодової одиниці UTF-16, `h = h * 31 + unit` із 32-бітною арифметикою з переповненням.
2. Виберіть відтінок із `[190, 210, 250, 290, 330, 160, 35]` за індексом `abs(h) mod 7`.
3. Перетворіть із HSV із насиченістю `0.45` і значенням `0.75` у темному режимі або `0.65` і `0.8` у світлому режимі.

Ініціал використовує цей колір; тло має той самий колір із непрозорістю 15%.

## Поведінка

* Зображення покриває всю форму з кадруванням по центру.
* Доки зображення завантажується, відображаються ініціал і спінер.

## API

| Властивість | Тип | Типове значення |
| :--- | :--- | :--- |
| `id` | string | обов’язковий |
| `name` | string | обов’язковий |
| `kind` | `AvatarKind` | `Direct` |
| `size` | DU | `10` |
| `status` | `PresenceStatus` | немає |
| `image_url` | string | немає |
| `badge` | slot | немає |
| `font_size` | TU | обчислюється з розміру |
| `border_width` | DU | `0.25` |
| `badge_offset` | DU | `0.25` |
| `badge_size` | DU | обчислюється з розміру |
| `aria_label` | string | `name` |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `size` | DU | `--op-avatar-size` | `avatar_header` (`10 DU`) |
| `font_size` | TU | `--op-avatar-font-size` | `18 TU` при 10 DU (`size * 1.8`) |
| `border_width` | DU | `--op-avatar-border-width` | `border` (`0.25 DU`) |
| `badge_offset` | DU | `--op-avatar-badge-offset` | `border` (`0.25 DU`) |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-avatar-background` | `color-mix(in srgb, var(--op-avatar-color) 15%, transparent)` |
| `--op-avatar-text` | `var(--op-avatar-color)` |
| `--op-avatar-border` | `border` |

| Слот | Розташування |
| :--- | :--- |
| `badge` | Замінює вбудований бейдж статусу в нижньому кінцевому кутку. |

`class` та `style` застосовуються до кореня.
