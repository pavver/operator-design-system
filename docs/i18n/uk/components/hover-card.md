# HoverCard

Плавуча картка з подробицями про елемент: що робить нода й як нею користуватися, попередній перегляд, коротка довідка з посиланнями.
На відміну від [Tooltip](tooltip.md), містить довільний вміст, зокрема посилання та кнопки, і залишається відкритою, поки вказівник над нею.

Статус: **чернетка** у вебреалізації.

## Використання

* Довідка за піктограмою `info`, наприклад опис типу ноди.
* Подробиці, які не вміщуються поруч з елементом і не потребують діалогу.
* Звичайні однорядкові підказки залишаються в [Tooltip](tooltip.md).

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Ширина | Типово `80 DU`, не ширше за область перегляду мінус `margin_screen` з обох боків. |
| Висота | До `100 DU`; довший вміст прокручується всередині картки. |
| Внутрішній відступ | `pad_card`; між блоками вмісту `pad_tight`. |
| Відстань | `1.5 DU` від якоря. |
| Поверхня | `surface_alt`, спільна рамка [Popover](popover.md) `0.25 DU` у кольорі `accent` всередині меж і тінь піднятого шару, як у [Menu](menu.md). |

## Поведінка

* Миша відкриває картку після наведення на якір протягом затримки підказки.
* Картка залишається відкритою, поки вказівник над якорем або карткою; закривається через `200 ms` після виходу вказівника з обох областей.
* Натискання на якорі (дотиком, пером або кліком) перемикає картку, тож вона працює без наведення.
* Клавіатурний фокус на якорі відкриває її (`open_on_focus`).
* Escape та натискання поза карткою й якорем закривають її.
* Картка є шаром [Popover](popover.md) під якорем (перевертається вгору за браку місця), тому предки з обрізанням ніколи її не обрізають.

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `card` | view | обов’язковий | Вміст картки. |
| `children` | view | обов’язковий | Якір, зазвичай [IconButton](icon-button.md) з `info`. |
| `delay_ms` | integer | затримка підказки | Час наведення до відкриття. |
| `width` | реактивна метрика DU | `80` | Ширина картки. |
| `placement` | `Placement` | `BelowStart` | Розташування поруч із якорем. |
| `label` | string | немає | Доступна назва картки. |
| `open_on_focus` | bool | `true` | Відкривати при клавіатурному фокусі. |

Властивості кастомізації є необов’язковими та приймають реактивні значення там, де це вказано.

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `class`, `style` | реактивний string | немає | Кореневі хуки. |
| `shadow_y` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-hover-card-shadow-y`. |
| `shadow_blur` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-hover-card-shadow-blur`. |
| `viewport_margin` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-hover-card-viewport-margin`. |
| `padding` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-hover-card-padding`. |
| `gap` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-hover-card-gap`. |
| `max_height` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-hover-card-max-height`. |
| `offset` | реактивна метрика DU | значення дизайн-системи | Встановлює `--op-hover-card-offset`. |
| `font_size` | реактивна метрика TU | значення дизайн-системи | Встановлює `--op-hover-card-font-size`. |

| `aria_label` | реактивний string | `hover-card.label` | Доступна назва; має пріоритет над `label`. |

## Кастомізація

`class` і `style` застосовуються до плавучого шару картки.
Метричні пропси записують відповідні змінні; явне оголошення `style` має перевагу.

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `shadow_y` | DU | `--op-hover-card-shadow-y` | `2 DU` |
| `shadow_blur` | DU | `--op-hover-card-shadow-blur` | `6 DU` |
| `viewport_margin` | DU | `--op-hover-card-viewport-margin` | `margin_screen` |
| `padding` | DU | `--op-hover-card-padding` | `pad_card` |
| `gap` | DU | `--op-hover-card-gap` | `pad_tight` |
| `width` | DU | `--op-hover-card-width` | `80 DU` |
| `max_height` | DU | `--op-hover-card-max-height` | `100 DU` |
| `offset` | DU | `--op-hover-card-offset` | `1.5 DU` |
| `font_size` | TU | `--op-hover-card-font-size` | `body_size` |
| `line_height` | TU | `--op-hover-card-line-height` | `body_line` |
| `max_width` | DU | `--op-hover-card-max-width` | `calc(100vw - var(--op-hover-card-viewport-margin, margin_screen) * 2)` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-hover-card-background` | `surface_alt` |
| `--op-hover-card-border` | `accent` |
| `--op-hover-card-shadow` | `rgb(0 0 0 / 35%)` |
| `--op-hover-card-text` | `text_primary` |

| Слот | Розташування |
| :--- | :--- |
| `header` | Вміст перед вмістом картки. |
| `actions` | Дії після вмісту картки. |
| `footer` | Вміст після тіла та дій. |

`header` передує `card`; `actions` і `footer` йдуть після нього всередині того самого тіла з внутрішніми відступами.

### Рядки

| Ключ | Типове значення | Проп |
| :--- | :--- | :--- |
| `hover-card.label` | `empty` | `aria_label / label` |

### Піктограми

Цей компонент не має вбудованих піктограм.

## Доступність

* Картка має роль `dialog` і заданий підпис; якір повідомляє `aria-expanded`.
