# EmptyState

Повідомлення замість вмісту, якого ще немає або який відфільтровано.
Пояснює, чому область порожня та що робити далі.

Статус: **reviewed** у вебреалізації.

## Використання

* Порожні списки, таблиці, результати пошуку та панелі.
* Пояснюйте, що зазвичай міститься тут і як це отримати; уникайте жартів та ілюстрацій.

## Геометрія

| Властивість | Значення |
| :--- | :--- |
| Компонування | Стовпець із центруванням. |
| Внутрішній відступ | `10 DU` по вертикалі та `4 DU` по горизонталі; компактний варіант: `6 DU` × `3 DU`. |
| Піктограма | `12 DU`, у компактному варіанті `8 DU`, колір `text_disabled`, на `2 DU` вище заголовка. |
| Назва | Стиль `row_title`, колір `text_primary`. |
| Опис | Основний стиль тексту, `text_secondary`, ширина щонайбільше `90 DU`. |
| Дії | На `3 DU` нижче тексту, по центру, із проміжком `2 DU`. |

## API

| Властивість | Тип | Типове значення | Опис |
| :--- | :--- | :--- | :--- |
| `title` | string | `empty-state.title` | Чого бракує. |
| `description` | string | немає | Чому та що робити. |
| `icon` | піктограма | `empty-state.icon` | Символ вмісту. |
| `actions` | слот | немає | Одна або дві кнопки. |
| `icon_slot` | слот | немає | Власний вміст піктограми. |
| `title_slot` | слот | немає | Власний вміст заголовка. |
| `compact` | bool | `false` | Менший варіант для панелей і тіл таблиць. |
| `icon_size` | DU | `12` (компактний варіант `8`) | Розмір піктограми. |
| `padding_x` | DU | `4` (компактний варіант `3`) | Горизонтальний внутрішній відступ. |
| `padding_y` | DU | `10` (компактний варіант `6`) | Вертикальний внутрішній відступ. |
| `gap` | DU | `1` | Проміжок між елементами. |
| `icon_gap` | DU | `2` | Проміжок під піктограмою. |
| `title_size` | TU | `type_row_title_size` | Розмір шрифту заголовка. |
| `max_width` | DU | `90` | Максимальна ширина опису. |

## Кастомізація

| Метричний проп | Одиниця | Змінна | Типове значення |
| :--- | :--- | :--- | :--- |
| `icon_size` | DU | `--op-empty-state-icon-size` | `12 DU` (компактний варіант `8 DU`) |
| `padding_x` | DU | `--op-empty-state-padding-x` | `margin_screen` (`4 DU`; компактний варіант `pad_card`, `3 DU`) |
| `padding_y` | DU | `--op-empty-state-padding-y` | `10 DU` (компактний варіант `section_gap`, `6 DU`) |
| `gap` | DU | `--op-empty-state-gap` | `pad_tight` (`1 DU`) |
| `icon_gap` | DU | `--op-empty-state-icon-gap` | `gutter` (`2 DU`) |
| `title_size` | TU | `--op-empty-state-title-size` | `type_row_title_size` |
| `max_width` | DU | `--op-empty-state-max-width` | `90 DU` |

| Змінна кольору | Типове значення |
| :--- | :--- |
| `--op-empty-state-title` | `text_primary` |
| `--op-empty-state-text` | `text_secondary` |
| `--op-empty-state-icon` | `text_disabled` |

| Слот | Розташування |
| :--- | :--- |
| `actions` | Кнопки під текстом. |
| `icon_slot` | Слот власної піктограми, що замінює вбудовану. |
| `title_slot` | Слот власного заголовка, що замінює текст заголовка. |

`class` і `style` застосовуються до кореня.
