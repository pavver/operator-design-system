# Web (Leptos)

[web/operator-ui](../../web/operator-ui) — це бібліотека компонентів для Leptos 0.8 у режимі клієнтського рендерингу.
[web/operator-ui-demo](../../web/operator-ui-demo) — це сайт документації.
Він містить по одній сторінці для кожного базового поняття та компонента з живими прикладами, і саме тут кожен компонент перевіряється в кожному стані.

## Сайт документації

Вимоги: ціль `wasm32-unknown-unknown` та [Trunk](https://trunkrs.dev).

```bash
rustup target add wasm32-unknown-unknown
cd web/operator-ui-demo
trunk serve
```

Відкрийте `http://127.0.0.1:8090/`.
Верхня панель перемикає темний і світлий режими.
Сторінки з асинхронними прикладами показують панель симуляції бекенду, яка примусово задає наступний результат (успіх, помилка чи чергування) та налаштовує затримку.

Текст сторінки не написаний мовою Rust.
Скрипт збирання рендерить кожен файл у [docs](..) у HTML, тому кожна сторінка показує той самий Markdown, який читають агенти ШІ.
Посилання між файлами Markdown стають посиланнями між сторінками; посилання на інші файли репозиторію відкриваються на GitHub.
Щоб задокументувати новий компонент, додайте його файл Markdown та зареєструйте його приклади в `src/pages/mod.rs` і його місце на бічній панелі в `src/main.rs`.

## Використання

Огорніть застосунок у `ThemeRoot`.
Він встановлює атрибути теми та одноразово підключає таблиці стилів токенів і компонентів.

```rust
use operator_ui::prelude::*;

#[component]
fn Settings() -> impl IntoView {
    let name = RwSignal::new("Gate-North".to_string());
    view! {
        <ThemeRoot>
            <TextField
                value=name
                placeholder="Device name"
                on_save=AsyncAction::new(|value: String| async move {
                    // send `value` to the backend here
                    let _ = value;
                    ActionResult::Success
                })
            />
        </ThemeRoot>
    }
}
```

Застосунок надає Cascadia Code через `@font-face`.
Сайт документації показує, як це зробити, у [demo.css](../../web/operator-ui-demo/demo.css).

## Примітки щодо реалізації

* Базовий контур є внутрішньою `box-shadow`, що утримує обведення всередині меж без зміни розміру елемента.
* Пульсація результату — це шар `::after` із подвійною межею; фон результату — це шар `::before`, що згасає лише через непрозорість.
* `data-state` містить поточний стан, `data-result` зберігає останній результат під час згасання при виході, а `data-fading` присутній, поки триває згасання.
* Сегмент очікування — це SVG-прямокутник із `pathLength="100"` і штриховим патерном `25 75`, анімованим за годинниковою стрілкою.
* TextField малює свій контур на шарі `::before` над кінцевими елементами керування.
* SegmentedControl переміщує індикатор за допомогою елемента-обгортки, тому стани результату, що вимикають переходи кольорів, ніколи не скасовують ковзання.
* Slider запобігає типовій дії pointer-down, щоб зупинити виділення тексту та нативне перетягування, яке інакше скасувало б перетягування.
